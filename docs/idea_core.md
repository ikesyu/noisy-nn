# NNN 中核理論・アルゴリズム（統一版）

**この文書の役割**: Noise-modulated Neural Network（NNN）そのものの理論とアルゴリズムを、
各チャレンジ文書（`idea_ca.md` / `idea_consolidation.md` / `idea_rl.md` / `idea_reservoir.md` /
`idea_duality.md` / `idea_coding.md` / `idea_fpga.md`）と実装（`nnn/`, `data_nce/fncl/`,
`tmp/rl/`, `tmp/consolidation/`, `tmp/reservoir/`）から再構成し、**単一の正典**として与える。

各チャレンジは同じモデルの異なる断面を扱っており、そこで導入された記号・規約・拡張が
文書ごとに少しずつ異なっている。本稿では、

1. まず**記号を裁定**し（第 1 節）、
2. NNN 本体の理論を、**ゲージ対称性を理論の一部として組み込んだ形**で述べ（第 2〜4 節）、
3. 学習則（forward-only credit assignment）を正典形で与え（第 5 節）、
4. 応用チャレンジは**最も成功した構成**と**本体理論に還元される知見**だけを簡潔に記す（第 7 節）。

作成日: 2026-08-01。以後、記号・定式化に変更が生じた場合は本稿を先に更新し、各チャレンジ文書が
本稿を参照する形に揃える。

### この文書の 4 つの核

急いでいる読者のために、本稿が言っていることを 4 文にまとめる。以下はすべてこの 4 つの敷衍である。

1. **ノイズがなければ NNN は計算しない。** 交差活性は入力がノイズをまたいだ瞬間だけ発火するので、
   ノイズを切ると恒等的に沈黙する。ノイズは除去すべき外乱ではなく、動作の前提である（第 2 節）。
2. **ノイズはユニットのものさしである。** 前活性も閾値も「ノイズ何個分か」という形でしか効かない。
   だから $\sigma$ の絶対値はそれ自体では意味を持たず、意味を持つのは比だけである（第 4 節）。
3. **同じ揺らぎが推論と学習の両方を賄う。** 推論のために引いた $T$ 個のサンプルの共分散から、
   重みミラーと局所傾きが得られ、backprop の構造が転置重みなしで再構成される（第 5 節）。
4. **ノイズ場は「誰が計算に参加するか」を決める。** 参加度はゲージ不変な交差率 $\nu$ で測り、
   制御はゲージ横断的なダイヤル $\rho$ で行う（第 3 節）。

### 1.2 多義記号の裁定

以下は文書間で衝突していた記号である。**左が本稿の正典用法**、右が今後使わない／改名する用法。

#### $\rho$ — 動員ダイヤル**のみ**に使う

- **正典**: $\rho_k \in [0,1]$、$\sigma_k=\rho_k\sigma_0,\ h_k=h_0/\rho_k$（`idea_consolidation.md` §4.6、
  `idea_rl.md` §23.7、`idea_reservoir.md` §5.6、`draft_tcds.md`）。**制御変数**であり観測量ではない。
- 改名するもの:
  - `idea_ca.md` §5.1 の層内相関比 $\rho_{ki}=\sum_n\mathrm{Cov}_T(z_k,z_i)/\sum_n\mathrm{Var}_T(z_i)$
    → 本稿では $\boldsymbol{c_{ki}}$（correlation ratio）と書く。
  - `idea_consolidation.md` §12.6.8 の圧縮残量計 $\rho_l=\mathrm{er}_l/n_l$
    → 本稿では $\boldsymbol{\varrho_l}$ もしくは「圧縮残量比 $R_l$」と書く。
  - `idea_duality.md` の $P=\mathrm{softplus}(\rho)$ における内部パラメータ $\rho$
    → $\boldsymbol{\varsigma}$（$\sigma=\mathrm{softplus}(\varsigma)$）と書く。
  - `idea_reservoir.md` §5.7 の減衰直交場のスペクトル半径 $\rho=0.97$
    → $\boldsymbol{\lambda_{\mathrm{sp}}}$ と書く。

#### $\nu$ — 交差率（観測量）

$\nu_k=\mathbb E[z_k]=\bar\phi(d_k;\sigma_k,h_k)$。**ゲージ不変な参加量**であり、
「そのユニットが計算に参加しているか」の唯一正しい尺度。

$\rho$ が**制御ダイヤル**（設定する量）であるのに対し、$\nu$ は**観測量**（測る量）である。
両者は同一ではなく、$\rho\downarrow$ とともに $\nu\downarrow$ し、**有限の $\rho$ で $\nu=0$ に到達する**
（不感帯、第 3.5 節）という単調な関係にあるだけである。

#### $\sigma$ — 4 つの別物を区別する

| 記号 | 意味 | 出典 |
|---|---|---|
| $\sigma_k$ | **注入ノイズ強度**（正典）。ノイズ場の成分 | 全文書 |
| $\sigma_e$ | RL の**外付け探索ノイズ**。$a=\mu+\sigma_e\epsilon$ | `idea_rl.md` §23.1 |
| $\sigma_{\mathrm{eff}}$ | 上流からの輸送ゆらぎを含む**実効ノイズ** $\sigma_{\mathrm{eff}}^2=\sigma_k^2+\mathrm{Var}(\text{輸送})$ | `idea_coding.md` §5.7 |
| $\sigma_\mu$ | PPO の**アンサンブル平均 $\mu$ 自身の標準偏差** $\approx \mathrm{std}_T/\sqrt T$ | `idea_rl.md` §23.10 |

$\sigma_e$ と $\sigma_k$ の混同は特に危険である。$\sigma_e$ は NNN の内部ノイズではなく、方策の
探索温度として**外から足された**独立なガウスノイズであり、現状の NNN-RL に残る構造的な逸脱点である
（第 7.2 節）。

#### $h$ — 二重の役割は衝突ではなく本質

$h_k$ は (i) 交差判定の 2 しきい値 $\pm h_k$ の半幅であり、同時に (ii) 局所傾き推定 $\phi_T'$ の

という NNN の設計上の要点である（第 2.4 節）。文書によって「crossing_h」「バンド幅」と呼び分けられて
いるが同じ $h$ を指す。

## 2. 素子: 交差活性化関数（crossing activation）

### 2.1 定義

NNN の基本素子は、**ノイズが存在するときにのみ発火する**活性化関数である。
入力 $d\in\mathbb R$ に対し、独立同分布のノイズ $\eta_1,\eta_2\overset{\mathrm{i.i.d.}}\sim p(\xi)$ を用いて

$$
z=\phi(d)=
\begin{cases}
1 & \text{if } (d\ge\eta_1)\ \dot\vee\ (d\ge\eta_2)\\
0 & \text{otherwise}
\end{cases}
$$

（$\dot\vee$ は XOR）。入力がノイズを「またいだ」瞬間にのみ 1 を出す最小のスパイキングニューロンであり、
$p(\xi)=\delta(\xi)$（ノイズなし）では定数入力に対して交差が起こり得ず、出力は恒等的に 0 になる。
これが「ノイズがなければ NNN は計算しない」という主張の数学的な中身である。

### 2.2 期待応答と局所微分

$F(d)=P(d\ge\eta)=\int_{-\infty}^d p(\xi)\,d\xi$ とおくと、

$$
\boxed{\ \mathbb E[z]=\bar\phi(d)=2F(d)\bigl(1-F(d)\bigr)\ }
\qquad
\boxed{\ \bar\phi'(d)=2\bigl(1-2F(d)\bigr)\,p(d)\ }
$$

**なぜこの形になるのか。** $F(d)$ は「1 回の抽選で $d\ge\eta$ となる確率」である。
2 回の抽選は独立なので、XOR が 1 になるのは「ちょうど一方だけが当たる」ときであり、
その確率は $F(1-F)+(1-F)F=2F(1-F)$ になる。式はこれだけのことを言っている。

この読み方から形も見える。$d$ がノイズ分布の中央にあるとき（$F=0.5$）2 回の抽選が最も食い違いやすく、
発火確率は最大の $0.5$ になる。逆に $d$ が極端に大きいか小さいと 2 回の抽選が**両方とも同じ結果**に
なってしまい、XOR は 0 に落ちる。すなわち $\bar\phi:\mathbb R\to[0,0.5]$ は
$F(d)=0.5$ で最大となる**単峰のバンプ**であって、シグモイド型の飽和ではない。
RBF に似た滑らかな基底として機能する。$\bar\phi'$ はしきい値の下側で正、上側で負、遠方で消える。

このバンプ性は後で 2 度効いてくる。第 3.3 節では「$\nu\approx0$ は沈黙とは限らない
（動作点が遠いだけかもしれない）」という注意になり、第 4.6 節では
「$\sigma\to0$ の極限が接近経路に依存する」という現象の源になる。

**この 2 式はノイズ分布を制限しない。** 累積分布 $F$ を持つ任意の $p(\xi)$ でそのまま成立する。

二値の階段関数の集まりであるにもかかわらず統計的な傾き $\mathrm d\mathbb E[z]/\mathrm dd$ が解析的に定まる、
という点が重要である。スパイキングネットワークの surrogate gradient が手設計の平滑関数で階段関数の
微分を置き換えるのに対し、NNN では順伝播の応答そのものとその微分が同一のノイズ統計から導かれるため、
**推論と学習の間に不整合がない**。

### 2.3 具体形

**ガウスノイズ** $p(\xi)=\mathcal N(0,\sigma^2)$、$F(d)=\frac12\bigl(1+\operatorname{erf}\frac{d}{\sqrt2\sigma}\bigr)$:

$$
\bar\phi(d)=\frac12\left(1-\operatorname{erf}^2\frac{d}{\sqrt2\,\sigma}\right),\qquad
\bar\phi'(d)=-\sqrt{\frac2\pi}\,\frac1\sigma\,\operatorname{erf}\!\left(\frac{d}{\sqrt2\,\sigma}\right)e^{-d^2/(2\sigma^2)}
$$

**一様ノイズ** $p(\xi)=\frac1{2r_u}\mathbf 1\{|\xi-c_u|\le r_u\}$:

$$
\bar\phi(d)=\frac12\left[1-\left(\frac{d-c_u}{r_u}\right)^{2}\right]_+,\qquad
\bar\phi'(d)=-\frac{d-c_u}{r_u^{2}}\quad(|d-c_u|<r_u,\ \text{他は }0)
$$

一様ノイズでは期待応答が**厳密な放物線**、局所微分が**一次式**に退化し、かつ
$|d-c_u|\ge r_u$ で発火確率が**厳密に 0**（コンパクトサポート）になる。この疎性はガウスでは得られず、
イベント駆動実装での活動・電力の疎性に直結する（第 7.6 節）。

### 2.4 分布フリーな局所傾き推定量 $\phi_T'$

$\bar\phi'$ の解析形はノイズ分布の事前知識を要するが、交差活性は**分布フリーな微分推定器を内蔵している**。
同一のノイズサンプルに対して入力を $\pm h$ ずらした 2 つの交差出力 $z^\pm=\phi(d\pm h)$ の
$T$ サンプル平均を $\bar z^+,\bar z^-$ とおくと、

$$
\boxed{\ \phi_T(d)=\tfrac12(\bar z^++\bar z^-)\approx\bar\phi(d),\qquad
\phi_T'(d)=\frac{\bar z^+-\bar z^-}{2h}\approx\bar\phi'(d)\ }
$$

$\phi_T'$ は帯域幅 $h$ の一様カーネルによるカーネル密度推定であり、$T\to\infty,\ h\to0$ で $\bar\phi'$ に収束する
（バイアスは $O(h^2)$）。

**統計的な要点**: $z^+$ と $z^-$ は**共通のノイズサンプル上で**評価される。しきい値を $\pm h$ ずらすことは
前活性 $d$ を $\mp h$ ずらすことと等価なので、$\phi_T'$ は共通乱数（common random numbers）の下での
対称有限差分に相当し、共有されたノイズが差分で相殺されて低分散になる。すなわち交差活性は、
antithetic/CRN 型の分散低減を自身のサンプル上で**追加コストなく**実行する微分推定器である。

第 5 節の学習則ではこの $\phi_T'$ を局所感度 $\partial z/\partial d$ として用いる。
検証では解析形 $\bar\phi'$ との交換可能性が確認されている（`idea_ca.md`: 0.035 対 0.031）。
すなわち**ノイズ分布の解析モデルは学習に不要**であり、分布フリー性の価値は性能ではなく適用範囲にある。

### 2.5 実装上の実現（2 しきい値と巡回 XOR）

実装（`nnn/activation.py`）は、$\eta_1,\eta_2$ を「$T$ 軸上の隣接する 2 サンプル」として実現し、
2 しきい値 $\pm h$ の交差カウンタを同時に生成する:

$$
b^+_t=\mathbf 1[d+\eta_t>h],\quad b^-_t=\mathbf 1[d+\eta_t>-h],\qquad
z_t=\tfrac12\Bigl(\lvert b^+_{t+1}-b^+_t\rvert+\lvert b^-_{t+1}-b^-_t\rvert\Bigr)
$$

（末尾は先頭に wrap する巡回 XOR）。同じ 2 本のカウンタの**和**が応答 $z$ を、**差**が傾き $\phi_T'$ を与える:

$$
\phi_T' = \frac{\overline{\lvert\Delta b^-\rvert}-\overline{\lvert\Delta b^+\rvert}}{2h}
$$

これが $h$ の二重の役割（第 1.2 節）の正体である。ハードウェア的には**比較器 2 個 + XOR + カウンタ 2 本**
で応答と局所微分の両方が得られる。

#### 同一パス版と再抽選版（実装上の重要な区別）

理想形では、$\phi_T'$ は**推論のために既に引かれたサンプル**の 2 本のカウンタから読み出される。
これが「学習の統計量は追加コストなしで得られる」という主張の根拠である。
`Crossing.backward` / `CrossingSample.backward` はまさにこれを実装しており、
`ctx` に保存した順伝播時の `xor1, xor2` から係数を返す。

ところが `nnn/stats.py: kde_slope` は**当該層を新しいノイズで再実行する**:

```python
d_req = d_clean.detach().clone().requires_grad_(True)
z = crossing_layer(d_req)      # ← 層の内部で torch.randn_like が再度呼ばれる
z.sum().backward()             # d_req.grad = mean_T(xor2' - xor1') / (2h)
```

`Capture` のフックは crossing 層モジュールの**入力**を記録するので、`d_clean` は
ノイズ注入**前**の前活性である。したがって再実行時に自層の $\eta^{(l)}$ が引き直される。
理由は純粋に実装上の都合である。学習ループは `no_grad` 下の手動更新なので順伝播が計算グラフを
作らず、`ctx` に保存されたはずの 2 本のカウンタが残っていない。活性化関数に手を入れずに
係数を取り出す最短経路が、この局所的な再実行だった。

**引き直されるもの・されないもの**:

| 量 | 再実行時の扱い |
|---|---|
| 決定的平均 $\bar d_k$ | **保存**（`d_clean` そのもの） |
| 上流サンプルゆらぎ $\delta^{\mathrm{up}}_k(t)$ | **保存**（$l\ge2$ では `d_clean` が $T$ 方向に変動しており、それがそのまま使われる） |
| 自層の注入ノイズ $\eta^{(l)}_k(t)$ | **引き直される** |

**推定量としての性質は変わらない**。共通乱数による分散低減は「$\phi_T'$ と順伝播の間」ではなく
「2 つのしきい値 $+h$ と $-h$ の間」に効いており、再実行内部で $\mathrm{xor}_1'$ と $\mathrm{xor}_2'$ は
同一のノイズ集合上で評価されるので、antithetic/CRN の性質は完全に保たれる。
不偏性も同じ（どちらも $\bar\phi'$ の同一の推定量）。
むしろ、$\phi_T'$ が $d$ を与えたとき $z^{(l)}$ と独立になるため、三要素則の積
$\langle\hat g\cdot\phi_T'\cdot z_{\mathrm{prev}}\rangle$ が意図どおり
「credit × 局所傾き × 前シナプス発火」の積に因数分解される、という副次的な利点さえある。

**変わるのはコストの会計だけである。** 層 1 つ分の追加評価と $[N,T,H]$ の追加乱数生成が生じるため、
第 5.10 節の「$T$ 回の forward サンプリングは全手法共通」という前提や、
第 7.6 節のハードウェア議論とは整合しない。回路では 2 本のカウンタを順伝播と同時に数えるべきである。

**同一パス版は既に実装・検証されている**: `tmp/fncl_phase1_fxp.py`（FPGA Phase 1）の Stage A は
`code = xor1 + xor2`（$=2z$）と `cdiff = \sum_t(\mathrm{xor}_2-\mathrm{xor}_1)$（slope の分子）を
1 回の順伝播で同時に得る。すなわち**再抽選は本質的な要件ではなく、汎用ライブラリ側の autograd 上の便宜**である。
`nnn/stats.py` 側も、`Capture` にノイズ注入後の値（または 2 本のカウンタ）を記録させれば
autograd なしで同一パス版に置き換えられる。

### 2.6 実装水準（sample / statistic / analytic）と、平均場が失うもの

| 水準 | 出力 | 用途 |
|---|---|---|
| **Sample-level** $\phi$ | 二値の確率的スパイク | **本体**。学習則も推論もこの水準で定義される |
| **Statistical-level** | $T$ サンプル平均（確率的連続値） | 中間水準。`CrossingStatistic` |
| **Analytical-level** $\bar\phi$ | 期待値（決定論） | 高速な平均場近似。`CrossingAnalytic` |

**理論的に重要な非等価性**: analytic 水準は sample 水準の忠実な縮約では**ない**。
ノイズ強度に対する最適性が消える。`recipe_sr.md` §3 と `draft_front_comp_neuro.md` §4 の実測:

- `sample`（実ノイズ注入 + $h>0$）: 学習水準スイープで**内点最適** $\sigma^*\approx0.8$–$1.2$、
  低 $\sigma$ 側で崩壊。しきい値下の信号はノイズの助けなしには伝達されないという**真の障壁**がある。
- `analytic`（期待値、しきい値なし）: 低 $\sigma$ でも重みの再スケールで学習が成立するため
  **低 $\sigma$ 端が最適**。SR の障壁を持たない。

すなわち**確率共鳴（SR）は平均場近似では消え、サンプルレベルの機構でのみ現れる**。
これは「ノイズは実装手段ではなく資源である」という NNN の中心主張の、最も直接的な証拠である。
`idea_reservoir.md` §13.1 でも同一重みでの診断により再確認された（sample は逆 U 字 $\kappa_\sigma^*\approx0.20$–$0.23$、
analytic は平坦なプラトー、6 seed すべて）。

## 3. ネットワークとノイズ場

### 3.1 層構成とアンサンブル平均読み出し

交差活性を要素ごとに適用する全結合フィードフォワードネットワーク。$\mathbf z^{(0)}=\mathbf x$ とし、
隠れ層 $l=1,\dots,L-1$ で

$$
\mathbf d^{(l)}=W^{(l)}\mathbf z^{(l-1)}+\mathbf b^{(l)},\qquad
\mathbf z^{(l)}=\Phi^{(l)}\bigl(\mathbf d^{(l)}\bigr),
$$

出力層は線形読み出し $\mathbf y=W^{(L)}\mathbf z^{(L-1)}+\mathbf b^{(L)}$。
学習対象は $\theta=\{W^{(l)},\mathbf b^{(l)}\}$ のみで、活性化層自体は学習パラメータを持たない。

1 回の推論において各ユニットは独立なノイズを $T$ 回引き、二値発火のサンプル列
$z^{(l)}_{(m)}\ (m=1,\dots,T)$ を生成する。ネットワーク出力はその線形読み出しのアンサンブル平均:

$$
\bar{\mathbf y}=\frac1T\sum_{m=1}^{T}\mathbf y_{(m)}
$$

**この $T$ 個の確率的 forward サンプルは推論のために元々計算されるものであり、第 5 節の学習則は
それを追加コストなく credit assignment の統計量として再利用する。** これが NNN の学習則が
「専用の摂動フェーズを持たない」と主張できる根拠である。

> **$T$ は時間ではない。** 全実装において $T$ 軸は「1 入力あたりの i.i.d. 確率サンプル」であり、
> 時間発展・OU 過程・時間相関ノイズはコア実装に存在しない。時間軸を明示的に扱うのは
> `idea_coding.md`（realtime `Crossing` を $[N,T,H]$ の $T$ 方向に適用）と
> `idea_reservoir.md`（場が時間発展する）だけで、いずれも本体からの明示的な拡張である。

### 3.2 ノイズ場 $\mathcal P$

各ユニットに与えるノイズ分布は共通である必要はない。第 $l$ 層第 $k$ ユニットのノイズ分布を
$p^{(l,k)}$ とおき、これらの全体を**ノイズ場**と呼ぶ:

$$
\mathcal P=\bigl\{\,p^{(l,k)}\,\bigr\}_{l,k}
$$

実用上は、スケールパラメータ $\sigma_k$ としきい値 $h_k$ の組で場を表現する:
$\mathcal P=\{(\sigma^{(l)}_k, h^{(l)}_k)\}$。

$p^{(l,k)}=\delta$（ノイズなし）のユニットは出力も勾配も恒等的に 0 となり、推論・学習の双方から
完全に切り離される。したがってノイズ場は、**どの部分ネットワークを計算に動員（recruit）するか**を
定めるハイパーパラメータとして機能する。重み $\theta$ が「動員されたサブネット内の写像」を決め、
場 $\mathcal P$ が「どのサブネットが機能するか」を決める、という役割分担である。

**credit と recruitment が同一の場を共有する**という点が本モデル固有の性質である。第 5 節の学習則は
この場と自然に整合し、$\sigma_k=0$ のユニットは共分散 credit も厳密に 0 になって更新から自動的に外れる。

実装上の場の生成:

| 実装 | 場の実体 |
|---|---|
| `nnn/noise_field.py` | 仮想 N-D グリッド上の分離型ガウスバンプ。振幅 0.1 未満を切断し、「振幅 > 0.1 の球の体積 = activation_ratio」となるよう $\sigma$ を解析的に逆算 |
| `tmp/rl/field.py` | uniform / split / graded / recruit / **recruit_rho** / bump（$\tau$ 直接指定）/ overlapping_pair |
| `tmp/consolidation/core.py` | per-unit `sigma_vecs`・`h_vecs`（$\rho$ ダイヤルの実体）+ `kill_unit` |
| `tmp/reservoir/nnn_map.py` | $\sigma_k(t)=\text{floor}+\mathrm{softplus}((M_{\mathrm{mix}}A(t))_k+\beta_k)$（**唯一、時変**） |

### 3.3 交差率 $\nu$: ゲージ不変な参加量

ユニットの「参加度」を測る正しい量は $\sigma_k$ ではなく**交差率**

$$
\nu_k = \mathbb E[z_k] = \bar\Phi\!\left(\frac{d_k}{\sigma_k},\ \frac{h_k}{\sigma_k}\right)
$$

である。期待活性 $\bar\Phi$ は $(d,h,\sigma)$ について**0 次同次**であり、比 $d/\sigma$ と $h/\sigma$ にしか
依存しない。この 0 次同次性が第 4 節のゲージ対称性の源であり、同時に「$\sigma$ の絶対値そのものには
意味がない」という帰結を生む。

**なぜ $\sigma$ ではなく $\nu$ なのか、一言で言えば**: $\sigma$ は「ノイズ源をどれだけ強く鳴らしたか」、
$\nu$ は「そのユニットが実際にどれだけ喋ったか」である。両者は一致しない。
上流から借りた声で喋ることもあれば（第 3.4 節の漏れ）、
強く鳴らしても動作点が遠くて黙っていることもある（$\bar\Phi$ がバンプだから）。
**参加しているかどうかを知りたいなら、鳴らした量ではなく喋った量を測る。**

したがって、コンソリデーション・recruitment・lesion など「どのユニットが働いているか」を論じる
すべての操作は、**$\nu$ 場の支持 $\{k\mid\nu_k>0\}$ の操作**として定義するのが正しい。

**期待の取り方に注意**: 上式の $\nu_k$ は入力を固定したときのノイズ期待値である。
$\bar\Phi$ は $|d_k|/\sigma_k$ が大きいところでも 0 に向かう**バンプ**なので、
動作点がしきい値から遠いだけのユニットも $\nu_k\approx0$ になる。これは $\rho$ で退役させた
ユニットとは全く別の状態であり（入力が変われば再び発火する）、両者を取り違えてはならない。
recruitment の指標として使うときは、**入力分布についても平均した**

$$
\bar\nu_k=\mathbb E_{x}\bigl[\nu_k(x)\bigr]
$$

を用いる（実装の「実測平均活動」がこれにあたる）。厳密退役の判定だけは、
$\bar\nu_k=0$ ではなく第 3.5 節の kill 三点操作が成立していることで行う。

**分散との関係**: $z_k$ は二値なので

$$
\mathrm{Var}(z_k)=\nu_k(1-\nu_k)
$$

が恒等的に成り立つ。$\nu_k\in[0,0.5]$ ではこれが $\nu_k$ の単調増加関数なので、
**参加量・credit の分母・下流に伝わるゆらぎの大きさがすべて同一の $\nu$ 場の単調関数**になる。
第 5.3 節の credit 自動消灯も、`idea_rl.md` §25.3 の「行動温度と動員量は場の操作だけでは
独立に動かせない」という交絡も、いずれもこの恒等式の帰結である。

**推定量としての注意**: $\nu_k$ は $T$ サンプル平均で推定するが、巡回 XOR により
$z_t$ と $z_{t+1}$ はサンプルを共有する（第 3.4 節）。したがって実効サンプル数は $T$ より小さく、
lag-1 相関の分だけ推定分散が大きい。

### 3.4 深層の漏れと全ゆらぎ分解

第 2 層以降では、前活性のゆらぎは注入ノイズだけではない:

$$
d_{k,t}=\underbrace{\bar d_k}_{\text{決定的平均}}
+\underbrace{\delta^{\mathrm{up}}_k(t)}_{\text{上流サンプルゆらぎ}}
+\underbrace{\eta_k(t)}_{\text{注入ノイズ }\sigma_k}
$$

このため、**$\sigma_k=0$ にしても層 $l\ge2$ では交差が続く**（「$\sigma=0$ リーク」）。
上流のゆらぎが $\pm h_k$ をまたいでしまうからである。実測では層 2 で $\nu=0.11$–$0.17$ の
プラトーが残る（`idea_consolidation.md` §12.7.6、`idea_rl.md` §21.4）。

#### なぜ漏れるのか: 理想形とサンプル実現の差

この漏れは NNN のモデル定義そのものから出るのではなく、**サンプルレベルの実現の仕方から出る**。
両者を分けておかないと、各文書の記述の正誤が判定できない。

一言で言えばこうである。**理想形は「同じ $d$ に対してコインを 2 回投げる」。実装は
「隣のサンプルのコインを借りる」。借りるとき、コインだけでなく隣の $d$ まで一緒に付いてくる。**
ノイズを切っても隣の $d$ は消えないので、そこが漏れ口になる。

**理想形（第 2.1 節）では漏れない。** $z=\mathbf 1[(d\ge\eta_1)\ \dot\vee\ (d\ge\eta_2)]$ は
**同一の $d$** に対する 2 回の独立抽選である。$p^{(l,k)}=\delta$（ノイズなし）なら
$\eta_1=\eta_2=0$ で 2 つの比較が恒等的に一致するので、$d$ の値によらず
$z\equiv0$ が**任意の層で厳密に**成立する。すなわち理想形の NNN では、
$\sigma_k=0$ は深さを問わずユニットを切り離す。

**実装（第 2.5 節）は漏れる。** 巡回 XOR は 2 回の抽選を「$T$ 軸上の隣接サンプル」で実現するため、
比較されるのは $\mathbf 1[d_t+\eta_t\gtrless\pm h]$ と $\mathbf 1[d_{t+1}+\eta_{t+1}\gtrless\pm h]$、
すなわち**異なる 2 つの前活性**である。$\eta\equiv0$ とすると

$$
z_t=\tfrac12\Bigl(\bigl\lvert\mathbf 1[d_{t+1}>h]-\mathbf 1[d_t>h]\bigr\rvert
+\bigl\lvert\mathbf 1[d_{t+1}>-h]-\mathbf 1[d_t>-h]\bigr\rvert\Bigr)
$$

となり、隣接サンプルの前活性がしきい値をまたぐたびに発火する。

**両者が一致する条件は $d$ が $T$ 方向に一定であること**である。
第 1 隠れ層では `SampleLayer` が $\mathbf d^{(1)}=W^{(1)}\mathbf x+\mathbf b^{(1)}$ を $T$ 回複製するので
$d$ は $T$ に沿って定数であり、実装は理想形を厳密に再現する。
層 $l\ge2$ では $\mathbf z^{(l-1)}$ が確率的なので $d_t$ が $T$ 方向に変動し、一致が崩れる。

**帰結**:

- 「$\sigma_k=0$ でユニットが切り離される」という記述は、**理想形の主張としては正しく、
  サンプルレベルのネットワークの主張としては第 1 隠れ層に限って正しい**。
  すべての実験はサンプルレベルで走っているので、運用上の規則は $\rho$（次節）である。
- したがって `draft_nce.md` §3.2 の場 $s_k\in[0,1]$（$\sigma$ のみをスケール）は
  理想形の記述としては無矛盾だが、隠れ 2 層の実験系に外挿すると誤りになる。
- 副次的な帰結として、$z_t$ と $z_{t+1}$ はサンプル $t+1$ を共有するため、
  $T$ 個の出力は**lag-1 相関**を持つ。これは有効ランクのノイズフロア補正
  （`idea_ca.md` §12.7.1: $\mathrm{Cov}_n(\bar z^{\mathrm{est}})=C_{\mathrm{true}}+(G_0+G_1+G_1^{\mathsf T})/T$ で
  lag-1 項が半分を担う）として既に観測されている。

`idea_coding.md` §5.7 は、この輸送を定量化した:

$$
\sigma_{\mathrm{eff},l+1}^2 \;\propto\; \underbrace{\chi\,\sigma_{\mathrm{eff},l}^2}_{\text{共有 = 保存}}
\;+\;\underbrace{(1-\chi)\,\sigma_{\mathrm{eff},l}^2/N}_{\text{独立 = 希釈}}
$$

（$\chi$ は共有ノイズ比、$N$ は層幅）。コヒーレントな信号駆動が $\propto 1$ で保存されるのに対し、
独立ゆらぎはプーリングで $1/\sqrt N$ に希釈される。したがって「深いほどレート符号化に寄る」という
素朴な予想は棄却され、**深さは輸送（レート方向）とプーリング（タイミング方向）の綱引きであり、
帰趨は上流ゆらぎの相関構造 $\chi$ が決める**。

### 3.5 動員ダイヤル $\rho$ と厳密沈黙

$\sigma$ と $h$ を**逆向きに**連動させる 1 本のダイヤルを導入する:

$$
\boxed{\ \sigma_k=\rho_k\,\sigma_0,\qquad h_k=h_0/\rho_k,\qquad \rho_k\in[0,1]\ }
$$

**なぜ逆向きなのか。** $\sigma$ を下げるだけでは第 3.4 節の漏れ口が塞がらない。上流ゆらぎが
残るからである。そこで $\sigma$ を下げると同時に $h$ を**上げる**、つまり不感帯を広げる。
ゆらぎが縮みながら不感帯が広がるので、**両側から挟み撃ちになる**。
定量的には $h_k/\sigma_k = h_0/(\rho_k^2\sigma_0)$ が $\rho_k^{-2}$ で発散する。
片側だけの $\rho_k^{-1}$ ではなく $\rho_k^{-2}$ で開くことが要点である。

受信ゆらぎ $|\bar d_k+\delta^{\mathrm{up}}_k+\eta_k|$ が有界である限り、
不感帯はいずれゆらぎの全域を覆い尽くす。すなわち
**有限の $\rho_k$ で $\nu_k=0$ が厳密に成立する**（不感帯）。
極限を取る必要はなく、途中で到達して止まる。
実測では $\rho\approx0.6^6\approx0.05$ で厳密 0、RL の実装では max mean $z$ = 0.0000。

完全な退役（kill）は次の 3 操作で行う:

$$
\sigma_k \leftarrow 0,\qquad h_k \leftarrow H_{\mathrm{DEAD}}=10^{6},\qquad W^{(l+1)}_{:,k}\leftarrow \mathbf 0
$$

$\sigma_k=0$ なら受信ゆらぎは上流の二値和のみで厳密に有界だから、$h$ 番兵によって $z_k\equiv0$ が
**測度零の例外もなく**成立する。このとき順伝播・KDE スロープ・credit・勾配のすべてが厳密に 0 になる。

**credit の自動消灯**: 学習側の離脱も同じ物理量が担う。

$$
\hat g_{z,k}=\frac{\mathrm{Cov}(L,z_k)}{\mathrm{Var}(z_k)+\varepsilon}
$$

において $\rho_k\to0$ では $\mathrm{Var}(z_k)\to0$ かつ $\mathrm{Cov}(L,z_k)\to0$ となり、
**推論離脱と学習離脱が単一のダイヤルで同時に進行する**。正則化項も凍結マスクも不要である。

> $\rho$ の向きは、学習時の慣用である連動 $h=c_h\sigma$（動員: $h\propto\sigma$）とは**逆**である
> （離脱: $h\propto1/\sigma$）。この向きの違いには第 4.6 節で幾何的な意味が与えられる。

### 3.6 ノイズ場の時間構造（周期タイル化）

深層でのミラー推定バイアス（第 5.7 節）を根治するために導入された、場の**時間方向（$T$ 軸方向）**の構造である。
上流層のノイズを周期 $P_\eta$ でタイルする:

$$
\eta_t=\eta_{t\bmod P_\eta}\qquad (P_\eta\ge4,\ P_\eta\mid T)
$$

対象層のノイズは周期 1（通常どおり）。共分散は位相クラス $G_c=\{t: t\equiv c\ (\mathrm{mod}\ P_\eta)\}$
**の内部で**中心化する。これにより層内相関の源である「上流層の総発火数のサンプルごとのゆらぎ」が
位相クラス内で定数になり、相関が**そもそも生じない**。

- $P_\eta=2$ は交差活性が退化するため不可（隣接サンプルが同一ノイズになる）。

## 4. ゲージ理論

NNN のパラメータ空間には**厳密な局所ゲージ対称性**が存在する。これは補足的な観察ではなく、
「何が学習可能な自由度か」「何を目的関数や評価指標に使ってよいか」を決める本体理論の一部である。

### 4.0 直観: ノイズはユニットのものさしである

厳密な話に入る前に、絵を 1 枚与えておく。

交差活性が見ているのは「入力 $d$ がノイズをまたいだか」だけである。ノイズの振れ幅 $\sigma$ は、
**そのユニットが世界を測るときのものさしの目盛り**にあたる。前活性 $d$ も閾値 $h$ も、
それ自体の絶対値ではなく「目盛り何個分か」という形でしか発火に効かない。

であれば、$d$・$h$・$\sigma$ を**一斉に**伸縮しても何も起きないはずである。
長さを cm で測るか inch で測るかを変えただけで、物が伸び縮みするわけではないからである。
これが NNN のゲージ対称性の中身であり、第 4.1 節以降はその厳密化にすぎない。

この 1 枚の絵から、本節の実務的な結論が 2 つとも出てくる。

- **単位に依らない量だけが意味を持つ。** 比 $d/\sigma$（動作点は閾値からノイズ何個分離れているか）、
  $h/\sigma$（不感帯はノイズ何個分の幅か）、実効ゲイン $\gamma_k=\lVert a_k\rVert/\sigma_k$
  （入力 1 単位でノイズ何個分動くか）、そして交差率 $\nu_k$（観測量なのでそもそも単位に依らない）。
- **単位に依存する量を目的関数や評価指標にしてはいけない。** 「$\mathrm{mean}(\mathcal P)$ を小さくせよ」
  という正則化は、「メートルで測った値を小さくせよ」と言っているのと同じである。
  キロメートルに持ち替えれば、ネットワークを一切変えずに達成できてしまう。

### 4.1 対称群の導出

「$\sigma$ がものさしである」ことは、次の 5 段で厳密になる。

**(1) ノイズがスケール族であること。** $p_k(\xi)=\frac1{\sigma_k}q(\xi/\sigma_k)$、すなわち
$\eta_k=\sigma_k u$ と書ける（$u$ は $\sigma$ を含まない標準化ノイズ）。
ガウスなら $q=\mathcal N(0,1)$、一様なら $q=\mathrm{Unif}(-1,1)$ である。

**(2) 累積分布が比の関数になる。**

$$
F(d;\sigma)=\int_{-\infty}^{d}\frac1\sigma\,q\!\left(\frac\xi\sigma\right)d\xi=Q\!\left(\frac d\sigma\right)
$$

**(3) 期待応答が比だけの関数になる。** 実装形の期待活性
$\bar z=\tfrac12\bigl[\bar\phi(d-h)+\bar\phi(d+h)\bigr]$ に (2) を代入すると

$$
\bar\Phi(d,h,\sigma)=G\!\left(\frac d\sigma,\ \frac h\sigma\right),
\qquad G(x,y)=\tfrac12\Bigl[\bar\phi_Q(x-y)+\bar\phi_Q(x+y)\Bigr],\quad \bar\phi_Q(s)=2Q(s)\bigl(1-Q(s)\bigr)
$$

$G$ はノイズの**形状** $q$ だけで決まる固定の 2 変数関数であり、**振幅 $\sigma$ は $G$ の中に残らない**。
これが全体の要である。

**(4) 0 次同次性。** (3) から直ちに

$$
\bar\Phi(\alpha d,\ \alpha h,\ \alpha\sigma)
=G\!\left(\frac{\alpha d}{\alpha\sigma},\ \frac{\alpha h}{\alpha\sigma}\right)
=G\!\left(\frac d\sigma,\ \frac h\sigma\right)=\alpha^{0}\,\bar\Phi(d,h,\sigma)
$$

3 つ組 $(d,h,\sigma)$ を**一緒に**動かしたときだけ 0 次同次である点に注意する。
どれか 1 つだけを動かせば当然応答は変わる。

**(5) $(w,b)$ から $d$ へ。** $d_k=w_k^{\mathsf T}z^{(l-1)}+b_k$ は $(w_k,b_k)$ について 1 次同次なので、
$z^{(l-1)}$ を固定すれば $(w_k,b_k)\to\alpha(w_k,b_k)$ で $d_k\to\alpha d_k$ となる。

以上より、出力を不変に保つ変換は次で与えられる:

$$
\boxed{\ \ \mathcal G:\quad (w_k,\ b_k,\ \sigma_k,\ h_k)\ \longmapsto\ \alpha_k\,(w_k,\ b_k,\ \sigma_k,\ h_k)
\qquad \alpha_k>0,\ \text{ユニットごとに独立}\ \ }
$$

ゲージ群は $\mathcal G\cong(\mathbb R_{>0})^{\sum_l H_l}$ である。

### 4.2 局所性と厳密性

第 4.1 節は期待応答 $\bar\Phi$ の話だったが、実は**もっと強いことが言える**。

**(a) 厳密性: 期待値ではなくサンプルパスごと。** 乱数を固定し、ノイズ実現値を $\eta=\sigma u$
（$u$ は固定した標準化ドロー）と書くと、発火を決めているのは 1 本の不等式だけである:

$$
\mathbf 1[\,d+\sigma u > h\,]
$$

ゲージ変換の下でこれは

$$
\mathbf 1[\,\alpha d+\alpha\sigma u > \alpha h\,]
=\mathbf 1[\,\alpha\,(d+\sigma u-h) > 0\,]
=\mathbf 1[\,d+\sigma u > h\,]\qquad(\alpha>0)
$$

$\alpha>0$ が不等号の向きを保つので、**$z$ はビット単位で同一**になる。
期待値が一致するのではなく、個々のスパイクが一致する。
だからこの不変性はサンプルレベルのネットワークでも厳密に成り立つ。
実測 $\max|dy|=0.00\times10^{0}$（層 1 のみ／層 2 のみ／両層すべて）。

**(b) 局所性: 補償がユニット内で完結する。** 上の打ち消しは同じユニットの中だけで起きるので、
中間表現が動かない（$dz^{(1)}=0$）。これが第 4.1 節 (5) の「$z^{(l-1)}$ を固定すれば」という
条件を層について帰納的に保証している。
ReLU の正斉次性が「隣接層の共謀」による大域対称性であるのと対照的に、
NNN のこれは**真の局所ゲージ対称性**である。

### 4.3 何が冗長で何が実体か

#### 次元の数え上げ

ユニット $k$ のパラメータは $(w_k,b_k,\sigma_k,h_k)$ の $\dim(w)+3$ 個ある。
これに対して、関数として外から観測できるのは比だけであり、たとえば

$$
\left(\frac{w_k}{\sigma_k},\ \frac{b_k}{\sigma_k},\ \frac{h_k}{\sigma_k}\right)
$$

の $\dim(w)+2$ 個で尽きる。すなわちパラメータから関数への写像は多対一で、
**ファイバー（ゲージ軌道）はユニットあたり厳密に 1 次元**である。

この 1 次元は好きに使ってよい。$\alpha_k=1/\sigma_k$ と選べば、
学習された場を全ユニットで $\sigma_k\equiv1$ に潰しても出力はビット単位で同一である
（`idea_duality.md` §12.3 の実測）。これが「単一文脈では場は 100% ゲージ」の内容である。

裏を返すと、次の言明は**ネットワークについての言明になっていない**:

> 「ユニット $k$ の $\sigma_k$ は 0.05 だから、ほとんど黙っている。電源を落としてよい。」

同じネットワークが $\sigma_k=100$ とも書けるからである。

#### 不変量の完全系

ユニットあたり、意味のある量は次の 3 つで尽きる:

| 不変量 | 直観的な意味 | 次元 |
|---|---|---|
| 重みの方向 $\hat a_k=a_k/\lVert a_k\rVert$ | **何に**反応するか | $\dim(a)-1$ |
| 実効ゲイン $\gamma_k=\lVert a_k\rVert/\sigma_k$ | **どれだけ鋭く**反応するか | 1 |
| しきい値比 $h_k/\sigma_k$ | 不感帯が**ノイズ何個分**か | 1 |

合計 $\dim(a)+1$ で、パラメータ数 $\dim(a)+2$ からゲージ 1 次元を引いた数にちょうど一致する。

交差率もこの 3 つから組み上がる。$d_k/\sigma_k=\gamma_k\,(\hat a_k\cdot[z,1])$ なので

$$
\nu_k=G\bigl(\gamma_k\,(\hat a_k\cdot[z,1]),\ h_k/\sigma_k\bigr)
$$

**$\nu$ が参加度の尺度として使えるのは、それが不変量だけで書ける量だからである。**

#### 測ってよい量・いけない量

| ゲージ**不変**（測ってよい） | ゲージ**依存**（測ってはいけない） |
|---|---|
| 交差率 $\nu_k=\mathbb E[z_k]$ | $\sigma_k$ の絶対値 |
| 比 $d_k/\sigma_k$、$h_k/\sigma_k$ | $\lVert w_k\rVert$ 単独 |
| 実効ゲイン $\gamma_k=\lVert[w_k,b_k]\rVert/\sigma_k$ | $\mathrm{mean}(\mathcal P)$ |
| 重みの**方向** $\hat a_k=a_k/\lVert a_k\rVert$ | $\cos(\mathcal P_A,\mathcal P_B)$（場の重なり） |
| 文脈間の相対場 $\tilde s_{r,k}=\log\sigma_{r,k}-\frac1R\sum_{r'}\log\sigma_{r',k}$ | ノイズ予算 $\sum_k\sigma_k^2$ |
| ネットワーク出力 $y$ そのもの | 上記以外の場の統計量一般 |

**実測による警告**（`idea_duality.md` §12.6）: 学習済みネットワークにゲージ変換を施したところ、
出力は $\max|dy|=0.00\times10^0$（ビット単位で不変）のまま、
overlap は $0.8305\to0.8720$、$\mathrm{mean}(\mathcal P)$ は $0.5016\to1.1033$ と大きく動いた。
不変な比 $\sigma_{B,k}/\sigma_{A,k}$ の変化は $1.19\times10^{-7}$ にとどまった。
**ネットワークが何もしていないのに、指標だけが動いたのである。**

したがって、$\lambda_{\mathrm{sparse}}\,\mathrm{mean}(\mathcal P)+\lambda_{\mathrm{overlap}}\cos(\mathcal P_A,\mathcal P_B)$
という形の正則化は、タスク損失を一切悪化させずに正則化項だけを下げるゲージ方向を持つ。
最適化はその方向を必ず見つけるので、**この正則化は「場を疎にする」のではなく「単位を取り替える」**。
同じ罠は「$\sigma$ が小さいユニットの電源を落とす」という消費電力ゲーティングの議論にも当てはまる。
測るべきは実効ゲイン $\gamma_k$ か交差率 $\nu_k$ である。

### 4.4 ゲージ恒等式（Euler / Noether 関係）

対称性の生成子に沿った損失の変化はゼロでなければならない。$\alpha_k=e^{\epsilon}$ の 1 次で

$$
\boxed{\ \frac{\partial L}{\partial\log\sigma_k}
+\left(w_k^{\mathsf T}\frac{\partial L}{\partial w_k}+b_k\frac{\partial L}{\partial b_k}\right)=0\ }
$$

（$h$ も同時にスケールする規約のとき。$h$ を独立に持つ場合は左辺に $h_k\,\partial L/\partial h_k$ が加わる。）

これは第 5.8 節の $\sigma$ 勾配と厳密に整合する。$\hat\delta_k=\hat g_k\phi_T'(d_k)$ とおくと
$w_k^{\mathsf T}g_{w_k}+b_kg_{b_k}=\langle\hat\delta_k d_k\rangle$ であり、
$\sigma$ 勾配は $\langle\hat\delta_k\cdot(-d_k/\sigma_k)\rangle\cdot\sigma_k=-\langle\hat\delta_kd_k\rangle$
なので符号が厳密に反転する。実測残差は $8.15\times10^{-9}$（層 1）、$1.86\times10^{-9}$（層 2）。

活性側でも同じ関係が Euler の定理として現れる（`idea_consolidation.md` §7.5）:

$$
\sigma_k\frac{\partial\bar z_k}{\partial\sigma_k}
=-\left(d_k\frac{\partial\bar z_k}{\partial d_k}+h_k\frac{\partial\bar z_k}{\partial h_k}\right)
$$

### 4.5 パラメータ空間の 3 分解

ユニット $k$ の $(a_k,\sigma_k)$ が張る空間は、次の 3 成分に**正しく**分解される
（`idea_duality.md` §12.3。当初の「$\theta$ = 計算、$\mathcal P$ = ルーティング」という直交 2 系統の
描像は不正確として撤回された）:

1. **重みの方向** $\hat a_k$ — $\dim(a_k)-1$ 次元。$\theta$ のみが動かせる**実体**。
2. **共通スケール** — 1 次元。**ゲージ自由度**（冗長）。
3. **文脈間の相対 $\sigma$** — 複数文脈がある場合のみ存在する、**ゲージ不変な実体**。

したがって:

> $\mathcal P$ が動かせるのは各ユニットの**動径 1 次元だけ**であり、$\mathcal P$ の作用は $\theta$ の作用の
> 部分空間である。両者は直交しない。

単一文脈では冗長性は 100% である（$\alpha_k=1/\sigma_k$ をとれば学習された場を $\sigma\equiv1$ に潰しても
出力はビット単位で同一）。2 文脈では 128 個のパラメータのうち 64 個がゲージ、残り 64 個
（比 $\sigma_{B,k}/\sigma_{A,k}$）が実体である。

**正しい統一的言明**（`idea_duality.md` §4）:

> $\theta$ と $\mathcal P$ は別々の学習機構で動く 2 つの系ではない。同一の credit $\hat g$ を、外積の相手として
> $z_{\mathrm{prev}}$ に当てれば $\theta$ の勾配、$-d/\sigma$ に当てれば $\mathcal P$ の勾配が出る。
> **1 つの前向き共分散 credit に、2 人の消費者がいる。**

### 4.6 $(\sigma,h)$ 平面の幾何: ゲージ軌道と消滅経路

$(\log\sigma_k,\log h_k)$ 平面で考えると、2 つの操作は**直交する 2 方向**になる。

| 操作 | 平面での方向 | 不変量 $h/\sigma$ | ものさしで読むと | 効果 |
|---|---|---|---|---|
| **ゲージ** $\alpha$ | $(+1,+1)$ | 不変 | 目盛りと閾値を**一緒に**伸ばす | 読みは変わらない。出力も $\nu$ も不変 |
| **動員ダイヤル** $\rho$ | $(+1,-1)$ | $\rho^{-2}$ で変化 | 目盛りを縮めながら閾値を**広げる** | 閾値が「ノイズ何個分も先」へ遠のき、やがて届かなくなる |

すなわち **$\rho$ はゲージに横断的な座標であり、$\alpha$ はゲージに沿った座標である**。
これが「$\rho$ の連動の向きが学習時の $h=c_h\sigma$ と逆になる」ことの幾何的な意味である。
$\rho$ がユニットを殺せるのは、まさにそれがゲージ変換では到達できない方向だからである。
逆に、いくらゲージ変換を重ねてもユニットは決して黙らない。目盛りを変えているだけだからである。

対応して、$\sigma_k\to0$ の極限は**接近経路に依存する**:

- **ゲージ軌道**（$\alpha_k\to0^+$）: $\lim_{\alpha_k\to0^+}z_k(\alpha_k)\neq z_k(0)$。$h/\sigma$ が一定のまま
  なので $\nu$ は変わらず、極限で**特異**。
- **消滅経路**（$w_k,b_k$ 固定、$\rho_k\downarrow$）: ほとんど至るところで
  $\lim_{\rho_k\to0^+}\nu_k=0=\nu_k(\rho_k{=}0)$。**連続な終端**。

第 1 隠れ層では $h$ 固定・$\sigma\downarrow$（水平経路）でも消滅経路になるが、深い層では
上流ゆらぎのために $h\uparrow$ を伴う経路（$\rho$）でなければならない（第 3.4 節）。

### 4.7 ゲージが存在する条件: 3 つの体制

文書間で「$\sigma$ は冗長か、本物の自由度か」という主張が食い違って見えるが、
それは**どの体制にいるか**の違いに過ぎない。以下が完全な整理である。

| 体制 | $h$ の扱い | $\theta$ | ものさしで言えば | ゲージ | $\sigma$ の身分 | 該当文書 |
|---|---|---|---|---|---|---|
| **(a) 連動** | $h_k=c_h\sigma_k$（または $h_k$ が per-unit 自由） | 学習 | 「閾値はノイズ $c_h$ 個分」とだけ決めた。**目盛りの大きさは未定** | **存在** | 動径 1 次元のみ、$\theta$ で代替可能 | `idea_duality.md` §12 |
| **(b) 固定** | $h$ は大域ハイパーパラメータ | 学習 | 「閾値は必ず 0.2」と決めた。**目盛りが一意に定まる** | **不在** | 本物の自由度 | `draft_nce.md`, `idea_ca.md` |
| **(c) 凍結** | どちらでもよい | **凍結** | **ものさしを持ち替える自由がない** | **自動固定** | 本物の自由度 | `idea_reservoir.md` §12 |

3 つの体制の差は、**$h$ の規約がゲージ固定条件になっているかどうか**で説明できる。
ゲージ固定条件とは、各ゲージ軌道と**ちょうど 1 点で交わる**条件のことである。

- **$h$ を大域定数 $h_0$ に固定する規約は、完全なゲージ固定である。** 軌道
  $\{(\alpha w_k,\alpha b_k,\alpha\sigma_k,\alpha h_k)\}_{\alpha>0}$ 上で $\alpha h_k=h_0$ を満たす
  $\alpha$ は $\alpha=h_0/h_k$ ただ 1 つだから、各軌道から代表元が一意に選ばれる。
  残留ゲージはなく、$\sigma_k$ は本物の座標になる（体制 (b)）。
- **連動規約 $h_k=c_h\sigma_k$ はゲージ固定ではない。** 条件 $\alpha h_k=c_h\,\alpha\sigma_k$ は
  $\alpha$ が消えて $h_k=c_h\sigma_k$ に帰着するので、軌道上で恒真か恒偽のいずれかである。
  すなわちこれはゲージ**不変な部分多様体への制限**であり、ゲージはそのまま生き残る（体制 (a)）。
  $h_k$ を per-unit の自由パラメータとして持つ場合も同様にゲージは残る。
- **$\theta$ の凍結もゲージ固定の一種である。** ゲージ変換は $w_k,b_k$ の同時スケールを要求するので、
  $\theta$ を動かせないなら $\alpha_k=1$ の恒等変換しか実現できない（体制 (c)）。
  したがってリザバー的な運用では $\sigma$ のスケールは冗長でなくなり、
  $\sigma$（過渡の richness）と $h$（on/off・休止）を 2 枚の独立な場として持つことが原理的に正当化される。

**ゲージ固定は「単位系を 1 つ選ぶ」ことに相当する。** 固定してしまえば冗長だった座標は意味を持つが、
その意味は**選んだ固定条件に相対的**である。「この棒は 1.7 だ」と言えるのはメートルを選んだからで、
1.7 という数そのものが棒の性質なのではない。同様に、体制 (b) で「$\sigma^*=0.4$ が最適」と
言えるのは $h=0.2$ を固定したからであって、$0.4$ という数がノイズの性質なのではない。
だから報告の際は、単位に依らない比 $h/\sigma^*$（この例では $0.5$）を併記するのが正しい。

**体制 (b) に固有の落とし穴**: $\sigma$ 勾配の推定量 $\langle\hat g\,\phi_T'\,(-d/\sigma)\rangle$ は
連動 $h\propto\sigma$ の下でのみ厳密である。ところが実測では、この推定量は $h$ 固定でも
Euler 恒等式を**恒等的に満たしてしまう**（数値が完全に同一）。つまり
**推定量がモデルの持たない対称性を強制している**ことになり、これはサンプル数で消えない構造バイアスである。
体制 (b) で場を学習するときは、この点を明示的に扱う必要がある。

現時点で未決の争点は次の二択である（`idea_duality.md` §12.7）:

> 「厳密な推定量 + ゲージ冗長（連動 $h=c_h\sigma$）」 対 「本物の自由度 + 偏った推定量（$h$ 固定）」

擁護は強い順に、(1) ハードウェアでは $\sigma$ が安い座標であり数学的に冗長でも意味がある、
(2) 形状パラメータ（歪度・裾指数）は重みで代替できない真に新しい自由度である（第 5.8 節の一般化定理）、
(3) 複数文脈での相対場はゲージ不変な実体である。

### 4.8 実務上の帰結（禁止事項）

1. **$\mathrm{mean}(\mathcal P)$ や $\cos(\mathcal P_A,\mathcal P_B)$ を目的関数・評価指標にしない。**
   使うなら $\gamma_k=\lVert a_k\rVert/\sigma_k$ か $\nu_k$。
2. **「$\sigma$ が小さい = 参加していない」と読まない。** 参加は $\nu_k$ で測る。
3. **時間軸上で $\sigma$ の値そのものを問わない。** `idea_coding.md` はこの理由から
   ゲージ不変な無次元量 $\Gamma=|\dot d_k|\Delta t/\sigma$（1 ステップあたりの決定論的変化 ÷ ノイズ std）を
   制御変数に採用した。分子・分母が同率に伸縮するのでゲージ不変である。
4. **ユニットを不活化したいときはゲージ変換ではなく $\rho$（消滅経路）を使う。**
5. **ネットワークレベルの有限差分を測定器として使わない**（`idea_duality.md` §9.7 の負の結果）。
   $\mathbb E[L]=(\mathbb E[y]-t)^2+\mathrm{Var}(y)$ であり $\sigma$ は分散項も動かすが、
   $\sigma$ 勾配は信号項だけを推定するため一致しない。

**規則 2 は全体制で成り立つが、成り立つ理由が体制によって違う**（第 4.7 節）。混同しないこと。

- **体制 (a)**: $\sigma$ の絶対値は純粋なゲージ方向であり、文字どおり何も意味しない。
- **体制 (b)(c)**: $\sigma$ は本物の自由度である。それでも参加度の尺度にはならない。理由は 2 つあり、
  いずれもゲージとは独立である。
  (i) 参加は $d/\sigma$ と $h/\sigma$ の**両方**で決まる。$\bar\Phi$ はバンプなので、
  $h/\sigma$ が小さくても $|d|/\sigma$ が大きければ $\nu\approx0$ になる。$\sigma$ 単独では
  動作点の情報が落ちる。
  (ii) 層 $l\ge2$ では $\sigma_k=0$ としても上流ゆらぎで交差が残る（第 3.4 節）。

つまり「参加度は $\nu$ で測る」は例外のない規則である。体制 (a) では $\sigma$ が**意味を持たない**から、
体制 (b)(c) では $\sigma$ が**必要な情報を持っていない**から、というだけの違いである。

## 5. 学習: 前向き揺らぎ共分散による credit assignment

### 5.1 問題設定

NNN は backprop で学習できる。ネットワークは層の合成、読み出しは線形、各交差活性は期待応答と
局所微分を順伝播から与えるからである。しかし backprop は順方向重みの転置 $W^{(l)\mathsf T}$ を経由する
逆向きパス（重み輸送）を要求し、これが NNN のニューロモルフィック計算としての妥当性を損なう。

読み出し層の勾配は $\bar{\mathbf y}_n$ が $W^{(L)}$ に線形であることから厳密かつ局所に書ける:

$$
\frac{\partial L}{\partial W^{(L)}}=\frac1N\sum_n \mathbf e_n\,\bar{\mathbf z}^{(L-1)\mathsf T}_n,
\qquad \mathbf e_n=2(\bar{\mathbf y}_n-\mathbf t_n)
$$

よって問題は隠れ層の credit assignment、すなわち
**「$\partial L/\partial z^{(l)}_i$ を forward 統計からどう推定するか」**に帰着する。
SGD や Adam などのオプティマイザは重みごとに閉じるので重み輸送を生じない。

記法: 入力 $n$、サンプル $m$ における量を $(\cdot)_{(m,n)}$、$T$ サンプル平均を上付きバー、
全サンプル・全入力の平均を $\langle\cdot\rangle_{m,n}$ と書く。
per-sample 損失は $L_{(m,n)}=\lVert\mathbf y_{(m,n)}-\mathbf t_n\rVert^2$。

### 5.2 三要素則としての一般形

提案する学習則の族はすべて、シナプス（前ユニット $j$ → 後ユニット $i$）ごとの**3 因子の積の平均**として書ける:

$$
\boxed{\
\frac{\partial L}{\partial W^{(l)}_{ij}}
\;\approx\;
\Bigl\langle\,
\underbrace{\hat g^{(l)}_{n,i}}_{\text{第 3 因子（誤差 credit）}}
\;\cdot\;
\underbrace{\phi_T'\bigl(d^{(l)}_{n,i}\bigr)}_{\text{後シナプス（局所傾き）}}
\;\cdot\;
\underbrace{z^{(l-1)}_{n,j}}_{\text{前シナプス（発火）}}
\,\Bigr\rangle_{m,n}\ }
$$

- **前シナプス因子** $z^{(l-1)}_j$: 前ユニットの二値・確率的発火。Hebb 則の前シナプス項。
- **後シナプス因子** $\phi_T'(d^{(l)}_i)$: 後ユニット自身の前向き揺らぎから局所推定される局所感度
  （KDE slope = 交差計数）。前因子との積 $\phi_T'\,z$ が eligibility trace にあたる。
- **第 3 因子** $\hat g^{(l)}_i\approx\partial L/\partial z^{(l)}_i$: 後ユニットに届く credit。
  **この作り方だけが手法ごとに異なる。**

既存の三要素則が第 3 因子の由来を weight transport や専用フィードバック経路に頼るのに対し、
本モデルは第 3 因子を**前向きノイズの共分散から作る**点が新規性である。
また第 3 因子は大域スカラー（報酬・神経修飾の neo-Hebbian 型）ではなく、
ユニットごとのベクトル credit を配る型（per-neuron error 型）である。

**この式が本稿の索引として使える。** 以下の節はすべて「3 因子のどれをどう作るか」の話である:

| 因子 | どこで作るか | 差し替えると何になるか |
|---|---|---|
| 第 3 因子 $\hat g$ | §5.3（スカラー共分散）／**§5.4（ミラー再帰・正典）**／§5.6（読み出しも共分散） | 手法の系譜そのもの |
| 後シナプス $\phi_T'$ | §2.4（KDE slope）。解析形 $\bar\phi'$ と交換可能（§5.9 のアブレーション） | 交換しても性能はほぼ不変 |
| 前シナプス $z^{(l-1)}$ | 順伝播そのもの。**ここを $-d/\sigma$ に差し替えると場の勾配になる**（§5.8） | 重みの学習 → 場の学習 |

最後の行が第 4.5 節の「1 つの credit に 2 人の消費者がいる」の正体である。
$\theta$ と $\mathcal P$ は別々の学習機構ではなく、同じ $\hat g\,\phi_T'$ に何を掛けるかの違いにすぎない。

**留保**: 第 3 因子はシナプスにとっては局所だが、その計算自体は上位層の $\hat\delta^{(l+1)}$ を要する
層方向の再帰である。シナプス局所性（更新が 3 因子の積で書けること）と、誤差ベクトルを運ぶ
層間の情報伝達は別レベルの話として整理する。

第 4.5 節で述べたように、**同じ第 3 因子を $-d/\sigma$ に当てれば場の勾配になる**（第 5.8 節）。

### 5.3 スカラー共分散 credit（`cov_only` / `cov_deriv`）とその消えないバイアス

最も単純な構成は、各ユニットの自発的揺らぎに対する損失の回帰である:

$$
\hat g^{(l)}_{n,i}=\frac{\mathrm{Cov}_T\bigl(L_n,\ z^{(l)}_{n,i}\bigr)}
{\mathrm{Var}_T\bigl(z^{(l)}_{n,i}\bigr)+\varepsilon}\;\approx\;\frac{\partial L_n}{\partial z^{(l)}_{n,i}}
$$

必要な統計量はユニットあたり 4 つのサンプル平均 $\overline L_n,\ \overline z_{n,i},\ \overline{Lz}_{n,i},\ \overline{z^2}_{n,i}$
だけで、いずれもサンプルが得られるたびにオンラインで蓄積できる:

$$
\mathrm{Cov}_T(L_n,z_{n,i})=\overline{Lz}_{n,i}-\overline L_n\,\overline z_{n,i},\qquad
\mathrm{Var}_T(z_{n,i})=\overline{z^2}_{n,i}-\overline z_{n,i}^{\,2}
$$

これに $\phi_T'$ を乗じたものが `cov_deriv`、乗じないものが `cov_only` である。

**`cov_deriv` は node perturbation を NNN に組み入れたもの**と解釈できる。古典的な node perturbation は
学習のためだけに独立な摂動を各ユニットに注入するが、ここでは交差活性が forward ノイズによって
既に揺らいでいるため、**自発揺らぎ $z-\bar z$ 自体が摂動の役割を果たし、摂動専用のプロセスが不要**である。

#### per-input 中心化が決定的

共分散は**入力 $n$ を固定した $T$ サンプル上で**取らねばならない。全入力でプールすると、
入力間の損失変動が混入して局所勾配の近似にならない。実測: per-input 0.035 対 pooled 0.42
（アブレーション中で最大の劣化。学習がほぼ成立しない）。

#### 消えないバイアス

$\mathrm{Cov}(L,z_i)/\mathrm{Var}(z_i)$ は、ユニット $i$ の下流に広がるネットワーク全体の効果を
スカラー損失 $L$ に潰した**単変量回帰**であり、複数ユニットが同時に揺らぐときの交互作用を線形化して
無視する。この線形化誤差は有限サンプル効果ではないため、**$T$ を増やしても消えない**。
実測では、学習途中の隠れ層で厳密勾配との cosine が 0.19 まで低下する。

この情報の潰れを回避するには、スカラー $L$ ではなく**計算グラフの構造に沿った量**と共分散を取る必要がある。

### 5.4 構造化共分散 credit（`cov_jac`）: backpropagation の再構成 【正典】

#### (a) 重みミラー

前活性は活性に対して厳密に線形（$\mathbf d^{(l+1)}=W^{(l+1)}\mathbf z^{(l)}+\mathbf b^{(l+1)}$）である。
よって入力を固定したときの $T$ サンプル揺らぎの単回帰係数は、順方向重みそのものを与える:

$$
\boxed{\ \hat W^{(l+1)}_{ji}
=\frac{\sum_n\mathrm{Cov}_T\bigl(d^{(l+1)}_{n,j},\ z^{(l)}_{n,i}\bigr)}
{\sum_n\mathrm{Var}_T\bigl(z^{(l)}_{n,i}\bigr)+\varepsilon}\;\approx\;W^{(l+1)}_{ji}\ }
$$

**直観**: ユニット $i$ の発火が 1 単位揺れたとき、下流の前活性 $d_j$ は $W_{ji}$ だけ動く。
これは近似ではなく定義（線形結合）である。だから「$z_i$ が揺れたとき $d_j$ がどれだけ動いたか」を
測って割り算すれば、$W_{ji}$ がそのまま出てくる。**ネットワークは自分の重みを、自分の揺らぎを
観察することで読み出せる。** 転置行列にアクセスする必要はない。

これはノイズ注入下の入出力活動の相関から重み行列を推定する weight mirror の応用だが、
**専用のノイズ注入フェーズを設ける代わりに、NNN が forward パスで既に生成している揺らぎを
そのまま利用する**点が異なる。既存手法が「測定のために揺らす」のに対し、
NNN は**もともと揺れている**ので、測定が推論に相乗りできる。
各ユニットの交差ノイズは入力を固定すれば独立に揺らぐため、この回帰に交絡はなく
高精度な推定が期待できる（実測 $\mathrm{corr}\ge0.999$）。

実装上の要点 3 つ:

1. **相関は前活性 $d^{(l+1)}$ と取る。** $\mathbf z^{(l)}$ に厳密に線形なので回帰係数がそのまま $W_{ji}$ を与える。
   二値の $z^{(l+1)}$ と相関を取ると退化する（実測 $\mathrm{corr}\approx0.14$）。
2. **分子・分母を全入力で総和してから 1 回だけ割る**（重みは入力に依存しないので、
   1 更新ステップに含まれる全 $NT$ サンプルを 1 つの推定に使う。入力ごとに比を取って平均するより低分散）。
3. **EMA + Kolen–Pollack 追従**（第 5.5 節）。

#### (b) 誤差の再帰伝播

$\hat W$ と $\phi_T'$ を用いれば、backpropagation と同形の再帰で出力誤差を伝播できる:

$$
\boxed{\
\hat{\boldsymbol\delta}^{(L-1)}_n=\Bigl(\hat W^{(L)\mathsf T}\mathbf e_n\Bigr)\odot\phi_T'\bigl(\mathbf d^{(L-1)}_n\bigr),
\qquad
\hat{\boldsymbol\delta}^{(l)}_n=\Bigl(\hat W^{(l+1)\mathsf T}\hat{\boldsymbol\delta}^{(l+1)}_n\Bigr)\odot\phi_T'\bigl(\mathbf d^{(l)}_n\bigr)\ }
$$

勾配推定は外積 $\hat G^{(l)}=\langle\hat{\boldsymbol\delta}^{(l)}\mathbf z^{(l-1)\mathsf T}\rangle_{m,n}$ で求まる。
**誤差逆伝播法との唯一の違いは $W^{\mathsf T}$ が前向き摂動から推定された $\hat W^{\mathsf T}$ に置き換わっている点だけ**である。

backprop が連鎖律で乗じていく層間ヤコビアンは、線形結合部分
$\partial\mathbf d^{(l+1)}/\partial\mathbf z^{(l)}=W^{(l+1)}$ と活性化の局所微分 $\partial z/\partial d$ の
2 因子からなる。上の再帰はこの 2 因子をそれぞれ forward 統計からの推定値 $\hat W$ と $\phi_T'$ に
置き換えたもの、すなわち**前向き摂動によるヤコビアンの推定に基づく backpropagation の再構成**である。

`cov_deriv` と異なり credit をスカラー $L$ に潰さないため線形化バイアスを持たず、
誤差はサンプル増加で低減できる。計算量は層幅 $K$ に対し $O(K^2)$（`cov_deriv` は $O(K)$）だが、
依然として forward-only かつオンライン蓄積可能である。

#### 実装（正典擬似コード）

```
1 回の forward で捕捉:  d^(l), z^(l) ∈ {0,1}^[N,T,H],  y_samples [N,T,Dout],  ȳ [N,Dout]
slope^(l)  = mean_T(xor2 - xor1) / (2h)            # KDE 局所傾き
Ŵ_meas^(l) = cov_weight(d^(l), z^(l-1), pool=True) # 重みミラー測定
Ŵ^(l)      ← β_EMA Ŵ^(l) + (1-β_EMA) Ŵ_meas^(l)   # β_EMA = 0.9（保持率）
e          = 2(ȳ - t)
a^(L-1)    = e @ Ŵ^(L)                             # 読み出しミラー経由
a^(l)      = (a^(l+1) ⊙ mean_T slope^(l+1)) @ Ŵ^(l+1)
δ^(l)      = a^(l) ⊗ slope^(l)                     # [N,T,H]
gW^(l)     = einsum("nto,nti->oi", δ^(l), z^(l-1)) / (N·T)
gW^(L)     = eᵀ z̄^(L-1) / N                        # 読み出しは厳密勾配
Adam(no_grad) で更新;  Ŵ^(l) ← Ŵ^(l) - (適用したデクリメント)   # Kolen–Pollack
```

### 5.5 ミラーの保守: EMA + Kolen–Pollack + 入力プーリング

ミラーは**動く標的**（$W$ 自身が毎ステップ更新される）を追う必要がある。3 つの機構を併用する。

1. **EMA 平滑化** $\hat W\leftarrow\beta_{\mathrm{EMA}}\hat W+(1-\beta_{\mathrm{EMA}})\hat W_{\mathrm{meas}}$。
   $\beta_{\mathrm{EMA}}=0.9$（RL online では混入率 0.1、定常分散は単発測定の約 1/19）。
2. **Kolen–Pollack 追従**: オプティマイザが実際に適用した既知の更新量 $\Delta W$ をミラーに直接加算する
   （$\hat W\leftarrow\hat W-\Delta W_{\mathrm{applied}}$）。これにより共分散測定は静的なオフセットの補正だけを担う。
   実装では `ManualOpt.update()` が適用デクリメントを返す。
3. **入力プーリング**: $\hat W=(\sum_n\mathrm{Cov}_T)/(\sum_n\mathrm{Var}_T)$。

この 3 点は「あれば良い」実装詳細ではない。RL のようにバッチサイズ $N=1$ のオンライン設定では、
**per-step の単発ミラー推定が学習の律速そのものになる**ことが判明している
（`idea_rl.md` §23.5→§23.9: credit cosine 0.44 で頭打ちだったものが、EMA + KP の移植だけで解決した）。

### 5.6 読み出し誤差の共分散推定（`cov_jac_full`）と歪度バイアス

`cov_jac` で解析的に計算している唯一の量は読み出し誤差 $\mathbf e_n=2(\bar{\mathbf y}_n-\mathbf t_n)$ である。
これは重み輸送とは無関係だが、この最後の損失微分も forward 統計に置き換えられる。
サンプル出力 $y_{(m,n)}$ は forward 摂動で揺らぐ連続量なので、隠れ層と同じ入力ごとの回帰が適用できる:

$$
\hat g_{y,n}=\frac{\mathrm{Cov}_T(L_n,\ y_n)}{\mathrm{Var}_T(y_n)+\varepsilon}\;\approx\;e_n
$$

**このときネットワークが観測するのは per-sample のスカラー損失のみであり、
解析的な損失微分はどこにも現れない。** これが `cov_jac_full` の存在意義であり（性能は `cov_jac` と同等）、
主張は性能ではなく**構成上の完全性**にある。

#### 歪度バイアス

$L=(y-t)^2$ は $y$ の 2 次関数なので、母集団の回帰係数は厳密には

$$
\frac{\mathrm{Cov}(L,y)}{\mathrm{Var}(y)}=2\bigl(\mathbb E[y]-t\bigr)+\frac{\mathbb E[\epsilon^3]}{\mathrm{Var}(\epsilon)},
\qquad \epsilon=y-\mathbb E[y]
$$

第 2 項は読み出し揺らぎの**歪度に比例する定数バイアス**であり、$y$ が二値発火の重み付き和であるため
一般に 0 でなく、$T$ を増やしても消えない。SGD では勾配の縮小とともに歩幅も縮むため露見しにくいが、
勾配スケールを正規化する Adam はこれを増幅し続け、学習後期に解を漂流させる
（実測: epoch 200 付近まで正常に収束した後、epoch 500 以降 0.024 まで漂流）。

#### 2 つの補正

| 補正 | 式 | 追加コスト | 厳密性 |
|---|---|---|---|
| **3 次モーメント補正**（既定） | $\hat g_y=(\mathrm{Cov}_T(L,y)-m_3)/\mathrm{Var}_T(y)$、$m_3=\overline{y^3}-3\bar y\,\overline{y^2}+2\bar y^{\,3}$ | 累算 1 本（$\overline{y^3}$） | 2 次損失に対して厳密 |
| **対称プローブ** | $\hat g_y=\mathrm{Cov}_T(L(y+\xi),\xi)/\mathrm{Var}_T(\xi)$、$\mathbb E[\xi^3]=0$ | 累算追加なし、**外部摂動が必要** | 任意の滑らかな損失で不偏 |

**3 次モーメント補正を既定とする。** 観測量 $(L,y)$ だけで完結するため付加的な摂動の注入が不要で、
「専用の摂動フェーズを持たない」という NNN の主張を損なわないからである。
実測: m3 補正 0.00057（backprop 0.00057 と一致）、対称プローブ 0.00090、補正なし 0.0241。
バイアス項そのものも直接検証されており、観測バイアスは予測項 $m_3/\mathrm{Var}$ と相関 0.998 で一致し、
収束付近ではバイアスの rms（0.062）が真の誤差信号の rms（0.049）を上回った。

### 5.7 対角近似バイアスと周期ノイズ場による根治

$\hat W$ の単回帰は層内の活性が無相関であることを仮定した**対角近似**である。厳密には

$$
\boxed{\ \hat W_{ji}=W_{ji}+\sum_{k\neq i}W_{jk}\,c_{ki},
\qquad c_{ki}=\frac{\sum_n\mathrm{Cov}_T(z_k,z_i)}{\sum_n\mathrm{Var}_T(z_i)}\ }
$$

行列形では $\hat W=W\,\mathrm{Cov}(z,z)\,\mathrm{diag}(\mathrm{Var}(z))^{-1}$。
これは**サンプル数で消えない方向性バイアス**である。

**直観**: ミラーは「$z_i$ が揺れたとき $d_j$ がどれだけ動いたか」を測る。ところが $z_i$ が揺れるとき
$z_k$ も一緒に揺れていたら、$z_k$ 経由の寄与 $W_{jk}$ まで $\hat W_{ji}$ の勘定に入ってしまう。
$c_{ki}$ は「$z_i$ が動いたとき $z_k$ がどれだけ連れて動くか」であり、
**近傍の重みが $c_{ki}$ の重みで漏れ込む**。サンプルを増やしても $c_{ki}$ 自体は縮まないので、
このズレは消えない。

#### 層内相関の起源

注入ノイズ自体はユニット間独立だが、層内活動には**学習後に相関が創発する**。1 次近似で

$$
\mathrm{Cov}_T(z_k,z_i)\approx\bar\phi'_k\bar\phi'_i\,\mathrm{Cov}_T(d_k,d_i),
\qquad
\mathrm{Var}_T(z_i)\approx(\bar\phi'_i)^2\mathrm{Var}_T(d_i)+v_i
$$

（$v_i\approx\bar\phi_i(1-\bar\phi_i)$ は私的なベルヌーイ分散、最大 0.25）、
$\mathrm{Cov}_T(d_k,d_i)=\sum_m W_{km}W_{im}\mathrm{Var}_T(z^{(l-1)}_m)$ は上流からの共有駆動。相関係数は

$$
c_{ki}\approx\frac{\text{共有駆動}}{\text{共有駆動}+\text{私的ノイズ}}
$$

の形になる。実測ではこの相関は**ランク 1 の一様な共通モード**（$c_{ki}\approx\mathrm{const}\approx0.0027$）であり、
物理的には「上流層の総発火数がサンプルごとに揺らぎ、下流全体を同じ向きに駆動する」現象である。
第 1 隠れ層では入力を固定すると $d^{(1)}$ が $T$ にわたり定数なので相関はゼロ。
**深いほど、学習が進むほど悪化する。**

#### 試みて全滅した対処と、成功した対処

- **安価な代数補正は全滅した**（ブロック対角 `blk*`、`cm`、`rank1`、Woodbury、`unif`、`r1lo`）。
  バイアスは経験共分散そのもので決まるため、事後の代数操作では除けない。
- **多変量ミラー** $\hat W=\mathrm{Cov}(d,z)\,\mathrm{Cov}(z,z)^{-1}$（Tikhonov 版
  $\mathrm{Cov}(d,z)[\mathrm{Cov}(z,z)+\lambda I]^{-1}$）は厳密（$\mathrm{corr}=1.000$）だが
  $O(H^3)$ の逆行列を要し、局所性の利点を失う。
- **成功した対処は「バイアスを補正する」のではなく「そもそも生じさせない」こと**、
  すなわち第 3.6 節の**周期ノイズ場**である。上流ノイズを周期 $P_\eta$ でタイルし、位相クラス内で
  中心化すれば共有駆動が位相内で定数になり、相関が構造的に消える。
  実測: ミラー $\mathrm{corr}=1.000$、隠れ 4 層 MNIST で backprop とパリティ
  （0.879 ± 0.007 対 0.872 ± 0.008、3 seed）。

  **なぜこれで消えるのか**: 汚染源は「上流層の総発火数がサンプルごとに揺らぐ」ことだった。
  上流ノイズを周期 $P_\eta$ で使い回すと、同じ位相のサンプルは**上流がまったく同じ実現値**を持つ。
  その位相クラスの中だけで中心化すれば、共有駆動は定数として引き算され、
  残るのは対象層固有のゆらぎだけになる。補正項を足すのではなく、
  **測る場所を選ぶことで汚染を避けている**のが要点である。ハードウェアでは LFSR のクロックを
  $P_\eta$ サイクルに 1 回だけ進めればよく、追加回路はゼロである。

> **重要な但し書き**（`idea_ca.md` §10 の教訓）: **推定量の正しさと汎化の結合は緩い。**
> 周期ノイズ場による利得は設定依存であり、ガウス・隠れ 4 層では明瞭（分散 3–4 分の 1）だが、
> 隠れ 2/3 層や一様ノイズでは差が小さい。cosine は「楽観にも悲観にもぶれる代理指標」であり、
> 主証拠にしてはならない。

### 5.8 場への credit: $\sigma$ 勾配と一般化定理

#### 中心の恒等式

$p$ がスケール族 $p(\xi)=\frac1\sigma q(\xi/\sigma)$ であれば、$\partial_\sigma F=q(d/\sigma)(-d/\sigma^2)=-\frac d\sigma p(d)$
を $\partial_\sigma\bar\phi=2(1-2F)\partial_\sigma F$ に代入して

$$
\boxed{\ \frac{\partial\bar\phi(d;\sigma)}{\partial\sigma}=-\frac d\sigma\,\bar\phi'(d)\ }
$$

数値検証: ガウス残差 $3.0\times10^{-11}$、一様 $1.3\times10^{-10}$。
連動 $h_k=c_h\sigma_k$ のときは $\bar z(d;\sigma)=g(d/\sigma)$ となり、$c_h$ の値によらず厳密に成立する。

#### 場の勾配は第 3 因子の再利用

$$
\boxed{\ \frac{\partial L}{\partial\sigma^{(l)}_k}\approx
\Bigl\langle\,\underbrace{\hat g^{(l)}_{n,k}}_{\text{credit}}\cdot
\underbrace{\Bigl(-\frac{d^{(l)}_{n,k}}{\sigma^{(l)}_k}\Bigr)\phi_T'\bigl(d^{(l)}_{n,k}\bigr)}_{\partial z_k/\partial\sigma_k}\,\Bigr\rangle_{m,n}\ }
$$

重み則（第 5.2 節）と比べると、**前シナプス因子 $z^{(l-1)}_j$ が $-d_k/\sigma_k$ に置き換わっただけ**である。
新しい統計量も専用の摂動フェーズも不要で、$\phi_T'$ が分布フリーなので $\sigma$ 勾配も分布フリーである。

**コスト比較**: SPSA が同等の忠実度に達するのに 1657–7005 回の追加 forward を要するのに対し、
$\sigma$ 勾配は**追加 forward 0 回**である。最も堅い形の主張は
「任意のゼロ次法は $H$ 個の未知数を決めるのに最低 $\Omega(H)$ 回の追加評価を要する。$\sigma$ 勾配は 0 回である」。

**忠実度の実測**: 真の $\sigma$ 勾配との cosine は $c_\infty\approx0.94$（3 seed で 0.82–0.97）で 1 ではない。
$T$ を増やしても頭打ちになるので分散では説明できず、残差は構造的である。
最有力の説明は第 4.5 節の動径成分（勾配ノルムの 2–4 割）である。

#### 一般化定理（任意の分布パラメータへ）

$\bar\phi(d;\lambda)=G(F(d;\lambda))$ と書ける任意の分布パラメータ $\lambda$ について

$$
\frac{\partial\bar\phi}{\partial\lambda}=-v_\lambda(d)\,\frac{\partial\bar\phi}{\partial d},
\qquad v_\lambda(d)=-\frac{\partial_\lambda F(d;\lambda)}{p(d;\lambda)}
$$

$v_\lambda$ は確率質量の速度場（輸送方程式型）である。スケール族なら $v_\sigma=d/\sigma$、位置族なら $v_\mu=1$。
すなわち**同一の forward credit と同一の $\phi_T'$ で、任意の分布パラメータを学習できる**。
歪度・裾指数のような形状パラメータは重みで代替できない真に新しい自由度であり
（第 4.7 節の擁護 (2)）、`nnn/noise.py` は $\alpha$ 安定分布のサンプラーと数値 PDF/CDF を既に備えている。
ただしこの定理は代数的に確認されただけで、**数値検証は未実施**である。

### 5.9 オプティマイザ適合

パラメータ更新には任意のオプティマイザを組み合わせられる。SGD はもちろん、Adam の 1 次・2 次モーメント
$m,v$ も重みごとに閉じた量なので、Adam を用いても重み輸送は発生しない。
ただし**オプティマイザの適性は推定量の誤差の性質に依存する**:

| 学習則 | 誤差の性質 | 適合オプティマイザ | 実測 |
|---|---|---|---|
| `cov_only` / `cov_deriv` | 消えない系統誤差 | **SGD** | Adam にすると 0.035 → 0.147 ± 0.091 と悪化 |
| `cov_jac` / `cov_jac_full` | 低分散・準不偏 | **Adam** | SGD 0.015、Adam 0.00056（27 倍差） |

Adam の $1/\sqrt v$ 正規化は勾配スケールを正規化するため、系統誤差を持つ推定量に適用すると
学習後期に真の勾配が縮小するなかでバイアス成分だけが相対的に増幅され続ける。
逆に準不偏な推定量に対しては backprop と同様に有効に働く。

`cov_jac` が SGD で残す 0.015 は**推定量のバイアスではなく最適化に由来するアーチファクト**である。
一方で「backprop 水準に到達するには Adam が要る」ことはハードウェア物語と緊張する
（重みごとの 1 次・2 次モーメントのメモリが要る）。これは未解決の課題である。

> **RL では逆の知見がある**: `idea_rl.md` §24 は「SGD が堅く Adam は不安定」と記録している。
> オンライン・非定常な設定では Adam のモーメント推定が追随できないためと考えられる。

### 5.11 保存すべき否定的結果

理論文書の「落とし穴」として明示的に残す。

1. **外部ノード摂動は二値交差に効かない。** 明示的な摂動 $\xi$ を注入して
   $\hat g_d=\mathrm{Cov}_T(L,\xi)/\mathrm{Var}_T(\xi)$ を取る `cov_deriv_gate` は不偏だが高分散
   （標準誤差 $\sim\sqrt{\mathrm{Var}L/T}/\alpha$）。RNG 状態をリセットしてビット厳密な共通乱数ペア
   $(+\xi,-\xi)$ を走らせる `cov_deriv_gate_crn` でも改善は僅少である。
   原因は**二値活性のパスワイズ微分の退化**（測度零集合でしか flip しない）であり、
   per-sample 損失差が厳密に 0 になる割合が高い。
   **交差の内部密度推定（crossing counting）こそが正しい傾き推定器である。**
2. **ノイズ予算の移転は失敗する。** ユニット削除時に $\sigma_j'^2=\sigma_j^2+W_{jk}^2\mathrm{Var}(r_k)$ で
   分散を下流に移す操作は、共分散を無視した過剰注入になる。
3. **安価な代数補正はすべて失敗する**（第 5.7 節）。
4. **ネットワークレベルの有限差分は測定器にならない**（第 4.8 節）。
5. **SAC の適応標準化はブートストラップと正帰還して発散する**（`tmp/rl/sac.py` のコメントに保存）。
   代わりに固定クランプ $|y|\le r_{\max}/(1-\gamma)$ を使う。

## 7. 応用チャレンジからの参照情報

各チャレンジのうち、**最も成功した構成**と、**本体理論に還元される知見**だけを記す。
詳細は各文書を参照。

### 7.1 Self-consolidation（`idea_consolidation.md`）

**最も成功した構成**: 経路 B（noise-annealed self-consolidation）。
$\rho$ ダイヤルを毎段 $\times0.6$（$h$ は $\div0.6$）で減衰させながら通常の cov_jac 学習を続け、
実測平均活動 < 0.01 で kill する。補償は専用の代入操作ではなく**学習則そのものが担う**。
逐次格納の容量は 16 タスク（$\sin(kx+\varphi)$）で hard 4 / readout-only 8 / softA 11 / caseB 12。

**本体理論への還元**:

1. **$\rho$ ダイヤルの発見**（第 3.5 節）。$\sigma$ だけでは深層で漏れるという事実と、
   $h$ 番兵による厳密沈黙。これは本体理論の一部として第 3 節に取り込んだ。
2. **ゲージ軌道と消滅経路の区別**（第 4.6 節）。$\sigma\to0$ の性質が接近経路に依存するという観察。
3. **credit の自動消灯**: 推論離脱と学習離脱が単一の物理量で同時進行する（第 3.5 節）。
4. **冗長性は学習が再生産する資源である**（§12.6）。削除コスト $S_k$ が非単調で停止判定に使えず、
   閉ループの保留率（holds）が唯一有効な先行指標であった。
5. **圧縮フロア則** $m\le\text{floor}_l\le\lceil\mathrm{er}_l\rceil$（下流が層 $l$ に要求する関数空間の次元）。
   `idea_reservoir.md` §12 はこれを memory capacity と次元対応させている。

### 7.2 Reinforcement learning（`idea_rl.md`）

**最も成功した構成**: **PPO v4**（§23.10）。backprop ゼロ・転置重みなしの単一 NNN が
倒立振子の swing-up と保持を安定に学習する（upd 75–300 の 10 連続チェックポイントすべて
last100_up = 1.000、value $R^2$ 0.89–0.92）。backprop フリー制約下では PPO 系が構造的に有利であり、
SAC の効率源泉である reparameterization が制約で禁じられるため到達速度で約 4 倍の差がつく。

**本体理論への還元**:

1. **credit エンジンは損失に依存しない。** 教師あり学習の出力誤差 $2(\bar y-t)$ を
   方策スコア $u_t=\Sigma_t^{-1}(a_t-\mu_t)$（離散なら $a-p$）に**差し替えるだけ**で、
   $\hat\delta^{(l)}=(\hat W^{(l+1)\mathsf T}\hat\delta^{(l+1)})\odot\phi_T'(d^{(l)})$ の再帰は無変更で機能する。
   これは第 5.2 節の三要素則における「第 3 因子の種だけが変わる」という主張の最も強い実証である。
2. **EMA ミラー + KP はオンライン設定では必須である**（第 5.5 節）。$N=1$ の単発推定が律速だった。
3. **$\rho$/$h$ ゲートの実務的検証**（§23.7）。凍結した領域を read-only の語彙として動員する
   「olap アーム」が、保持 1.000 と新規学習 1.000 を両立した。
4. **per-unit の $\sigma$ eligibility は ill-posed**（§21.6）。$\mathbb E[\partial\log\pi/\partial\sigma]\approx0$
   （200 pass 平均でノルム ~0、2 pass 間 cosine ≈ −0.04）。
   **場は per-unit $\sigma$ ではなく低次元の recruitment 座標として学習するのが正しい。**
   これは第 4.5 節の「$\mathcal P$ が動かせるのは動径 1 次元だけ」という結論と整合する。
5. **RL は低忠実度 credit に頑健である**（cosine 0.44 でも解ける）。一方で最良制御の $\sigma$（0.6–1.3）と
   最良 credit の $\sigma$（0.1）は一致しない（§20.16）。

**残る構造的な逸脱**: 探索温度 $\sigma_e$ が外付けの固定ガウスノイズであること。
NNN のサンプル分散に結ぶと $(a-\mu)/\sigma^2$ が発散するため切り離されたが、
「探索温度の NNN 内部化」は未解決である。§23.13（壁不使用 swing-up）では
$\sigma_e\ge0.2$ のフロアが微細バランスゲイン学習の律速となり、実タスクから再要請されている。

### 7.3 Reservoir computing（`idea_reservoir.md`）

**最も成功した構成**: (B)-mix（§10.19）。場（LDN 等の線形記憶力学系）が**ノイズ強度にのみ**入り
入力には入らない、"noise-modulated" に忠実な定式化。
$\sigma_k(t)=\text{floor}+\mathrm{softplus}((M_{\mathrm{mix}}A(t))_k+\beta_k)$。

**性能の物語は撤回済みである**（§13.3）。NG-RC に予算を揃えて敗北したため（NARMA-20 で
NG-RC 0.078@562 params 対 本系 0.360@3265）、存在理由は固有性質と生物学的接地に移行した。

**本体理論への還元**:

1. **$\theta$ 凍結はゲージを自動固定する**（第 4.7 節の体制 (c)）。これが「$\sigma$ は冗長か」という
   文書間の見かけの矛盾を解消する鍵である。
2. **SR は sample 水準にしか存在しない**（第 2.6 節）。同一重みでの診断により、
   sample は逆 U 字（$\kappa_\sigma^*\approx0.20$–$0.23$、6 seed すべて）、analytic は平坦なプラトー。
   「ノイズは資源であって実装手段ではない」が時間軸上でも成立する。
3. **forward-only credit は静的勾配として厳密である。** $\theta$ を貫く時間再帰がないので
   $\partial L/\partial\theta$ は各時刻を独立サンプルとした静的勾配の時間和になり、BPTT を要しない。
   実測 cosine = 1.000000、有限差分との相対誤差 $7.2\times10^{-9}$。
4. **$\partial z/\partial\sigma=\partial z/\partial(\cdot)\cdot(-d/\sigma^2)$ が独立に再発見されている**
   （`tmp/reservoir/nnn_map.py`）。第 5.8 節の恒等式と同一物であり、統一の好材料である。
5. **$\sigma\to0$ は echo state property の完全散逸極限**として解釈できる。
   ただし ESP に必要なのは収縮性だけでアトラクタが 0 である必要はなく、
   非零固定点・リミットサイクル・入力依存多安定・臨界の 5 分類が可能である（§6）。

**要再訪の核心**（§7.2）: 「ESP を持つ非線形ダイナミクスが十分に複雑なら読み出しだけの学習で足りる」
という RC の一般化主張に対し、BPTT フリーな forward-only 特徴学習が反証を与えられるか。
これを示せない限り本系は「ノイズ場という基質で RC を再現しただけ」に吸収される。
要石は **option 2（真の確率的 cov_jac + 特徴学習が原理的に必要な課題）で、現時点で未着手**である。

### 7.4 神経修飾場と確率共鳴（`draft_front_comp_neuro.md`, `recipe_sr.md`）

**最も成功した主張**: ノイズ場は単一の共有重み集合に多重化された複数の方策を**アドレスする**が、
それは記号的な「鍵（look-up key）」ではなく**最適強度をもつ機能的資源**である。
鍵ならば閾値を超える限りどの強度でも同じ行動が選ばれるはずで最適強度は存在しないから、
内点最適の存在が対抗仮説への直接の反証になる。

実測（seed 7、`--sweep train --model sample`）: 刺激依存信号のピークは $\sigma_{\mathrm{train}}=1.19$（内点）、
端点 0.063 / 0.790 に対しピーク 0.803。タスク誤差は端点 0.414（低 $\sigma$ = しきい値下の崩壊）/ 0.030 に対し最小 0.014。

**本体理論への還元**: 第 2.6 節（analytic は sample の忠実な縮約ではない）。
これは NNN の 3 実装水準の関係についての、最も重要な非自明な事実である。

### 7.5 符号化様式（`idea_coding.md`）

**本体理論への還元**:

1. **ゲージ不変な無次元制御量** $\Gamma=|\dot d_k|\Delta t/\sigma$ の導入（第 4.8 節）。
   時間軸上で $\sigma$ を論じるには、まず無次元化しなければならない。
2. **学習則そのものがノイズを要求し、レート符号化を選好する。**
   KDE 代理勾配は信号がしきい値帯 $\pm h$ 内にある時刻でしか立たないため、
   自分の訓練ノイズで評価したときの $\Gamma$ はすべて 0.35 以下になる。
   タイミング符号を得るには「ノイズありで学習し、その後ノイズを抜く」必要がある。
3. **ノイズ輸送とプーリングの綱引き**（第 3.4 節）。
4. **方法論的教訓**: 絶対ステップ数で固定した解析窓を持つ指標は、信号の時定数が変わると必ず交絡する。

### 7.6 ハードウェア（`idea_fpga.md`, `draft_nce.md` §6）

一様ノイズを選ぶ本質的な理由は 2 つである:

1. 一様乱数は LFSR（シフトと XOR）のみで生成でき、ガウスに必要な Box–Muller や CLT 近似の追加回路が不要。
2. 統計的に等価な活性化関数が**コンパクトサポート**を持つ（第 2.3 節）。
   しきい値から遠いユニットはスパイクも学習統計も厳密に 0 のままであり、
   イベント駆動実装における活動と電力の疎性に直結する。ガウスでは全域で発火確率が正なのでこの疎性は得られない。

| プリミティブ | ガウス | 一様 |
|---|---|---|
| 乱数生成 | Box–Muller / CLT 近似 | **LFSR のみ** |
| 発火確率のサポート | 全域で正 | **$\lvert d-c_u\rvert\ge r_u$ で厳密 0** |
| 交差活性 | 比較器 2 個 + XOR | 同一 |
| 分布フリー局所微分 | XOR カウンタの差分 | 同一 |
| 学習統計 | カウンタ + 積和 + 除算 | 同一 |
| （解析式を使う場合） | erf 系（LUT） | 2 次多項式 / 一次式 |

なお、性能はノイズ分布に依存しない（第 6 節）ので、**ノイズ源は学習性能ではなく実装コストの基準で選べる**。

## 8. 未解決問題

本体理論に属するものを優先度順に挙げる。

1. **深層での対角近似バイアスの外的妥当性**（第 5.7 節）。周期ノイズ場は隠れ 4 層 MNIST で
   パリティを示したが、隠れ 2/3 層や一様ノイズでは利得が小さい。
   より深いネットワーク・より大きなタスクでの検証が必要。
   これは `draft_nce.md` の open problem、`idea_consolidation.md` §16.1、`idea_ca.md` §9.3 で共通の項目である。
2. **ゲージ体制の選択**（第 4.7 節）。「厳密な推定量 + ゲージ冗長」対「本物の自由度 + 偏った推定量」の二択が未決。
   形状パラメータ（歪度・裾指数）が真に新しい自由度を与えるかどうかが決め手になりうる。
3. **一般化定理の数値検証**（第 5.8 節）。$\partial\bar\phi/\partial\lambda=-v_\lambda\,\partial\bar\phi/\partial d$ は
   代数的に確認されただけである。$\alpha$ 安定分布のサンプラーは既に `nnn/noise.py` にある。
4. **$\sigma$ 勾配の $c_\infty\approx0.94$ の内訳**（第 5.8 節）。動径成分仮説の直接検証。
5. **Adam 依存**（第 5.9 節）。`cov_jac` は SGD で 27 倍劣る。
   符号ベースの軽量オプティマイザ（sign-SGD、Adam の 1 bit 近似）で代替できるかが
   ハードウェア物語との整合上もっとも重要。
6. **場生成パラメータへの credit 経路の完全 forward 化**。`idea_rl.md` §19 は二層方策として
   理論的に定式化済みだが、実証はスカラー場中心の最小版まで。
   per-unit の weight-mirror による $\partial\tilde c/\partial\theta_{\mathrm{mod}}$ の forward 推定は未実装。
7. **RC の一般化主張への反証**（第 7.3 節、option 2）。未着手。
8. **探索温度の NNN 内部化**（第 7.2 節）。$\sigma_e$ の撤廃。

**整備項目**（理論上の未解決ではなく、実装の宿題）:

- **周期ノイズ場のライブラリ化**（第 3.6 節）。現状は `tmp/` の検証コードで運用しており当面は問題ない。
- **`kde_slope` の同一パス化**（第 2.5 節）。同一パス版は `tmp/fncl_phase1_fxp.py` Stage A に既にある。
  `nnn/stats.py` 側を置き換えれば、コスト会計とハードウェア議論が実装と一致する。
- **MirrorEMA / MirrorState の $\beta$ 規約の統一**（第 1.3 節）。保持率と混入率が反転して並存している。
  なお `nnn/` と `data_nce/fncl/` の並行実装は、後者が暫定の検証パイプラインである以上そのままでよい。
