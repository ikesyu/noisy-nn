**位置づけ**：ノイズ場 $\mathcal P$ を静的なアドレス（`docs/idea_neuromod.md`）や
最適化で駆動するアニール変数（`docs/idea_consolidation.md`）としてではなく、**それ自身が
時間発展する散逸力学系**として扱う構想。場のダイナミクスがリザバー、ネットワークの重み
$\theta$ とその出力が固定の非線形観測、学習は読み出しだけ、という Reservoir Computing（RC）の
規律をノイズ場の上に移植する。関連：`docs/idea_consolidation.md`（消滅経路＝散逸、ρ ダイヤル）、
`docs/idea_neuromod.md`（場が方策をアドレスする＝多安定版リザバー）、
`docs/draft_nce.md`（forward-only 学習＝読み出しも backprop 不要）、`tmp/rbf_nnn_masks.py`
（交差＝バンプ＝RBF 辞書）。

**用語規約（2026-08-03 更新）**：本稿で「**ノイズ場**」とは、**NNN の各ユニットに与える加法ノイズ強度 $\sigma_k$ を
決める機構**を指す — 入力 $u$ で駆動される散逸メモリ場が $\sigma_k(t)=\text{floor}+\text{softplus}((MA(t))_k+c_k)$ を
供給し、固定動作点 $d_k$ の交差活性 $z_k=2\Phi(d_k/\sigma_k)(1-\Phi(d_k/\sigma_k))$ を変調する。**場を単にユニットの
入力として与える使い方は「ノイズ場」に含めない**。この機構だけを **「Ours」「提案手法」「NNN reservoir」** と呼ぶ。
場→ノイズの配線に**混合ノイズ場**（各ユニットが全場座標の学習線形結合を読む＝既定）と**対角ノイズ場**（場座標を

≈LMU）は**提案手法ではなく参照ベースライン**である。以下の実行報告中の「Ours／ノイズ場／混合ノイズ場」は本機構を、
「入力結合版」は参照版を指す。学習は場を固定した forward-only（$d,M,c$＋線形読み出し、BPTT 不要）。

## 1. コアアイデア（一文）

> **ノイズ場を「どんな初期状態からもやがて $\sigma\equiv0$（全ユニット離脱）へ漸近する散逸力学系」として構成すると、その過渡状態の族が高次元の特徴基底になる。固定入力に対する出力を学習することは、この散逸ノイズ場リザバーの読み出しを学習することに等しい。入力は場を変調するパラメータであり、各場状態はネットワークを介して「入力 $x$ を関数として写す」ので、系全体は関数を出力する関数＝汎関数（作用素）の Reservoir Computing になる。**

$\sigma\to0$ への漸近は「初期条件を忘れる」という Echo State Property（ESP）／fading memory の
最も強い（完全散逸）極限にあたる。RC の計算力は固定点そのものではなく**過渡**に宿るので、
richness は $\sigma\to0$ の漸近ではなく、そこへ至る過渡の空間構造（拡散・反応）と入力変調が担う。

---

## 2. 出発点の直観：ゼロ漸近ノイズ場は散逸リザバーである

NNN の交差活性の期待応答はバンプ型 $\bar\phi(d)=2F(d)(1-F(d))$ で、ユニット $k$ の寄与は
その場強度 $\sigma_k$（深い層では $h_k$ も）が縮むと連続にフェードし、ゲージ不変な参加量
＝交差率 $\nu_k\to0$ で完全に離脱する（`idea_consolidation.md` §4）。重み $\theta$ を固定した
ままの $\sigma\downarrow$ は**ゲージ軌道ではなく消滅経路**なので、ユニットは本当に消える。

ここまではコンソリデーション稿と同じ物理だが、あちらは $\sigma_k$ を**タスク損失で駆動して
アニール**していた。本稿は $\sigma$ 場に**自律的な時間ダイナミクス** $\dot\sigma=F(\sigma;x)$ を
与え、$F$ を**大域的に $\sigma\equiv0$ を漸近安定平衡にもつ散逸系**に選ぶ。すると：

- 過渡（$t$ 小〜中）では場が非ゼロで、ネットワークは入力に応じた非自明な出力を返す。
- $t\to\infty$ では全ユニットが離脱し、**いかなる入力に対しても出力は 0** になる。

この「初期条件を washout して自明な休止状態へ収束する」性質が、まさに RC の ESP／fading
memory の力学的実体である。$\sigma\equiv0$ は「静止した貯水池」に相当する。

## 3. Reservoir Computing との対応辞書

| RC の要素 | 標準 ESN | 本構想（ノイズ場リザバー） |
|---|---|---|
| リザバー状態 | ニューロン状態 $\mathbf r(t)$ | **ノイズ場** $\sigma(t)\in\mathbb R_{\ge0}^{H}$（またはグリッド上の場） |
| リザバー力学 | $\mathbf r_{t+1}=\tanh(W_{\text{res}}\mathbf r_t+W_{\text{in}}u_t)$ | $\dot\sigma=F(\sigma;x)$（拡散＋漏れ等の**散逸 PDE/ODE**） |
| 固定・非学習部 | $W_{\text{res}},W_{\text{in}}$ | 場の力学 $F$、ネットワーク重み $\theta=(w,b)$、交差非線形 |
| 入力 | 状態への加法注入 $u(t)$ | **場ダイナミクスの変調**（初期条件・ソース項・拡散係数・ドリフト） |
| 観測（各時刻の特徴） | 状態 $\mathbf r(t)$ | 場が誘導する**関数** $\phi_t:x\mapsto f(x;\theta,\sigma(t))$、またはユニット活性 $z(t)$ |
| 読み出し（学習部） | 線形 $W_{\text{out}}\mathbf r(t)$ | 場の軌道上の線形結合（後述、汎関数の場合は $\int\beta(t)\phi_t\,dt$） |
| ESP／fading memory | スペクトル半径 $<1$ で担保 | **散逸性（$\sigma\to0$ への収縮）で担保**。$\sigma\equiv0$ が大域アトラクタ |

重要な設計の分岐は**「観測を何にするか」**である。

- **(a) 通常の RC**：観測を活性ベクトル $z(t)\in\mathbb R^H$ とし、固定入力 $x$ に対する出力
  $y=\sum_t W_{\text{out}}(t)\,z(t)$ を学習する。これは「時間発展する特徴写像を持つ NNN」であり、
  RC の素直な移植。
- **(b) 汎関数の RC**：観測を**関数** $\phi_t(\cdot)$ とみなす（次節）。ここが本構想の売り。

## 4. なぜ「汎関数（作用素）の RC」なのか

各時刻の場 $\sigma(t)$ は、ネットワークを介して一つの関数
$\phi_t:x\mapsto f(x;\theta,\sigma(t))$ を定める。したがって散逸ノイズ場リザバーが吐くのは
**関数の軌道** $\{\phi_t\}_{t\ge0}$ である。標準 RC がベクトルの軌道 $\{\mathbf r(t)\}$ を吐き、
線形読み出しでスカラーを作るのに対し、ここでは関数の軌道を線形結合して**新しい関数**を作れる：

$$
\Psi[\,\cdot\,](x)\;=\;\int_0^{T}\beta(t)\,\phi_t(x)\,dt
\;=\;\int_0^{T}\beta(t)\,f(x;\theta,\sigma(t))\,dt .
$$

学習するのは重み関数 $\beta(t)$（時間軸上の線形読み出し）だけである。入力（＝場を変調する量、
たとえば入力信号や制御パラメータ $u$）を変えると場の軌道 $\{\phi_t\}$ が変わるので、
$u\mapsto\Psi_u(\cdot)$ という**関数から関数への写像＝作用素**が実現される。

この視点は作用素学習（DeepONet の branch/trunk 分解）と対応づく：
- 場の軌道 $\{\phi_t(x)\}$ は、**力学が自己生成する trunk 基底**（クエリ座標 $x$ 上の基底関数族）。
- 読み出し係数 $\beta(t)$ は branch 側の係数に対応。
- 違いは、trunk を学習・設計する代わりに**散逸ノイズ場の過渡が無学習で供給する**点。
  RC の「リザバーは訓練しない」規律を、作用素学習の trunk に持ち込んだ形になる。

交差の期待応答がバンプ（$\bar\phi$ は $d=wx+b$ に対する山、放物線版なら有界台のRBF）である
ことから、$\phi_t(x)$ は**時間発展する RBF 辞書の重ね合わせ**として読める（`rbf_nnn_masks.py`
のバンプ辞書の時間版）。場が拡散すれば台が移動・拡幅し、入力空間上のタイル化が時々刻々変わる
――これが trunk 基底の richness の源泉になる。

## 5. そのようなノイズ場をどう作るか（構築法の候補）

$\sigma$ は非負（ノイズ強度）で、グリッド構造（`nnn/noise_field.py` の `Structure`）を既に持つ。
これを活かして、単純な順に：

### 5.1 リーキー積分（最小構成、ただし過渡が貧しい）
$$\sigma_{t+1}=\lambda\,\sigma_t,\quad 0<\lambda<1.$$
大域アトラクタ 0、ESP 自明。だが軌道は初期方向の指数減衰だけで**1 次元的**。RC としては
memory capacity が乏しく、baseline 以上にはなりにくい。richness を出すには次以降が要る。

### 5.2 拡散＋漏れ（本命・グリッドを活かす）
グリッド上のラプラシアン $\nabla^2$ を使い、
$$\partial_t\sigma = D\,\nabla^2\sigma \;-\;\gamma\,\sigma .$$
バンプが**空間的に広がりながら**全体が漏れて 0 へ。非負性は熱方程式が保存する（初期非負なら
非負のまま）。過渡は「バンプの拡散・減衰」で高次元的になり、$\nabla^2$ の固有モードが
自然な特徴基底を与える。$\gamma$ が fading memory の時定数、$D$ が空間的な混合度＝特徴の広がり。
**まずこれで最小実証するのが良い**（既存の `gaussian_fill` を初期条件に使える）。

### 5.3 移流拡散（入力変調を素直に入れる）
$$\partial_t\sigma = D\,\nabla^2\sigma - \nabla\!\cdot(\mathbf v(x)\,\sigma) - \gamma\sigma .$$
入力 $x$ を**ドリフト場** $\mathbf v(x)$ に写すと、入力がバンプの動く向き・速さを決める。
異なる入力が異なる軌道形状を残すので、§8 で述べる「入力が過渡に痕跡を残す」要件を満たしやすい。

### 5.4 反応拡散（richness 最大化、edge-of-chaos 探索）
$$\partial_t\sigma = D\,\nabla^2\sigma + R(\sigma) - \gamma\sigma,$$
$R$ に軽い非線形（Turing 的な局所活性・側抑制）を入れると、進行波・スポット等の構造的な
過渡が出る。**大域漏れ $-\gamma\sigma$ を十分強く保てば $\sigma\equiv0$ の大域安定性は維持**
できる（$R(0)=0$ かつ線形化が漏れ支配なら）。RC の計算力は安定性境界近傍で最大化するので、
$\gamma$ を臨界へ寄せて memory capacity を掃引するのが自然な実験軸になる。

### 5.5 減衰波動（記憶を延ばす）
$$\partial_t^2\sigma + \gamma\,\partial_t\sigma = c^2\nabla^2\sigma \;(\to0).$$
振動しながら減衰する過渡で、単調減衰より長い有効記憶を持つ。時系列タスク向け。

### 5.6 状態変数を $\sigma$ でなく $\rho$ にする（推奨・§8 の 2 難所を同時に閉じる）

上の力学はすべて $\sigma$ を状態にして書いたが、**状態変数を動員ダイヤル $\rho_k$
（$\sigma_k=\rho_k\sigma_0,\ h_k=h_0/\rho_k$、`idea_consolidation.md` §4.6）にすると、
§8 の難所 1・2 を機構として同時に解ける**。たとえば拡散＋漏れは
$$\partial_t\rho = D\,\nabla^2\rho - \gamma\rho,\qquad \sigma_k=\rho_k\sigma_0,\ h_k=h_0/\rho_k .$$

- **難所5（深い層の休止）の解決＝休止が厳密ゼロになる**：$\sigma$ 単独では深い層が上流ゆらぎで
  $\sigma_k=0$ でも発火し続け（$\nu=0.11$–$0.17$ のプラトー）、貯水池が完全に静止しない＝fading
  memory に非減衰残差が混じる。$\rho\to0$ は $h\uparrow$ を伴うので有限パラメータで厳密に
  $\nu_k=0$ に達し、**「空の貯水池」＝真のゼロ出力アトラクタが $\rho$ 上でのみ厳密**になる
  （RL 稿 §23.7 の ρ/h ゲートで漏れを解いたのと同じ機構）。
- **難所1（ゲージ冗長）は $\rho$ で扱いやすくなる。ただし主目的ではない**：ゲージ不変な参加量は
  交差率 $\nu_k=\mathbb E[z_k]$（観測量）であり、$\rho_k$ はそれを制御するダイヤル（制御量）である。
  両者は同一ではなく、$\rho\downarrow$ とともに $\nu\downarrow$ し**有限の $\rho$ で $\nu=0$ に到達する**
  という単調な関係にある。$\rho$ はゲージ方向 $(\sigma,h)\to(\alpha\sigma,\alpha h)$ に**横断的**な座標
  （$(\log\sigma,\log h)$ 平面でゲージが $(+1,+1)$、$\rho$ が $(+1,-1)$）なので、ゲージ不変量 $h/\sigma$ を
  実際に動かせる。詳細は `docs/idea_core.md` §1.2・§4.6。
  **ただし §12 の通り、リザバーは $\theta$ 凍結で既にゲージが固定されており、
  $\sigma$ のスケールはもはや冗長ではない（重みが補償できないため本物の DOF になる）**。よって
  「冗長モードを潰す」ことは $\rho$ を使う主目的ではなく、主目的は難所5（厳密な休止）に一本化される。
  $\rho\in[0,1]$・$\rho=0$ で厳密離脱という**有界・単調な座標**である利点は残る。
- **トレードオフ（手放す DOF）**：$\rho$ は $\sigma$ と $h$ を機械的に連動させるため、θ 凍結下で
  本物の DOF になった $\sigma$（＝バンプ幅＝確率的特徴の richness）を **$h$ と独立に動かすノブを
  1 つ失う**（ここで失うのはゲージ冗長方向ではなく、§12-II で本物になった実 DOF である点に注意）。
  $\rho$ は on/off＋fading-memory ダイヤルに徹する。
- **推奨**：まず **$\rho$ 単独**で始める（「やがてゼロ」の前提に厳密一致、状態が不変座標、深い層でも
  真に静止）。過渡の richness が不足したときのみ、$\rho$（動員）と $\sigma_{\text{shape}}$（幅）を
  **2 枚の場**に分離する（冗長気味の DOF を明示的に扱う負担と引き換え）。§6 の非零アトラクタ版も
  $\rho\to\rho^\*(\ne0)$ と書けば同じ座標で統一できる。

### 実装上の注意
- **非負性**：拡散系は非負を保つが、ドリフト・反応を入れる場合は $\sigma=\text{softplus}(a)$
  等の非負リンクを噛ませて内部状態 $a$ を発展させると安全。
- **深い層の漏れ**：`idea_consolidation.md` §4.5 の通り深い層は上流ゆらぎで $\sigma_k=0$ でも
  発火が残る。厳密な休止（$\nu\equiv0$）には $h_k\uparrow$ を併用する ρ ダイヤルが要る。
  リザバーとして「完全に静止する」ことを主張するなら $h$ ゲートを設計に含める。
- **時間軸の実装**：realtime 版 `Crossing`（$[N,T]$ の $T$ 方向に交差）が時間 credit を保つ
  （`idea_coding.md` §4 の教訓：`CrossingSample` は $T$ 平均で時間情報が消える）。ただし RC の
  読み出しは線形回帰／forward-only なので backward の質は本質でなく、観測をどう時間サンプルに
  写すかの設計が主。

### 5.7 実装された離散ノイズ場のダイナミクス（`tmp/reservoir/fields.py`）

§5.1–5.6 は連続系の候補だが、実際に 入力結合版/ノイズ場 の実験（§10.11–10.15）で用いたのは以下の**離散ノイズ場**
である。ここに力学を一箇所へまとめる。いずれもスカラー入力 $u(t)$ で駆動される**線形メモリ**で、
状態 $x(t)\in\mathbb R^{H}$（＝場 $A(t)$）が ノイズ場 のノイズ強度 $\sigma_k(t)=\text{floor}+\text{softplus}((MA(t))_k+c_k)$
を変調する（場自身は確率的でなく、交差ユニットの σ を決める決定論的リザバー）。

| 場（クラス） | 離散ダイナミクス | 散逸 | 生物学的読み |
|---|---|---|---|
| **遅延線** `DelayLineField` | $x_i(t)=u(t-1-i)$（純シフトレジスタ、各座標＝1 厳密ラグ） | 無損失（$\sigma\to0$ しない） | 遅延線回路（小脳顆粒細胞・音源定位） |
| **カスケード** `CascadeField` | $x_0(t)=u(t),\quad x_i(t)=a\,x_{i-1}(t-1)\ \Rightarrow\ x_i(t)=a^{\,i}u(t-i)$（$a=0.92$） | ○（$\sim H$ 歩で 0 へ） | 信号伝播＋減衰（feedforward / synfire chain） |
| **減衰直交** `DampedOrthField` | $x(t)=\lambda_{\mathrm{sp}}\,Q\,x(t-1)+w_{\text{in}}u(t)$（$Q$ ランダム直交、$\lambda_{\mathrm{sp}}=0.97$） | ○（指数減衰） | 神経修飾物質のクリアランス |
| **LDN** `LDNField` | $m(t)=A_d\,m(t-1)+B_d\,u(t)$（下記行列を ZOH 離散化） | ○（窓 $\theta$ で放出） | 時間細胞 / ワーキングメモリ（LMU） |
| **拡散** `DiffusionField` | $x(t)=M\,x(t-1)+w_{\text{in}}u(t),\quad M=I-\Delta t\,(D\mathcal L+\gamma I)$ | ○（緩慢） | 容積伝達（§5.2 の陽 Euler 離散） |
| **ランダム**（劣設計参照）`LinearReservoir` | $x(t)=(1-\lambda)x(t-1)+\lambda\big(Wx(t-1)+w_{\text{in}}u(t)\big)$（$W$ 疎乱数、sr スケール） | sr$<1$ で○ | ―（ラグが絡んだ乱数場） |

**LDN 行列**（Voelker 2019 の Legendre Delay Network）：
$$A_{ij}=(2i+1)\begin{cases}-1 & i<j\\ (-1)^{\,i-j+1} & i\ge j\end{cases},\qquad B_i=(2i+1)(-1)^i,$$
$$A_d=\exp\!\Big(\tfrac{\Delta t}{\theta}A\Big),\qquad B_d=A^{-1}(A_d-I)B.$$
ZOH（行列指数）離散化が安定化の鍵で、陽 Euler は発散する（§10.13）。分数遅延 $r\in[0,1]$ での復号は
$\hat u(t-r\theta)=\sum_i P_i(2r-1)\,m_i(t)$（$P_i$＝Legendre 多項式、`decode_weights`）で、各遅延セルが窓を
タイルする＝時間細胞の描像（§10.15、ただし受容野幅の Weber 則との整合は §13.4 で不成立＝主張の水準を落とす）。
$\mathcal L$ は1次元パスグラフのラプラシアン（近傍差分）で、$M=I-\Delta t(D\mathcal L+\gamma I)$ は §5.2 の
$\partial_t\sigma=D\nabla^2\sigma-\gamma\sigma$ の陽 Euler 離散に一致する。

**参照**：性能・MC・生物対応の実測は §10.11–10.15、コードは `tmp/reservoir/fields.py`。比較基準の ESN
（`esn.py` `LeakyESN`）は「場」ではなく**記憶と非線形を同居**させた
$x(t)=(1-\lambda)x(t-1)+\lambda\tanh\!\big(Wx(t-1)+w_{\text{in}}u(t)\big)$（§10.11 以降の対照）。混合ノイズ場 で
最良なのは**分離メモリの遅延線／カスケード**（各座標＝1 ラグをマップ $M$ が組み合わせやすい、§10.19）。

### 5.8 LDN とカスケードの詳細、および場の性能上限（Jaeger/Dambre）と配分フロンティア

**LDN（Legendre Delay Network）の詳細**：長さ $\theta$ の直近入力窓を $d$ 状態で**最適表現**する系（Voelker &
Eliasmith 2019 の LMU メモリ）。純遅延を Padé 近似する連続系 $\theta\dot m=Am+Bu$ で、状態 $m$ は窓の
**Legendre 係数**（0次＝平均、1次＝傾き…＝窓のモーメント）。強さの源は3点：**(i) 直交基底**（係数が互いに独立、
良条件）、**(ii) 相異なる時定数**（$A/\theta$ の固有値が広く散る→有効ランク高→MC≈38）、**(iii) 窓上で散逸**（ESP、
時間細胞）。性格は**暗黙的**（単一ラグでなく窓全体の holistic 符号）かつ**圧縮的**（$d<\theta$）→ 滑らかな長窓に強い。

**カスケードの詳細**：$x_i(t)=a^i u(t-i)$。各座標＝**1つの厳密ラグ（減衰付き）**＝**明示的・ディスエンタングル**。
混合 $M$ が任意ラグ対を自明に選べるので 混合ノイズ場 最良（0.238）。MC≈47（$H$ 上限近く）、$a^i$ で散逸（ESP）、生物対応は
信号伝播＋減衰（synfire／樹状突起ケーブル）。**LDN＝暗黙・圧縮・直交窓（モーメント）／カスケード＝明示・非圧縮・
個別ラグ**。厳密ラグ課題（NARMA）はカスケード、滑らかな長窓は LDN が有利。

**性能だけで LDN/カスケードを超える場はあるか — 原理的にはほぼ無理**：

- **① 線形 MC の上限＝$H$（Jaeger 上限）**：線形リザバー・$H$ ノード・i.i.d. スカラー入力で**総線形 MC $\le H$**
  （Jaeger 2002; White-Lee-Sompolinsky 2004）。**遅延線は MC$=H$ を厳密達成（理論最適）**、カスケードは MC≈47≈$H$ で
  ほぼ上限。→ **総線形記憶では遅延線/カスケードを超える場は存在しない**（遅延線が最適、カスケードはその散逸版）。
- **② IPC のトレードオフ（Dambre et al. 2012）**：総処理容量（線形＋全非線形）も $H$ で頭打ちで、線形容量と非線形
  容量は $H$ の予算を奪い合う。本系は**分離アーキ＝場は純線形メモリ（MC$=H$ 最大化）／非線形は NNN マップ**。
  ゆえに場を非線形化すると線形 MC を無駄遣いする（ESN は同居で MC≈6、STP も同様 §10.22–10.23）。→ **分離アーキでは
  「線形 MC$=H$ を飽和する場（遅延線/カスケード）が本質的に最適」**、非線形場はむしろ悪化。
- **③ 残る唯一のレバー＝記憶の配分（MC($k$) プロファイル）**：総量は $H$ で固定だが**どのラグに予算を割くか**は選べる。
  遅延線/カスケードはラグ $1..H$ を解像度1で密にカバー（$x\le H$ の NARMA-$x$ で最適）。**必要ラグが $H$ 超**なら圧縮
  （LDN が窓 $\theta>H$ を解像度↔範囲でトレード）。**マルチスケール/広範囲**なら**対数間隔の遅延線**（タップ $1,2,4,8,\dots$）で
  $H$ タップで指数的に長い範囲をカバーし、短＋超長を要するタスクで一様カスケードを上回りうる。

**結論**：**万能に超える場は存在しない**（総容量が $H$ で縛られる）。超えられるのは**タスクの時間依存構造に $H$ の
予算を合わせたとき**だけ＝タスク依存の配分問題。フロンティアは「より良い場」ではなく「**タスク整合の記憶配分
（IPC 配分）**」で、その意味で**対数間隔遅延線が広範囲マルチスケールタスクで一様カスケードを超えるか**が、検証する
価値のある唯一クリーンな候補（NARMA-$x$ は密ラグゆえ遅延線/カスケードが既に最適で、そこは超えられない）。

**実行報告（2026-08-03 実施）：対数間隔遅延線は「不成立」、広範囲記憶の正解は LDN の窓長 $\theta$（圧縮）**
（`tmp/reservoir_logdelay.py` → `tmp/out/reservoir_logdelay/logdelay.png`、線形読み出しで場の記憶を直接評価。
配分の問いは場の**線形メモリ**の性質なので線形読み出しが正しい道具＝ノイズ場 マップは全場に同一に載る）。同 $H{=}48$ で
一様カスケード（到達 ~48）／対数間隔遅延線（到達 ~512）／LDN $\theta{=}60$／LDN $\theta{=}300$ を比較。

- **(1) 到達（厳密ラグ MC）**：一様＝ラグ $1..48$ で MC=1 の密ブロック／対数＝タップで MC=1 の疎な櫛（~160 まで）／
  LDN $\theta{=}300$＝全域で MC≈0.1–0.2 の浅く広い覆い（厳密単一ラグは解像できない、到達 7）。
- **(2) 滑らかな広範囲タスク** $y=u(t{-}2)+\text{windowmean}(u;D)$：**対数間隔遅延線は全 $D$ で NRMSE≈1.0＝完全に失敗**。
  疎な厳密タップは i.i.d. 入力の任意ラグを補間できず（$u(t{-}2)$ 用のラグ2すら無い）、滑らかな窓も**アンダーサンプル**する。
  一様カスケードは $D\le45$ で 0、$D>48$ で崖（0.12–0.19）。**LDN $\theta{=}300$ は $D{=}140,220$ でも 0.05 と全域で最良**＝
  **長い滑らかな窓は圧縮直交基底（LDN 大 $\theta$）が正解**で、疎タップでも一様到達でもない。
- **(3) 密な短ラグ** $y=\text{mean}_{1..20}u(t{-}k)$：一様 0.00／LDN $\theta{=}60$ 0.06／LDN $\theta{=}300$ 0.12／**対数 0.79（最悪）**。

**結論（§5.8 の精緻化）**：**配分レバーは実在するが、それを実現するのは「対数間隔の疎タップ」ではなく「LDN の窓長
$\theta$（滑らかな圧縮）」**。$\theta$ が短精度↔長範囲を振るノブで、短い厳密ラグは一様カスケード（密・到達 $H$）、長い
滑らかな窓は LDN 大 $\theta$（圧縮）、と**タスクの時間構造で使い分ける**（万能な単一場は無い、を再確認）。
対数間隔遅延線候補は**反証**された（疎な厳密タップは補間もアンダーサンプルもできず全域で劣る）。カスケード/遅延線を
「超える」のは**長い滑らかな記憶を要するタスクで LDN 大 $\theta$ を使ったときだけ**、というのが唯一の成立ケース。

## 6. ゼロ漸近以外への一般化（アトラクタの分類）

$\sigma\equiv0$ への漸近は「完全散逸リザバー」だが、ESP に必要なのは**収縮性（初期条件の
忘却）**であって、アトラクタが 0 である必要はない。一般化すると、ノイズ場は「制御された
散逸力学系」であり、アトラクタ構造の選択が別々の計算的性格を与える：

| アトラクタ | 場の漸近挙動 | 計算的性格・対応 |
|---|---|---|
| **原点（$\sigma\equiv0$）** | 全ユニット離脱、出力→0 | 完全 fading memory。過渡だけが情報を運ぶ。本稿の出発点 |
| **非零固定点 $\sigma^\*$** | 一定の非自明な場へ緩和 | 標準的リーキー ESN。過渡＝入力情報、漸近＝固定動作点。出力は定常関数へ |
| **リミットサイクル** | 場が周期振動 | 律動的神経修飾。関数の周期族を生成。時系列・位相タスク向け |
| **入力依存の多安定** | 入力ごとに別アトラクタへ | `idea_neuromod.md` の「場が方策をアドレス」の力学版。conceptor 的 |
| **臨界（edge of chaos）** | 減衰が極めて遅い／境界 | memory capacity 最大。$\gamma\to\gamma_c$ の掃引で性能ピーク |

統一的抽象：

> **ノイズ場は、神経修飾強度の空間上の制御された散逸力学系である。ネットワーク重み $\theta$ は
> 各場状態を「入力を関数へ写す固定の非線形観測」に変換し、入力は場の力学への制御（変調）
> として入り、線形読み出しだけを場の軌道（またはそれが誘導する関数軌道）の上で学習する。
> $\sigma\equiv0$ 漸近は散逸の極限、多安定は `idea_neuromod.md` との接続点、
> 臨界は計算力の最大化点。**

この一般化により、本構想は既発の 3 断面（学習則 NCE・資源制御 consolidation・アドレッシング
neuromod）を**時間軸上のリザバー**として束ねる第 4 の断面になる。とくに多安定アトラクタ版は
neuromod 稿の静的アドレッシングを「アドレスが力学的に選ばれる」に格上げする。

### 6.1 【最重要の未解決課題】特定時刻に起きたイベントの保持と、出力フィードバック

**論点（本構想で最も重要な残課題の一つ）**：本系の記憶はすべて **fading memory（散逸）**であり、
**「ある特定の時刻に起きたイベント（情報）を、その後長期にわたって保持し、必要なときに使う」ことが原理的に苦手**である。
リザバーの記憶は連続的に減衰する軌跡であり、$k$ ステップ前を**選択的に取り出す**のは場の設計（解けた表現か＝
§10.12–10.13）に依存し、しかも保持時間は場の射程（§5.8：総線形 MC $\le H$、LDN なら窓 $\theta$）で上限が決まる。
**イベント駆動の離散的・長期的な保持（フラグ、モード、文脈の記銘）は、散逸場のどの設計でも到達できない**。

**出力フィードバックによる解法と、その代償**：出力（または層 2 の状態）を場・$\sigma$ に戻す

$$\sigma_k(t)=\text{floor}+\text{softplus}\big((MA(t))_k+(M_{fb}\,z(t-1))_k+c_k\big)$$

と、自己維持ループ（あるユニット群が高 $\sigma$→交差活性→フィードバックで自分の $\sigma$ を維持）＝**アトラクタ**が作れ、
入力が去っても状態が残る。すなわち**特定時刻のイベントを無限に保持できる**（§6 の多安定・conceptor 的一般化の実装）。
生物学的にも自然（Mongillo の STP ワーキングメモリ、持続発火アトラクタ、神経修飾による文脈保持）。**しかし代償が二重に重い**：

1. **ESP を失う**。「$\sigma\to0$ へ散逸する＝fading memory」は §1–§2 の看板であり、§13.3 path (a) の固有性質 (ii) の
   一角。自己維持ループはまさにその散逸を壊す。
2. **forward-only credit を失う（決定的）**。フィードバックは **$\theta$ を貫く時間再帰**を作るので、§7.1 の「場が固定
   ゆえ $\partial L/\partial\theta$ は各時刻の静的勾配の時間和」という論理が崩れ、**BPTT が必要になる**。BPTT 回避は
   NG-RC/LMU に対する本系最大の固有性（§7.2・§13.3）なので、素朴なフィードバック導入は**存在理由の半分を捨てる**。

（標準 RC で出力フィードバックが不安定化・ESP 喪失を招くのと同じ問題。§10.11 で「出力フィードバックは使わず ESN と
フェアに比較」としたのもこの理由。）

**折衷案＝時間スケールの分離（推奨）**：散逸する高速経路と、離散的に保持する低速経路を分ける。

$$\underbrace{\text{散逸ノイズ場}}_{\text{ESP・連続値・}\sigma\to0\text{・短中期}}\ +\ \underbrace{\text{少数の低速ゲート状態}}_{\text{フィードバックで自己維持・離散的・長期}}$$

- 場（LDN/カスケード）は従来どおり散逸＝**ESP を速い変数について保つ**（条件付き ESP）。
- 別に少数の**低速フィードバック変数（文脈フラグ）**を置き、それが $\sigma$ のバイアス、あるいは**相関 $\rho$**（§14）を設定する。
- BPTT を低速変数に限定する（さらに低速変数を離散化・固定すれば forward-only を保てる）。

**§14（共分散変調）との接続＝本命の合流点**：この低速ゲート状態が担うべき役割は、まさに
**「文脈が"どの結合を有効にするか"を長期保持し、共分散変調がそれを実装する」**である。すなわち
(i) 記憶＝場（散逸・短中期）＋低速フラグ（イベント駆動・長期）、(ii) 結合＝共分散変調（動的な再配線）、
(iii) 生物対応＝神経修飾/STP が文脈を保持しつつ実効結合を変える、が一つの物語に収まる。§14.3 のゲート課題は
現状**全ラグを場の射程内に置いた「結合の課題」**（記憶の課題ではない）だが、ここを
**「文脈が結合の設定として長期保持され、後続の入力対に適用される」**形へ拡張すれば、**記憶と結合が協調しないと
解けない課題**になり、本節の論点と §14 が直結する。

**優先度**：現在の path (a)（(ii) 固有性質で立てる）を固める前に手を広げるのは危険なので、**共分散変調（§14）より後**。
ただし**「特定時刻のイベント保持」は本構想の最重要の未解決課題**として明示的に残す（fading memory の原理的限界であり、
ここを解く設計＝時間スケール分離は、多安定（§6）・neuromod のアドレッシング・consolidation の資源制御を束ねうる）。

## 7. 何を固定し、何を学習するか（RC の規律と本プログラムとの整合）

- **固定（リザバー）**：ネットワーク重み $\theta$、場の力学 $F$（$D,\gamma$ 等のハイパー）、
  交差非線形。$\theta$ はランダム固定でも、事前学習済み（バンプ辞書を張った状態）でもよい。
- **学習（読み出し）**：時間軸線形結合 $W_{\text{out}}(t)$ あるいは汎関数の $\beta(t)$。
  線形なのでリッジ回帰で閉形式、**backprop 不要**。
- **売り**：リザバーは無学習、読み出しは線形＝凸。NCE の forward-only 学習・FPGA の安価な
  オンチップ学習と同じ思想の上に乗る。「学習は場のダイナミクスの外側の 1 枚だけ」という
  極端に軽い学習が、`idea_fpga.md` のハードウェア物語と直結する（場は LFSR/拡散カーネルで
  生成、読み出しは running sum の線形回帰）。

### 7.1 credit の 3 層分解 — 交差ネット θ は BPTT なしで学習できる（2026-07-25 追記）

標準 RC が読み出ししか学習しないのは、再帰が結合重みにあり、その訓練に BPTT が要る（高コスト・
勾配消失）ため。**本系は再帰が θ に無い**ので事情が変わる。credit の必要性は 3 層に分解する：

| 層 | 時間的性質 | 必要 credit | 既定の扱い |
|---|---|---|---|
| 場の力学 $M=I-\Delta t(D\mathcal L+\gamma I)$ | 再帰的（メモリの所在） | 訓練するなら BPTT | **固定（リザバー役）** |
| 交差ネット $\theta=(w,b)$ | **各時刻で静的** $z(t)=f(x;\theta,\sigma(t))$ | **BPTT 不要**・静的勾配 | **cov_jac/BP で学習可** |
| 線形読み出し $W_{\text{out}}$ | 静的線形 | 自明 | 学習（ridge/LMS） |

$\theta$ は損失に各時刻の観測を通してしか効かず、**$\theta$ を貫く時間再帰が無い**ので $\partial L/\partial\theta$
は各時刻を独立サンプルとした静的勾配の時間和になり、時間展開が要らない。これは cov_jac（転置重み
backward なしに交差へ credit を配る forward-only 則）が作られた状況そのもので、各時刻に $\sigma(t)$ を
与えて NCE の学習則を適用するだけで $\theta$ を訓練できる（読み出しミラーは cov_weight）。

**含意（系の格上げ）**：標準 RC「固定リザバー＋線形読み出し」→ 本系「**固定の場（メモリを無償供給・
BPTT 不要）＋学習される feedforward 非線形写像 $\theta$（cov_jac・forward-only）＋線形読み出し**」。
RC より表現力が高く BPTT フリーのまま、RC と RNN の中間の独自ポジション。留保：場のパラメータ
$(D,\gamma,w_{\text{in}})$ は再帰的なので訓練には BPTT が要る → 固定が自然（§19 の場 credit 経路と地続き）。
§10.2 A2 で交差が非線形優位を示さなかったのは $\theta$ 固定ランダムのための可能性が高く、$\theta$ を
cov_jac 学習すれば「場ゲート下の RBF 辞書をタスクに合わせて配置」でき、解消しうる（次の検証項目）。

### 7.2 【本取り組みの最重要主張・要再訪】「特徴学習は不要」への反証

> **賭け金（一文）**：本取り組みの最も重要な問いは、「ESP を持つ非線形ダイナミクスが十分に複雑なら
> 読み出しだけの学習で足りる（特徴＝リザバーの学習は不要）」という Reservoir Computing の一般化主張に、
> **BPTT フリーな forward-only 特徴学習が明確なカウンターを与えられるか**である。これを示せない限り、
> 本系は「ノイズ場という基質で RC を再現しただけ」に**吸収**される。**この反証がこの取り組みで最も
> 重要な点**であり、必ず再訪する。**

**立場の整理**。RC の価値は本物だが、それは **BPTT の困難（コスト・不安定）への実務的な妥協**としての
価値である。「特徴を一切学習しなくてよい」を**原理**として一般化することはできない（十分複雑な固定
リザバー＋読み出しは万能近似だが、それは「原理的に可能」であって「学習が不要」ではない）。

**本系が唯一この反証を張れる理由**。標準 RC が特徴を凍結するのは、再帰が結合重みにあり特徴学習に
BPTT が要るからだった。本系は再帰が場にあり **特徴 $\theta$ を BPTT なしで学習できる**（§7.1、勾配コサイン
1.0 で実証）。RC が特徴凍結を正当化する理由（BPTT の困難）そのものが消えるので、「**同等の複雑さの
固定リザバーに対し、特徴を学習した方が勝つか**」を正面から検証できる立場にある。

**option 1（§10.3）の警告**。NARMA では良条件で学習 $\theta$ が読み出しのみ（線形場）を超えなかった。
これを放置すると「固定の場が十分複雑だっただけ、特徴学習は何も足していない」という RC の主張に**そのまま
吸収される**。吸収を避けるには、次のいずれかを**公正な比較**（リザバー規模・パラメータ数・計算量を揃える）
で示す必要がある：

1. **能力の反証**：読み出しのみが（どんな妥当な規模の固定リザバーでも）頭打ちになる課題で、forward-only
   特徴学習がその天井を超える。候補＝固定ランダム基底では表現に莫大な幅を要するタスク（パリティ様、
   入力適応的な基底配置を要する作用素、`idea_multivalued` 的な分岐）。
2. **効率の反証**：同じ誤差に達するのに、学習特徴は固定特徴より**遥かに少ないユニット数**で足りる
   （特徴学習＝複雑さ/資源の勝ち）。学習 $\theta$ と固定 $\theta$ の「誤差 vs ユニット数」曲線の乖離で示す。

**したがって option 2（真の確率的 cov_jac ＋ 特徴学習が原理的に必要な課題）は、本系が RC を超えて
新しいことを言えるか否かを決める要石**である。option 1 で機構（BPTT フリー credit）は確立したので、
残るのは「その機構が読み出しのみを**明確に上回る土俵**を作れるか」。これを Tier B/C の中で最優先の
科学的問いとして扱う（実装は forward-only の sample 交差版 cov_jac＝`nnn.credit` の cov_weight/
covariance_credit を本流用、比較は規模を揃えた読み出しのみ RC）。

## 8. ゲージ問題と正直な難所

1. **ゲージ冗長性**：$\sigma$ の**大域スケール**は重みスケールと冗長（`idea_consolidation.md`
   §3、`idea_duality.md` §12）。したがって情報を運ぶのは場の**全体強度ではなく形状**であり、
   読み出しはゲージ不変な特徴（交差率 $\nu$、場の空間パターン）を拾う必要がある。**ただしこの懸念は
   RC では大幅に軽い：$\theta$ 凍結が既にゲージを固定し、$\sigma$ スケールは本物の DOF になる（§12-I,II）。**
   $\rho$ を状態にする利点は残るが（$\rho$ はゲージ横断的な座標なので不変量 $h/\sigma$ を動かせる。
   ゲージ不変な**観測量**は交差率 $\nu$ であって $\rho$ そのものではない点に注意。§5.6）、
   主目的は難所5（厳密休止）であって冗長性除去ではない。
2. **原点アトラクタの退化**：$\sigma\equiv0$ 漸近そのものは情報ゼロ。richness は過渡と空間
   構造に全面依存する。「初期条件だけ変調＋単調減衰」だと、異なる入力の軌道が似た減衰に潰れ
   分離が悪い。**入力は初期条件だけでなく力学（ソース・ドリフト・$D$）を変調すべき**（§5.3）。
3. **ESP の証明条件**：線形漏れは自明に収縮。反応拡散では $R(0)=0$ と漏れ支配の線形化で
   大域安定を担保する条件を明示する必要がある（Lyapunov 関数 $\int\sigma^2$ の単調減少など）。
4. **「単なる時間変化するランダム特徴」との差別化**：拡散・反応が与える構造的過渡が、
   ランダムな時間特徴より有用であることを memory capacity／作用素近似誤差で示す必要がある。
5. **深い層の休止**：完全な出力ゼロ化には $h$ ゲート併用。**解決＝§5.6：状態を $\rho=(\sigma,h)$
   にすれば深い層でも有限パラメータで厳密に $\nu\equiv0$ に達し、「空の貯水池」＝真のゼロ出力
   アトラクタが厳密になる。** これを怠ると「決して完全には静止しない」ことが ESP の主張を弱める。

### 9.1 ノイズ場は何に対応するか — 神経修飾以外の対応候補

ノイズ場 では場が各ユニットの**加法ノイズ強度** $\sigma_k(t)=\text{floor}+\text{softplus}((MA)_k+c_k)$ を決める。
つまり場が担う機能形式は「**入力の減衰する記憶を保持し、その値でユニットの利得／変動性（σ）を変調する、
ユニットごとのスカラー**」。この「**入力駆動の漏れ性メモリ ×（利得/変動）変調**」を満たす神経パラメータは
神経修飾（濃度＝拡散）以外にも複数あり、しかも**LDN/カスケードに素直に載る（時間的・シナプス局所で
空間拡散を要さない）**ものがある。神経修飾は拡散場に合うが LDN/カスケードには載りにくかった（§10.14–10.15、
§5.7 実行報告）ので、後者に載る対応こそ有用。

| 神経パラメータ | 満たす条件 | 相性の良い場 | 文献の錨 |
|---|---|---|---|
| **短期シナプス可塑性（STP＝促通/減弱）** | 記憶＋乗法的な利得変調 | **LDN・カスケード・遅延線** | Mongillo, Barak & Tsodyks 2008（synaptic working memory）；Tsodyks–Markram |
| 樹状突起ケーブル濾波 | 濾波（記憶）＋局所利得 | **カスケード**（$a^i u(t-i)$＝逐次減衰に最 literal） | 受動ケーブル論 |
| 細胞内 Ca²⁺／適応電流（AHP・SK/M） | 活動の漏れ積分＋興奮性低下 | 任意の時間場・減衰直交（指数） | 適応電流 |
| 背景シナプス入力（high-conductance state） | σ（膜電位分散）と利得を直接 | 任意（σ に直結） | Chance, Abbott & Reyes 2002 |
| アストロサイト Ca²⁺波（グリア） | 遅い**空間伝播**＋修飾 | カスケード・移流・2D 拡散（進行波） | グリア Ca²⁺ 波 |
| 神経修飾物質濃度（既出） | 濃度＋利得（容積伝達） | **拡散**（1D/2D） | volume transmission |

- **最有力＝短期シナプス可塑性（STP）**：前シナプス活動の残余 Ca²⁺（促通）／小胞枯渇（減弱）が**減衰する
  痕跡（記憶）**を保持し、シナプス効率（利得）を乗法的にスケールする＝場の役割そのもの。Mongillo 2008 の
  「ワーキングメモリを STP で保持」説は本系の分業（**記憶＝場／非線形計算＝回路**）と直接対応し、**時間的・
  シナプス局所なので LDN（窓の最適表現＝理想化 STP メモリ）・カスケード（減弱シナプスの鎖）にこそ自然に載る**。
  促通(~100ms)と減弱(~秒)で**多時定数**も出る。→ 神経修飾（拡散）で苦しかった LDN/カスケードを救う対応。
- **σ そのものの由来を厳密に言うなら背景シナプス入力**（Chance-Abbott-Reyes：背景入力が膜電位分散＝σ と
  利得を同時に決める）。拡散を要さず「場→σ→利得/ノイズ」を機構的に最も直接に裏づける。
- **神経修飾以外の空間場**が欲しければアストロサイト Ca²⁺波（進行波＝カスケード/移流/2D）。

**正直な留保**（§13.4 の教訓）：いずれも「**同じ機能形式を持つ**」水準の対応。「である」と主張するなら実測の
時定数・シグネチャ（STP なら促通/減弱時定数、背景入力なら分散-利得関係）との桁整合を確かめて水準を決め、
照合前は「**同じ計算的役割を担いうる基質**」と書く。実装での裏づけは §10.22（STP 場）で行う。

### 9.2 橋渡しの明示：LDN ＝直交化された理想 STP メモリ

生物対応の一連の検証（拡散＝§5.7、STP＝§10.22–10.23）で、**生物的に忠実な基質は記憶が薄く（拡散・STP とも
MC≈5–9）、高性能な場（LDN・カスケード, MC 38–47）は直交化された理想化基底で生物的地位が弱い**、という
トレードオフが基質一般に確定した。この二律背反を**主張の水準で解消する橋渡し**が「**LDN ＝直交化された
理想 STP メモリ**」である。以下がその論拠：

1. **同じ機能クラス**：STP も LDN も「**入力の直近の窓を減衰保持し、その状態でユニットの利得／σ を変調する
   分散メモリ**」。STP は各シナプスの促通/減弱、LDN は窓の Legendre 係数として保持する。役割（ノイズ場 の場）は同一。
2. **STP＝ill-conditioned な窓メモリ**：STP バンクは各シナプスが**指数漏れ積分器**で、時定数が near-collinear
   ＝有効ランクが低い（MC≈6, §10.22）。生の生物基質は窓を**悪条件**にしか保持しない。
3. **LDN＝その最適・直交化版**：LDN は「長さ $\theta$ の遅延窓を $d$ 状態で表す**最適線形系**」（Padé/Legendre 由来）で、
   **直交基底・相異なる時定数**ゆえ有効ランクが高い（MC≈38）。すなわち LDN は STP が担う「直近の窓の保持」を
   **well-conditioned に実現した理想化**にほかならない。
4. **理路**：$\text{STP}$（生物的に literal・悪条件）$\xrightarrow{\text{直交化／最適条件化}}\text{LDN}$（同じ窓メモリ・
   高条件・高性能）。LDN を「**回路が直交化したときに STP が計算するもの**」と読めば、**生物学的忠実さ（STP 基質）と
   性能（LDN の条件数）を同一の物語で両立**できる。神経修飾（拡散）で苦しかった時間場の生物対応が、STP 経由で
   LDN/カスケードに接続される。
5. **正直な留保（§13.4 の水準）**：これは**機能的・数学的な橋渡し**であって「脳が LDN を実装する」主張ではない。
   誠実な水準は「**LDN は STP ワーキングメモリと同じ機能クラスの、最適に条件化されたメモリである。神経回路が
   その条件化にどこまで近づくかは実証問題**」。§10.23 で単純な再帰 STP が散逸域で直交化を達成しなかった（むしろ
   悪化）ことは、この「直交化」が再帰で自明に出るものではなく**設計された理想化**であることを裏づける。

**含意**：論文の生物学パートは「**記憶は短期シナプス動態（STP）に保持され、回路が非線形読み出しする**」（Mongillo 2008
の系譜）とし、**その STP メモリの最適条件化版として LDN を用いる**——と書ける。カスケードは同じ橋渡しの「明示的
遅延鎖（樹状突起ケーブル／synfire）版」。これで §13.3 path (a) の (ii) 固有性質（乗法ノイズ・SR・forward-only・ESP）に
**生物学的接地**を、性能を犠牲にせず接続できる。

**C. 場→σ／利得の変調（両場に共通、どの記憶構造とも組める）**

- 神経修飾（NE/ACh/DA/5HT）が利得を設定（Aston-Jones & Cohen 2005 の NE adaptive gain）。
- 背景シナプス入力（high-conductance state）が膜電位分散＝σ を直接設定（Chance-Abbott-Reyes 2002; Destexhe）＝**σ の由来として最直接**。
- 除算正規化/抑制性利得制御（Carandini-Heeger）、STP のシナプス利得スケール、アストロサイトによる利得/ノイズ修飾。

**最有力の物語**：**カスケード＝樹状突起ケーブル/軸索遅延線（A2/A3）**、**LDN＝時間細胞（B1）／Laplace 時間記憶
（B3）／小脳顆粒層（B5）**。とくに **B5 小脳型アーキ**は「顆粒層＝時間基底の場／Purkinje＝線形読み出し」で
**Ours 全体（ノイズ場＋線形読み出し）に最も直接対応**し、Marr-Albus 以来の確立した計算論を土台にできる。σ 変調側は
背景シナプス入力（C）が最直接。**正直な留保（§13.4）**：いずれも「同じ機能形式」水準で、B1 時間細胞は Weber 照合で
不整合（§13.4）ゆえ「時間細胞である」ではなく「時間窓を直交タイルする基底・機能的役割は同等」と書く。主張前に実測
シグネチャ（時定数・受容野幅スケーリング・遅延線の伝導速度）との桁整合を確認する。

### 10.1 ベンチマーク案（3 層＋較正の姿勢）

RL 稿 §20.14 と同じく、**Tier A は「勝つ土俵」でなく標準 RC として成立することの較正**、
Tier B/C で本アイデア固有の差（関数値の読み出し＝汎関数 RC）を示す。標準 ESN の線形読み出しは
状態→**固定次元ベクトル**しか出せず、任意クエリ $x$ で連続関数を出すには読み出しを $W_{\text{out}}(x)$
＝trunk net にする（DeepONet を継ぎ足す）しかない。本系は交差ユニットのバンプ応答で
$\phi_t(x)=f(x;\theta,\sigma(t))$ を**ネイティブに連続関数として**出せる — これが categorical な差。

**Tier A — 標準 RC との較正（スカラー目標・観測 = 活性 $z(t)$）**
1. **記憶容量 MC（Jaeger）**：$k$ ステップ前の入力を線形再構成し $MC(k)$。同サイズ ESN と比較。
   §12 補足の「拡散モードの減衰スペクトル＝記憶プロファイル」を直接可視化（$\gamma$ で記憶深度 ⇄
   非線形性の綱引き＝edge-of-chaos）。
2. **NARMA-10 / Mackey–Glass**：非線形時系列予測の定番。ESN と NRMSE 比較。**期待は同等〜やや劣**。
3. **ESP 検証**：異なる初期場から同一入力列 → 軌道収束（初期条件忘却）を距離減衰で示す。

**Tier B — 汎関数/作用素目標（各時刻に関数 $\phi_t(x)$ を出す。本アイデアの芯）**
4. **作用素学習（関数→関数）**：入力 $u$ が場を変調、目標は出力**関数** $\Psi_u(\cdot)$（微分・積分
   作用素、$\sin$ 族の族間写像など）。比較対象 **DeepONet（学習 trunk）**。売り＝trunk を無学習の
   散逸場が供給し、学習は線形読み出しだけ。
5. **モーフィング関数の再現**：目標が時間で連続変形（進行波 $\sin(x-ct)$、動くバンプ）。各 $t$ で
   空間プロファイル全体を場の軌道から再構成。「各時刻に関数を吐く」を最も素直に見せる。
6. **SR 曲線（リザバー版）**：場の強度に対し性能が逆 U 字（内点最適）。`idea_neuromod.md` の SR を
   時間軸へ移し「ノイズは資源」を本文脈で再現。

**Tier C — 「標準 RC には原理的に無理/不自然」を見せる切り札**
7. **解像度非依存の超解像読み出し**：読み出しを**粗いクエリ格子で学習 → 細かい格子でゼロショット
   評価**。$\phi_t(x)$ が連続なので超解像が効く。固定ベクトル出力の ESN は原理的に不可能。最も
   切れ味のよい「不可能」実証で実装も軽い。
8. **関数の記憶（functional MC）**：#1 のスカラーを**関数**に拡張＝$k$ ステップ前に見た入力**関数
   全体**を再構成。スカラー読み出し RC は復号器なしには構造的に不可能。
9. **PDE 解作用素のエミュレーション＋ロールアウト**：初期条件 $u_0(x)$ を入力に、解 $u(x,t)$ を
   関数として時間展開。作用素学習×時間ロールアウトの本丸。FNO/DeepONet（全学習）に対し
   「力学生成の基底＋線形読み出し」で挑む。
10. **場アドレッシングによる作用素多重化**（neuromod 稿接続）：入力モードで場が別アトラクタへ落ち、
    1 つの重み集合上で作用素の族を切り替える（§6 多安定版の実証）。

**推奨着手順**：**1+3（成立とESP）→ 7（超解像）→ 4（作用素学習）**。7 は軽量で「標準 RC には無理」を
最短で示せ、4 は DeepONet という明確な比較対象で主張を定量化できる。8/9 は主張最強だが実装が重く、
7/4 で手応えを得てから。**較正の留保**：狙いは DeepONet/FNO に精度で勝つことでなく、無学習の
力学生成基底＋線形（forward-only）読み出しで汎関数 RC が成立することと、7/8/9 の categorical な差。

### 10.2 探索の経緯（2026-07-25、要約：多くは負／撤回、スクリプト削除済）

現行 混合ノイズ場 に至る前に試した方向と、そこから**正しく残った教訓**（詳細レポートと対応スクリプトは削除、要点のみ）：

- **試した方向（いずれも現行モデルには不採用）：** Tier A 較正（ESP・記憶容量＝標準 RC 成立の確認）／交差ネット
  θ の forward-only 学習／超解像読み出し（Tier C-7）／key experiment（作用素・移動波の表現）／効率の反証
  （制約サイズで学習写像 > 線形読み出し）／**再帰交差リザバー＋BPTT**。
- **正しく残った教訓：**
  1. **forward-only credit は autograd と勾配 cosine=1.0** ＝場を固定すれば θ の $\partial L/\partial\theta$ は各時刻の
     静的勾配の時間和で、**BPTT 不要**（§7.1 の数値確認）。これは現 混合ノイズ場 の学習則の基盤。
  2. **交差バンプは前活性方向に立ち、ノイズ $\sigma$ には単調にしか効かない。** ゆえに「場を $\sigma$ 変調・入力固定」
     の素朴版は $u$ 選択的な演算子や積を作れない → これが 対角ノイズ場 の **GAM 制約**（§10.18–10.19）の起源であり、
     **混合 $M$ で解消**することの理由。
  3. **§10.7 の悲観的メタ総括「構想全体の戦略的再評価が要る」は誤りだった。** 律速は「特徴学習が無力」ではなく
     **場が記憶を持たない（非再帰）／場の設計**にあり（§10.8 で判明・撤回）、勝ち筋は再帰＋BPTT ではなく
     **固定散逸メモリ場＋ノイズ変調写像**（§10.11 以降）だった。
- **要するに：** BPTT を避けて「記憶＝無学習の力学場、非線形＝forward-only 学習写像、読み出し＝線形」に切り分ける
  という当初の狙いは正しく、律速だった**場の設計**（§10.11–10.15）と**場→ノイズの結合**（§10.18–10.21）を詰めて
  現行 混合ノイズ場 に到達した。

### 10.10 実行報告（2026-07-26 実施）：長期記憶の調査 — 記憶容量では優位、NARMA では未確認、清潔な試験は遅延タスクへ

**ユーザ仮説**：RC/ESN はリザバーに**非線形性と記憶を同居**させる（謳い文句に反し長期記憶が困難）。
本方式は**非線形性＝NNN・記憶＝（線形）ノイズ場に分担**するので、長期記憶で有利なはず。NARMA-$n$ の
$n$ を上げると ours と ESN の差が広がると予測。

**可視化（1・3 完了）**：
- **アーキ転換図**（`architecture.png`, 5 seed）：**非再帰は 0.888 で全 $H$ 平坦**（交差が非再帰状態を
  観測＝記憶なし）、再帰で記憶が形成され降下、ours（再帰＋学習写像）が RC を小 $H$ で上回る。§10.8 の
  「再帰が要る」が一目で分かる。
- **多 seed 効率図**（`summary.png` を 7 seed に更新）と、6 面図（波形・残差・効率・利得・学習・変種）。

**長期記憶（2）第1報 — 素朴な NARMA-$n$ では仮説は未確認（正直な負）**：`tmp/reservoir_longmem.py`。
線形場（sr=0.98）＋学習 NNN 写像（ours）vs ESN vs 線形場＋線形読み出し、$H$=80、NARMA-5〜40。

| NARMA-$n$ | ours（線形場+写像） | ESN | 線形場+線形 |
|---|---|---|---|
| 10 | 0.636 | **0.610** | 0.632 |
| 20 | 0.702 | **0.657** | 0.679 |
| 40 | 0.771 | **0.745** | 0.777 |

  状態が肥大し予測発散（NRMSE 23）＝数値的脆さのバグ（sr を下げれば解消）。

  長い」という機構は確認**された。
- **診断**：NARMA は**非線形な再帰**（$y$ が自分の過去の非線形関数）で、非線形リザバー（ESN）に構造的に
  有利。線形記憶＋**静的**非線形写像では再帰的非線形性を再現しにくい。**NARMA は仮説（長期線形記憶＋
  分離可能な静的非線形性）を清潔に試す課題ではない**。

**清潔な試験＝純粋な線形記憶タスク（仮説を確認）**：$\sin(2\pi u)$ は $u$ の全周期を振る過度な非線形性で
全手法が学習不能（NRMSE≈0.8–1.06）だった。非線形性の交絡を排し、**純粋な線形記憶** $y(t)=u(t{-}D)$
（$u$ i.i.d.、線形読み出し）で記憶基質だけを比較（`tmp/reservoir_delaytask.py`, `delaytask.png`, 5 seed）：

| $D$ | 線形場 NRMSE | ESN NRMSE | 線形場の優位（ESN−lin） |
|---|---|---|---|
| 2 | 0.773 | **0.745** | −0.028（ESN 優位） |
| 10 | 0.895 | 0.893 | −0.003（交差点付近） |
| 24 | **0.936** | 0.956 | +0.020 |
| 50 | **0.956** | 0.990 | **+0.034** |

- **短遅延（$D\le10$）では ESN が僅かに優位、$D\approx12$ で交差、長遅延では線形場が優位で、その優位が
  $D$ とともに単調に拡大**（$D$=50 で +0.034）。**ユーザ仮説（記憶を線形場に分担すれば長期記憶で有利）を
  直接確認**した。
- **機構**：memory capacity は線形場 MC≈9 ＞ ESN 6、MC($k$) も線形場が長い遅延まで保つ（tanh の飽和が
  ESN の長期記憶を削る）。図は (a) 誤差 vs $D$、(b) 優位が $D$ で拡大する棒、(c) MC($k$) の 3 面。

**長期記憶調査の総括**：ユーザ仮説は **2 段で成立**した — (i) **機構**：線形場は非線形（tanh）リザバーより
長い記憶を保ち、その差は遅延深さで拡大（純粋記憶タスク・MC で確認）。(ii) **限界の明確化**：NARMA の
ように**非線形性が記憶と再帰で絡む**課題は非線形リザバーに有利で、線形記憶＋静的写像では逆転しない。
**「長期の線形記憶＋分離可能な静的非線形性」を要する課題でこそ本方式が効く**、という条件が定まった。
残：長期線形記憶＋**学習可能な**分離非線形性を併せ持つ課題での lin+map vs ESN+map（$\sin(2\pi u)$ は過強、
より温和な非線形性で再挑戦）。longmem 図(a) の NARMA-30 は sr=0.98 の線形場が不安定で発散（sr を下げる）。

### 10.11 実行報告（2026-07-26 実施）：ノイズ場設計が決定的 — 遅延線場の Ours-sep が NARMA で ESN を圧倒（§10.10 の負を反転）

**ユーザの指摘**：Ours = Ours-sep（分離型）であり、その性能は**ノイズ場のダイナミクスをどう与えるか**で
決まる。出力フィードバックは使わず、ESN とフェア（両者 u 駆動のみ）に比較すべき。

**検証**：ノイズ場の設計だけを変えて Ours-sep（線形場 ＋ NNN 写像、forward-only）を比較（`tmp/
reservoir_fielddesign.py` → `tmp/reservoir_narma_final.py`, `narma_final.png`, $H$=48, 安定 NARMA-x）：

| NARMA-x | ESN | Ours（ランダム場） | **Ours（遅延線場）** | 優位（ESN−遅延線） |
|---|---|---|---|---|
| 10 | 0.582 | 0.796 | **0.251** | **+0.331** |
| 20 | 0.660 | 0.820 | **0.266** | **+0.394** |
| 30 | 0.691 | 0.839 | **0.260** | **+0.431** |
| 40 | 0.704 | 0.846 | **0.292** | **+0.412** |
| 50 | 0.745 | 0.861 | 0.790 | −0.045（容量超過） |

- **ノイズ場設計が決定的**：同じ Ours でも、**ランダム線形場では ESN に負ける（0.80）が、遅延線場
  （$x[t,i]=u(t{-}1{-}i)$＝各 u ラグをクリーンに保持する最適線形記憶）では ESN を圧倒**（0.25–0.29）。
  ランダム場はラグを混ぜて写像が抽出できないが、遅延線は全ラグを NNN 写像に**クリーンに**渡すので、
  NARMA の積項 $u(t{-}x)u(t{-}1)$ 等を正確に計算できる。ユーザの「場の与え方で決まる」が数値で実証された。
- **優位は memory order $x$ とともに拡大**（+0.33→+0.43）：ESN は tanh 結合の記憶が $x$ で劣化するのに対し、
  Ours（遅延線）は容量内では低誤差を保つ。**「$x$ を増やすと大きなアドバンテージになるか」への答えは YES**
  （容量内で）。
- **$x$=50 の崩れは容量限界（$H<x$）**：遅延線 $H$=48 は 48 ラグしか保持できず、NARMA-50（50 ラグ必要）で
  破綻。**$H$=64 にすると NARMA-50 で Ours=0.30 対 ESN=0.72 と復活**（確認済み）。よって条件は **$H\gtrsim x$**
  のみで、場を大きくすれば任意の $x$ で勝てる。

**機構（なぜ分離が勝つか）**：ESN は記憶と非線形性を tanh に**同居**させるため、記憶が飽和・ランダム混合で
劣化し、最適な記憶構造を選べない。Ours は**記憶（場）と非線形性（NNN）を分離**しているので、**最適な記憶
構造（遅延線＝完全な線形記憶）を場に選べる**。この自由度が、記憶が深い（$x$ 大）ほど効く。§10.10 の「NARMA
では ESN 有利」は、**ノイズ場をランダムにした場合の限定的な結論**であり、場を正しく設計すれば反転する
（ユーザの指摘が正しかった）。**Ours-sep の分離アーキが、fair・feedback なし・forward-only で ESN を
NARMA で明確に上回る、コンセプト実証が成立した。**

### 10.12 実行報告（2026-07-26 実施）：暗黙の長記憶ノイズ場 — 直交場は長記憶を持つが、写像には「解けた」記憶が要る

**ユーザの問い**：遅延線は過去を**明示的に**保存する(自明)。より説得力があるのは、**一見丸ごと保存
しないが、長い入力履歴が場のユニークな発展を生む＝暗黙の長記憶**を持つノイズ場。それで ESN に勝てれば
Ours の主張がより一般的になる。

**候補＝直交(回転)線形場**：$W$ を乱数直交行列、$x(t{+}1)=\rho W x(t)+w_{\text{in}}u(t)$（$\rho$=0.99）。
入力を高次元へ回転して分散保持するので、各ユニットが全履歴の**混合**になる(遅延線＝巡回シフトは特殊な
直交行列)。実装 `tmp/reservoir_goodfields.py`（`OrthogonalField`, `goodfields.png`, $H$=48）。

| 場 | 総 MC | NARMA-10 | NARMA-20 | NARMA-30 |
|---|---|---|---|---|
| 遅延線（明示） | 48.0 | **0.251** | 0.266 | 0.260 |
| **直交（暗黙）** | **35.2** | 0.755 | 0.710 | 0.761 |
| ランダム | 6.4 | 0.796 | 0.820 | 0.839 |
| ESN | 5.9 | 0.582 | 0.660 | 0.691 |

- **暗黙の長記憶は実在する**：直交場の MC($k$) は $k$=70 まで $\approx0.5$ を維持（総 MC=35.2）。ランダム
  (6.4)・ESN(5.9) が $k$=20 で消えるのに対し、**丸ごと保存せずとも長い履歴を分散保持**している。遅延線は
  $k\le48$ で MC=1.0 の断崖（明示的シフトレジスタ）。ユーザの言う「暗黙の長記憶ノイズ場」は直交場で実証。
- **しかし直交場は NARMA で ESN に届かない**（0.71–0.76 対 ESN 0.58–0.69、遅延線 0.26 とランダム 0.80 の
  中間）。**高い MC（線形記憶）は NARMA の勝ちを保証しない**。
- **機構（重要な設計原理）**：NARMA は特定ラグの**積** $u(t{-}x)u(t{-}1)$ を要する。遅延線は各ユニット＝
  1 ラグで**解けている**ので、NNN 写像は 2 ユニットを掛けるだけ。直交場はラグが**回転で絡んでいる**ため、
  写像はまず逆回転で解いてから積を作らねばならず、単層の交差写像には荷が重い（線形読み出しなら MC が
  示す通り解けるが、非線形の積抽出は難しい）。**「良いノイズ場」＝長記憶(MC)＋写像が使える解けた表現**、の
  二条件が要る。遅延線は両方、直交場は前者のみ。

**含意と次の一手**：暗黙の長記憶は作れる（直交場）が、それを **NNN 写像が非線形抽出できる形**にするのが
次の設計課題。候補：(i) 直交場＋**深い/二層の**交差写像（逆回転を層で学習）、(ii) 直交でも**局所的に
解けた**構造を持つ場（帯行列・複数時定数の減衰など、混合を抑えつつ長記憶）、(iii) 場の $W_1$（写像の
線形前段）が逆回転を学べるよう初期化/正則化。**目標＝「明示的な遅延線でなく、暗黙に長記憶を持つ場でも
ESN に勝つ」**を成立させ、Ours の主張を一般化する。

### 10.13 実行報告（2026-07-26 実施）：暗黙かつ「解けた」長記憶場 — Legendre 遅延網が ESN を破る

**direction 1（直交場＋深い写像）＝失敗**（`tmp/reservoir_deepmap.py`）：orth+2 層写像（0.72–0.76）は
orth+1 層（0.71–0.76）と**同じ**。ボトルネックは写像の深さでなく**場の絡んだ表現**。診断：遅延線の巡回
シフトは各ラグ方向を**直交**にする（各ラグが別ユニット）ので写像がクリーン抽出できるが、一般の直交場は
$Q^k w_{\text{in}}$ が互いに直交せず**ラグ間クロストーク**を生むため、どんな写像でも個別ラグを取り出せない。
「解けた」＝**ラグ方向が分離可能**、と判明。

**direction 2（暗黙かつ分離可能な場）＝ LDN で成立**（`tmp/reservoir_implicitfields.py`, `implicitfields.png`）：

| 場 | 総 MC | NARMA-10 | NARMA-20 | NARMA-30 | NARMA-40 |
|---|---|---|---|---|---|
| 遅延線（明示） | 48.0 | 0.251 | 0.266 | 0.260 | 0.292 |
| **Legendre LDN（暗黙）** | **39.8** | **0.214** | **0.359** | **0.406** | **0.424** |
| multiscale バンク（暗黙） | 7.6 | 0.602 | 0.693 | 0.719 | 0.728 |
| ESN | 5.9 | 0.582 | 0.660 | 0.691 | 0.704 |

- **Legendre Delay Network（LDN, Voelker 2019）が ESN を全次数で上回る**（0.21–0.42 対 0.58–0.70）。LDN は
  入力の窓を**直交多項式（Legendre）の係数**として表現する — **暗黙**（どのユニットも生の遅延を持たず、窓を
  圧縮した holistic な符号）かつ**分離可能**（直交多項式なので写像がラグを再構成できる）。MC=39.8、MC($k$) は
  窓 $\theta$=60 まで $\approx0.5$–0.7 を保ち $\theta$ で断崖。**「一見丸ごと保存しないが暗に長記憶を持つ場」で ESN に
  勝つ**、というユーザの狙いが LDN で実証された。ZOH（行列指数）離散化が安定化の鍵（Euler は発散）。
- multiscale バンク（指数カーネル）は MC=7.6 と低く ESN 同等止まり — 指数時定数が near-collinear で有効
  ランクが低い。「暗黙」でも**分離可能（well-conditioned）でなければ**駄目、という §10.12 の原理を裏づける。

**総括（良いノイズ場の条件）**：Ours-sep が ESN を破るノイズ場の条件は **(1) 長記憶（高 MC）＋ (2) 写像が
使える"解けた"＝分離可能な表現**。遅延線（明示・分離）と **LDN（暗黙・分離）**は両立、直交（暗黙・非分離）と
multiscale（暗黙・低容量）は不成立。**分離アーキ（記憶＝場、非線形性＝NNN）は、trivial な遅延線を超えて
原理的な暗黙記憶場（LDN）でも ESN を破る**、とコンセプトが一般化した。

### 10.14 実行報告（2026-07-26 実施）：散逸（ゼロへ減衰する）ノイズ場 — §2 の原点へ回帰、生物学的アナロジー

**ユーザの指摘**：遅延線・直交場は（ほぼ）非散逸（値を保持/回転するだけ）。§2 の原点は「どんな初期状態
からもゼロへ減衰する散逸系＝ESP」。**散逸的な場**で長記憶を保ち ESN を破れるか、そして**減衰ダイナミクスの
生物学的アナロジー**があれば主張が強まる。

**実装**：`tmp/reservoir_decayfields.py`（`CascadeField` 減衰遅延鎖、`DiffusionField` §5.2 拡散、`OrthogonalField`
ρ<1、`LDNField`）。入力パルス後の $\lVert$場$\rVert$ 減衰、MC、NARMA-20（Ours=場＋NNN 写像）vs ESN。

| 散逸場 | ゼロ減衰 | 総 MC | NARMA-20 | 生物学的アナロジー |
|---|---|---|---|---|
| **カスケード（減衰遅延鎖）** | 〜$H$ step で 0 | **47.0** | **0.281** | 信号伝播＋減衰（synfire chain 様） |

- **散逸（ゼロ減衰）と長記憶は両立できる**：カスケード・LDN・減衰直交の 3 つが**入力後にゼロへ減衰しつつ
  ESN を破る**（0.28–0.41 対 0.66）。§2 の「散逸＝ESP」の原点に戻りながら、性能で ESN を上回れることを実証。
  拡散場のみ記憶が薄く（MC=9）同等止まり。
- **減衰の"個性"が生物学的アナロジーに対応**（図 (a)）：カスケードは鎖長で速く減衰（**信号伝播＋減衰**）、
  **LDN は窓 $\theta$ まで保持して一気に放出（時間細胞/ワーキングメモリ・バッファ**、LMU は海馬・皮質の時間
  表現の計算モデル）、減衰直交は滑らかな指数減衰（**神経修飾物質の減衰**——本構想の「ノイズ場＝神経修飾場」に
  最も直接的）、拡散は緩やかに広がる減衰（**容積伝達**）。
- **副産物**：減衰直交は $\lambda_{\mathrm{sp}}$=0.99（§10.12–13, MC=35, NARMA 0.71）より
  **$\lambda_{\mathrm{sp}}$=0.97（MC=46, NARMA 0.41）が大幅に良い**。適度な散逸が条件を改善する
  （marginal 安定の $\lambda_{\mathrm{sp}}$=0.99 は状態が肥大・悪条件化。散逸が well-conditioned
  な表現を保つ）。※ このスペクトル半径は動員ダイヤル $\rho$ とは無関係（`idea_core.md` §1.2 の裁定により
  $\lambda_{\mathrm{sp}}$ に改名）。**「散逸は記憶を削る」の素朴な直観に反し、適度な散逸はむしろ Ours を助ける**。

**含意（主張の魅力）**：Ours の「記憶＝散逸ノイズ場、非線形性＝NNN」は、(i) §2 の散逸原点と整合し、(ii) 場の
減衰ダイナミクスに**神経修飾減衰・時間細胞・信号伝播・容積伝達**という複数の生物学的対応物を持ち、(iii) その
上で ESN を破る。神経修飾場のリザバーという物語（`idea_neuromod.md`）と一体で読ませられる。

### 10.15 生物学的妥当性の統合（2026-07-26）：散逸ノイズ場の神経科学的読み — 時間細胞・神経修飾・容積伝達

| **場 ＋ 学習 NNN 写像（Ours）** | **0.346** | 学習した非線形性が NARMA の積項を捉え上乗せ |

- **誠実な機構の切り分け**：勝ちは「学習パラメータが多いから」ではない。**主要因は分離（クリーンな記憶場は
  線形読み出しでも ESN を超える）**、その上に **forward-only 学習 NNN 写像が非線形性を上乗せ**（0.41→0.35）。
  ただし**写像はランダムでは駄目で学習が必須**（0.91）。field 設計と map 学習の両方が必要。

**バグ再チェック（発見・修正）**：
1. **`task_nrmse` が切片（バイアス列）を欠いていた** → 平均 0 標準化特徴では $y$ の非零平均を再現できず
   NRMSE が ≈4 に発散（初版 POC の ESN=4.0 の正体）。バイアス列を追加して修正（`metrics.py`）。MC は
   corr² で切片不変ゆえ無傷、以前の NARMA 実験は bias 付き `ridge_readout` を使っており正しい。
2. **`narma_x` の健全性**：平均正規化 NARMA。$y$ の std≈0.084・range[0,0.6] が $x$=10–50 で一定＝**非退化**
   （sum 形は $x$ 大で飽和/発散した）。「memory order $x$ だけを変える NARMA 様の族」と明記。
3. **公平性**：Ours と ESN は同一 $H$・同一 train/test 分割・共に $u$ 駆動・feedback なしを確認。Ours が
   多パラメータを学習する（forward-only）のは反証の主張そのもので不公平ではない。ESN は $x$ 毎に個別
   チューニングしていない（勝ち幅が大きく結論は不変）。

**到達点（この minimal set が象徴するもの）**：**記憶を散逸ノイズ場に、非線形性を forward-only の NNN 写像に
分離すると、(i) ESN を NARMA で破り（分離が主要因＋学習写像が上乗せ）、(ii) 場はゼロへ減衰（ESP＝§2 の
原点）、(iii) 最良の暗黙場（LDN）は時間細胞として読める。** BPTT を使わずに「特徴写像まで学習する」ことで
RC の「読み出しのみで足りる」を破る、という §7.2 の反証が、生物学的に接地した形で一枚に収束した。

### 10.18 実行報告（2026-07-26）：忠実な ノイズ場 — 場＝加法ノイズ で LDN が ESN を破る（on-brand 版が成立）

**ユーザの決定的な指摘**：ノイズ場は「入力とは別に**各ユニットに加法的に加わるノイズ**」でなければ、
それは単なる信号入力であり "noise field" の物語が宙に浮く。入力結合版 を認めると場＝reservoir と見るのがフェアで
別の論理になる。**ノイズ場 で結果を示すことが極めて重要。**

**ノイズ場 の実装**（`tmp/reservoir_noisefield_B.py`, `NoiseFieldMap`）：場 $A(t)$（$u$ 駆動・記憶）が各 NNN
ユニットの**加法ノイズの強度** $\sigma_k(t)=\text{floor}+\text{softplus}(g_kA_k+c_k)$ を与え（unit $k$ は場の
座標 $k$ を自分のノイズとして読む＝pointwise）、各ユニットは**固定入力の動作点** $d_k$ を持ち
$z_k(t)=2\Phi(d_k/\sigma_k(t))(1{-}\Phi(d_k/\sigma_k(t)))$。読み出しで $y$ に回帰、$d,g,c$ ＋読み出しを
forward-only 学習。**場は NNN のノイズにのみ入り、入力には入らない**。

**結果（NARMA-x, $H$=48, 3 seed）**：

| 場 | ESN | **ノイズ場 場＝ノイズ** | 入力結合版 場＝入力 |
|---|---|---|---|
| LDN, x=10/20/30 | 0.58/0.66/0.69 | **0.41 / 0.47 / 0.50** | 0.21/0.35/0.41 |
| delay | 同上 | 0.68 / 0.83 / 0.68（✗） | 0.30/0.35/0.26 |
| cascade | 同上 | 0.53 / 0.79 / 0.59（△） | 0.32/0.29/0.33 |

- **忠実な ノイズ場 は LDN 場で ESN を明確に破る**（0.41–0.50 対 0.58–0.69）。**"noise field = 各ユニットの
  加法ノイズ" の on-brand な設定で、Ours が ESN を上回ることが実証された**（ユーザの要請の核心）。
- **なぜ LDN だけ効くか（重要な機構）**：ノイズ場 では $z_k$ は $\sigma_k$ に**単調**（$z_k=$ monotone$(\sigma_k)=$
  monotone$($link$(A_k))$）なので、読み出しは場座標の**一般化加法モデル（GAM）**＝各座標の pointwise 非線形の
  和。NARMA の**積** $u(t{-}x)u(t{-}1)$ を作るには、**場の座標自体が既にラグの線形結合**でなければならない
  （和の非線形性が交差項＝積を生む）。**LDN 座標は Legendre 係数＝窓の多ラグの線形結合**なので pointwise
  非線形が積を生み成立。**遅延線座標は単一ラグ** $u(t{-}k)$ ゆえ pointwise 非線形では積が作れず失敗。cascade は
  減衰単一ラグで部分的。
- **入力結合版 は依然強い**（場＝入力なら交差の入力が学習線形結合 $W_1A$ になり積を直接作れる）が、**ノイズ場 こそが
  "noise-modulated" の名に忠実**であり、**LDN（＝時間細胞）という生物学的に自然な場でその ノイズ場 が成立**する。

**含意（物語の確定）**：主張を **ノイズ場＋LDN 場**で立てられる — **記憶を持つ散逸ノイズ場（LDN＝時間細胞）が
各 NNN ユニットの加法ノイズを供給し、固定入力の NNN が forward-only 学習で NARMA を解いて ESN を破る**。
「ノイズ場＝神経修飾/時間的な加法ノイズ」という原義（`idea_neuromod.md` §2–§5）と完全に整合し、
場＝reservoir という 入力結合版 の別論理に落ちない。**設計原理**：ノイズ場 が成立するノイズ場は「長記憶＋座標がラグを
pre-mix した表現」＝LDN/時間細胞が最適。最小実証は ノイズ場＋LDN で再構成するのが正しい。

### 10.19 実行報告（2026-07-26）：ノイズ場 の詰め — ノイズマップを「混合」にすると 入力結合版 との差が消え、単一ラグ場でも成立

**動機**：§10.18 の ノイズ場 は対角結合（unit $k$ は場座標 $k$ だけを自分のノイズ強度として読む）。ここを
**線形混合** $\sigma_k(t)=\text{floor}+\text{softplus}((MA(t))_k+c_k)$（各ユニットが**全場座標の学習線形結合**を
ノイズ強度として読む）に一般化し、入力結合版 との差の由来を切り分ける（`tmp/reservoir_B_mix.py`、
`NoiseModulatedMap(..., mix=True)`）。**forward-only 勾配**（$d,M,c$）は有限差分と一致（相対誤差 $\sim$1e-8、
readout 凍結損失に対して）。**忠実性は保たれる**：場は依然 NNN の**加法ノイズ強度**にのみ入り、入力は
固定動作点 $d_k$。変わるのは「1 座標→学習線形結合」だけ。

**理論的観察（差の分解の骨子）**：混合を入れても $z_k$ は $\sigma_k$（＝スカラー射影 $M_kA$ の単調関数）
について**単調**。つまり 混合ノイズ場 ユニットは「線形射影に対する飽和単調活性」＝**標準的なシグモイド型
隠れユニット**になる。一方 入力結合版 は pre に対する**バンプ（非単調）**。よって 入力結合版/ノイズ場 の差は理論上
**(i) 接続性**（対角 vs 混合）と **(ii) 表現**（単調 vs バンプ）の 2 成分に分かれる。

**結果（NARMA-x, $H$=48, 3 seed, T=6000/500ep, LDN 場）**：

| x | ESN | 対角ノイズ場 | **混合ノイズ場** | 入力結合版 |
|---|---|---|---|---|
| 10 | 0.576 | 0.419 | **0.216** | 0.243 |
| 20 | 0.628 | 0.470 | **0.354** | 0.340 |
| 30 | 0.674 | 0.526 | **0.399** | 0.387 |
| 40 | 0.690 | 0.584 | **0.414** | 0.410 |

**単一ラグ場テスト（NARMA-20, 対角ノイズ場 vs 混合ノイズ場）**：

| 場 | 対角ノイズ場 | **混合ノイズ場** |
|---|---|---|
| delay（純ラグ） | 0.516 | **0.238** |
| cascade（減衰ラグ） | 0.762 | **0.238** |
| LDN（pre-mix 済） | 0.470 | **0.354** |

**結論**：

- **入力結合版/ノイズ場 の差はほぼ全て「接続性」だった。** 混合ノイズ場 は 入力結合版 に到達（差 $\le$0.02、x=10 では
  混合ノイズ場 0.216 が 入力結合版 0.243 を**上回る**）。すなわち **(ii) 単調 vs バンプの表現差はほぼゼロ**。§10.18 で
  ノイズ場 が 入力結合版 に負けていたのは crossing が単調だからではなく、**各ユニットが場座標 1 つしか読めなかった
  接続性の制約**が原因、と分解された。バンプ活性は 入力結合版 の優位に本質的でない。
- **混合はラグ結合を「ノイズマップ側」で行うので、場は純メモリで足りる。** 混合ノイズ場 は delay/cascade
  でも 0.238 で成立し、pre-mix 済の LDN-mix（0.354）**より良い**（純ラグの方が $M$ で組み合わせやすい）。
  §10.18 の「ノイズ場 は LDN のような pre-mix 場でなければ失敗」は**対角に固有の制約**であり、混合で解消する。
- **これは分離テーゼを最も clean に実現する。** 「**記憶は場（生の遅延線で十分）**・**非線形（＋ラグ混合）
  は NNN のノイズマップ**」。場に高度な表現（Legendre 分解）を要求せず、単純な散逸遅延メモリに落とせる
  ので、生物学的・ハードウェア的により素直（§13 の「拡散だけで足りるか」への肯定的材料）。
- **図**：`tmp/out/reservoir_poc/poc_B_mix.png`（(a) 混合ノイズ場 が 入力結合版 に到達、(b) 混合が単一ラグ場を救済）。
  **メインの最小実証図 `poc_summary.png` もこの物語に統一**（`tmp/reservoir_poc.py`）：(a) Ours が ESN を
  破り 入力結合版 に到達・対角ノイズ場 を上回る、(b) ESP 減衰、(c) LDN=時間細胞、(d) ノイズマップの混合が単一ラグ
  場（delay/cascade）を救済。旧 (d) の「ノイズ場 は LDN 必須（単一ラグ失敗）」は対角固有の話として (a) の
  対角ノイズ場 曲線に残し、(d) は混合の効果に差し替えた。

**含意（物語の更新）**：主張は「ノイズ場＋LDN」から「**混合ノイズ場 ＋ 任意の散逸メモリ場**」へ一段強くなる。
LDN は依然「対角でも効く生物学的に自然な場（時間細胞）」として価値があるが、**必須ではない**。分離の要は
「場＝生の記憶／NNN ノイズマップ＝非線形＋混合」であり、混合ノイズ場 はそれを最小構成で示す。**残る詰め**：
混合ノイズ場 の Ho>Hf・floor 感度・入力結合版 を稀に上回る理由（bump より飽和単調の方が汎化に効く領域があるか）。

### 10.20 実行報告（2026-07-26）：軸3 — 「混合ノイズ場 が 入力結合版 を稀に超える」は seed ノイズ、活性の形はほぼ無関係（表現差≈0 を確定）

**動機**：§10.19 の 1 回のフル実行で x=10 の 混合ノイズ場 (0.216) が 入力結合版 (0.243) を上回った。これが本物の帰納
バイアス（飽和単調活性 vs バンプ活性）か seed ノイズかを切り分ける（`tmp/reservoir_B_gap.py`）。

**再解釈**：入力結合版 も 混合ノイズ場 も「場の学習線形射影 + 固定形活性 + 線形読出」で、**違いは活性の形だけ**。
$\phi_A(u)=2\Phi(u)(1{-}\Phi(u))$＝**バンプ（局所・非単調, RBF 的）**、
$\phi_B(u)=2\Phi(d/(\text{floor}+\text{softplus}(u)))(1{-}\cdots)$＝**飽和単調（シグモイド的, ridge 特徴）**。
仮説：大域的に滑らかな NARMA では大域シグモイド基底が汎化し、局所バンプは過学習する → シグネチャは
train-test ギャップの非対称。

**結果（$H$=48, 6 seed, T=6000, LDN 場; gap = 入力結合版test − 混合ノイズ場test, ± は seed 標準偏差）**：

| x | 入力結合版 test | 混合ノイズ場 test | gap(A−B) | 入力結合版 ovf | ノイズ場 ovf |
|---|---|---|---|---|---|
| 8 | 0.165 | 0.225 | −0.059±0.032 | 0.002 | 0.005 |
| 10 | 0.245 | 0.247 | −0.001±0.038 | 0.010 | 0.010 |
| 12 | 0.281 | 0.270 | +0.011±0.015 | 0.007 | 0.007 |
| 15 | 0.296 | 0.336 | −0.041±0.027 | 0.006 | 0.006 |
| 20 | 0.352 | 0.353 | −0.002±0.026 | 0.009 | 0.006 |
| 30 | 0.393 | 0.402 | −0.010±0.006 | 0.012 | 0.012 |
| 40 | 0.426 | 0.423 | +0.004±0.013 | 0.015 | 0.013 |

（ovf = test − train。特徴 participation ratio at x=10: 入力結合版 バンプ 8.0 < 混合ノイズ場 9.4。）

**結論**：

- **「混合ノイズ場 が 入力結合版 を超える」は seed ノイズだった。** 6 seed 平均で x=10 は完全同点（−0.001±0.038）、
  §10.19 の 0.216<0.243 は当たり seed。平均では 入力結合版 が僅かに優（最小 x=8 でのみ明確 −0.059、~4.5 SE）。
  全 x で **入力結合版 と 混合ノイズ場 は seed 分散内で実質同点**。
- **過学習の非対称は無い（バンプ過学習仮説を否定）。** ovf は両者とも 0.002–0.015 で**ほぼ同一**。
  train≈test で、どちらの活性も過学習していない。局所バンプ＝過学習という直観は本系では成立しない。
- **活性の形（バンプ vs 飽和単調シグモイド）は test 性能にほぼ無関係。** §10.19 の分解「(ii) 表現差≈0」が
  統計的に確定。強いて言えばバンプ 入力結合版 が髪一本優（非単調で僅かにリッチ）＝自然な upper reference。
- **混合ノイズ場 の特徴は高ランク（9.4>8.0）だが test 利得なし** → NARMA の読み出しは中ランク部分空間で足り、
  特徴の広がりは律速でない。

**含意**：軸3の前提（B-mix が系統的に 入力結合版 を超える）は否定。だが**分離テーゼはむしろ強化**される — 忠実な
ノイズ場 の単調ノイズ活性は入力駆動バンプ 入力結合版 と**実質同等**（≤0.06、大半は同点）で、「ノイズ場 に固執しても失う性能は
ほぼ無い」。§10.19（接続性が 入力結合版/ノイズ場 差の本体）と合わせ、**混合ノイズ場 は 入力結合版 の劣化版ではなく実効的に等価な
別定式化**であり、"noise-modulated" の名に忠実なまま 入力結合版 の性能水準を得る、と締められる。

### 10.21 実行報告（2026-07-26）：軸1 — 2 つの独立な容量ダイヤル（Ho=非線形／Hf=メモリ）、分離アーキの核心的うまみ

**動機**：混合ノイズ場 は Ho（NNN 隠れ幅）と Hf（場サイズ＝メモリ）を**独立に**サイズ設定できる（mix の $M$ は
$[H_o, H_f]$ なので $H_o\ne H_f$ が自然）。ESN は単一の $H$ が記憶と非線形を同時に担うのでこれができない。
2 つのスイープでどちらが律速かを可視化（`tmp/reservoir_B_capacity.py`, `poc_B_capacity.png`, $H$ 各値 3 seed）。

**行1（Ho を振る, Hf=48 固定）test NRMSE, 混合ノイズ場/入力結合版/ESN(H=Ho)**：

| x | Ho=12 | 24 | 48 | 96 | 144 |
|---|---|---|---|---|---|
| 10 | .245/.276/.642 | .264/.299/.592 | .233/.224/.578 | **.173/.165**/.563 | .178/.182/.555 |
| 20 | .367/.401/.792 | .380/.371/.682 | .357/.364/.659 | .357/.352/.652 | .361/.353/.640 |
| 40 | .424/.446/.802 | .428/.481/.776 | .429/.424/.697 | .441/.440/.698 | .443/.441/.686 |

**行2（Hf を振る, Ho=96 固定）test NRMSE, 混合ノイズ場/入力結合版/ESN(H=Hf)**：

| x | Hf=24 | 48 | 96 |
|---|---|---|---|
| 10 | .432/.425/.592 | .173/.165/.578 | .169/.130/.563 |
| 20 | .546/.525/.682 | .357/.352/.659 | **.112/.179**/.652 |
| 40 | .578/.565/.776 | .441/.440/.697 | **.130/.150**/.698 |

**結論（2 ダイヤルの分離）**：

- **短記憶（NARMA-10）は Ho 律速。** 行1 で Ho を増やすと 0.25→0.17（Ho=96 で最良、Ho=144 で微過学習）、
  行2 で Hf を 48 以上に増やしても 0.17 で頭打ち。＝**必要なのは非線形特徴の豊かさ（隠れ幅）**。
- **長記憶（NARMA-20/40）は Hf 律速。** 行1 で Ho を増やしても ~0.36 / ~0.43 で**フラット**、行2 で Hf を
  増やすと**劇的改善**（x=20: 0.55→0.36→**0.11**、x=40: 0.58→0.44→**0.13**）。＝**必要なのは場のメモリ解像度**
  （LDN 係数数＝窓内のラグ分解能）。
- **分離アーキの核心的うまみが実証された。** 律速はタスク（記憶次数 x）で Ho 側にも Hf 側にも移る。混合ノイズ場 は
  2 つを**独立に**振れるので、どちらが律速でもそこに容量を割り当てられる。**単一 $H$ の ESN はこれができず**、
  ESN(H=Ho) も ESN(H=Hf) も長記憶で ~0.65-0.70 に張り付く一方、Ours は (Hf=96,Ho=96) で 0.11-0.13＝**約 5 倍
  低い NRMSE**。（公正性の注記：Ours は Hf 個の**固定・無学習**な LDN メモリ座標＋Ho 個の学習隠れユニットを使う。
  メモリは RC の作法で「無償の固定リザバー」に相当。ESN は $H$ 再帰ユニットで両機能を兼ねる。要点は台数競争
  でなく、**最適な固定メモリ（LDN）と非線形容量を独立に選べる**という設計自由度。）
- 入力結合版 と 混合ノイズ場 は両スイープで追随（§10.20 の等価性が容量軸でも成立）。

**含意（物語の到達点）**：§10.18-10.21 で ノイズ場 の物語が完成した。**散逸ノイズ場＝記憶（サイズ Hf で解像度を選ぶ）／
NNN ノイズマップ＝非線形＋ラグ混合（幅 Ho で表現力を選ぶ）**、両者を独立配分できることが「記憶と非線形を tanh に

### 10.22 実行報告（2026-08-01 実施）：STP 場（短期シナプス可塑性）の検証 — 生物的には最有力だが記憶は薄い

**動機**：§10.22 で生の feedforward STP バンクは記憶が薄かった。Mongillo 2008 のように**再帰回路**が STP 記憶を

### 10.26 検討：閾値活性の KDE slope と、$\Delta h\to\infty$ による交差型の消失軌道

**【固めた枠組みは §10.28 を参照】** 本節の「閾値の消失ノブ (a)$h\uparrow$ / (b)$\Delta h\uparrow$」の整理は暫定で不正確な
点があった（$\Delta h\to\infty$ の扱い、交差との対応関係）。**§10.28 に、交差と閾値をゲージ・消失軌道の観点で統一する
確定枠組み（二値化ノイズ信号のモーメント）**を置く。以下は経緯として残す。

（ユーザ指摘。2021 論文「Noise-modulated neural networks for selectively functionalizing sub-networks…」の閾値活性
KDE slope の記述に対応。）**閾値活性でも $h\pm\Delta h$ でバンド幅を作れば KDE で slope を推定できる**：2 閾値
$h-\Delta h,\ h+\Delta h$ での発火率の差 $\big[\Phi(\tfrac{d-h+\Delta h}{\sigma})-\Phi(\tfrac{d-h-\Delta h}{\sigma})\big]/(2\Delta h)
\to \tfrac{1}{\sigma}\phi(\tfrac{d-h}{\sigma})$（$\Delta h\to0$）＝解析 slope の分布フリー推定（交差の $\pm h$ カウンタと同型、
`idea_core.md` §2.4–2.5）。**含意（重要）**：$\Delta h$ は交差活性における $h$（半幅）に対応する第 2 の消失軌道になりうる。
$\Delta h\to\infty$ とすると、2 閾値バンドが広がり**片側 $h+\Delta h\to\infty$（超・サブスレッショルド）／他側
$h-\Delta h\to-\infty$（超・スープラ）**で、バンド内応答＝差が $\to0$、すなわち**交差型（バンプ）の消失**が閾値の
座標でも現れる。つまり閾値活性は 2 つの消失ノブを持つ：(a) $h\uparrow$（＝$h_0/\sigma$、片側サブスレッショルド、
§10.25）、(b) **$\Delta h\uparrow$（両側バンド拡大、交差＝バンプ的消失）**。$\sigma$・$h$・$\Delta h$・$\rho$・$\nu$ の
ゲージ関係を整理し、(b) の $\Delta h$ 消失が (a) と機能的に等価か（あるいは別の消滅経路か）を次に検証する。

| 1 | 0.39 | 0.40 | 0.40 | 0.42 | 0.42 | 0.32 |

### 10.28 統一枠組み：交差活性と閾値活性は「二値化ノイズ信号のモーメント」（ゲージ・消失軌道の統一）

**【整理・確定版は §10.29】**（十分な説明つき・idea_core 用語に統一・移設検討あり）。本節は初出の骨子として残す。

交差（2021）と閾値（2018）を、ゲージと消失軌道の観点で最も統一感よく扱う枠組みを提案する。**両者は同じ二値化
ノイズ信号 $b_\theta=\mathbb 1[d+\eta>\theta]$（$\eta\sim N(0,\sigma^2)$）の異なるモーメントである**。

$b_\theta\sim\text{Bernoulli}(F)$、$\ F=\Phi(u),\quad u\equiv\dfrac{d-\theta}{\sigma}$（$d=w\!\cdot\!x+b$、$\theta$＝閾値／交差では中心）。

| 活性 | モーメント | 式 | 形 |
|---|---|---|---|
| **閾値（2018）** | 1 次（平均） | $z_{\text{thr}}=\mathbb E[b]=F=\Phi(u)$ | **単調シグモイド** |
| **交差（2021）** | 2 次中心（×2＝分散） | $z_{\text{cross}}=2\,\mathrm{Var}(b)=2F(1-F)=P(b_1\!\neq\!b_2)$ | **バンプ（非単調）** |

（交差＝「独立 2 サンプルが閾値を挟んで反対側に落ちる確率」$=2\mathrm{Var}(b)$。閾値＝発火確率＝平均。2 閾値 $\pm h$
版は $\theta=\pm h$ の平均。）

**(1) ゲージ（両者で完全に同一）**：$z_{\text{thr}},z_{\text{cross}}$ とも**不変量 $u=(d-\theta)/\sigma$ のみ**の関数。
ゲージ変換 $(w,b,\theta,\sigma)\to\beta(w,b,\theta,\sigma)$ で $u$ 不変（`idea_core.md` の 4 つ組ゲージ、$\theta$ が $h$ の役）。
実効ゲイン $\gamma=\lVert w\rVert/\sigma$ もゲージ不変。**閾値の $\theta$ は交差の $h$（中心・半幅）と同じゲージ座標**。

**(2) 消失軌道（$|u|\to\infty$ で統一、ただし片側/両側が違う）**：消失 $z\to0$ は $u$ を極限へ送ること。
- $z_{\text{thr}}=\Phi(u)$：**$u\to-\infty$ の片側のみ**で消失（$u\to+\infty$ は飽和 $\to1$）。
- $z_{\text{cross}}=2F(1-F)$：**$u\to\pm\infty$ の両側**で消失、$u=0$ で最大。
- 共通ノブ（すべて $u$ を動かす）：$\sigma\downarrow$、$\theta\uparrow$（$=h_0/\sigma$ でサブスレッショルド）、$|d-\theta|\uparrow$。
  **閾値の「$h\uparrow$ による消失」と交差の「$\sigma\downarrow$ による消失」は、同じ $u$ 座標上の移動**。
- **on-brand（ノイズ無し $\sigma\to0$ でゼロ）**：交差は**自動**（$d\neq\theta$ なら $\sigma\to0$ で $|u|\to\infty$→分散 0→ゼロ）。
  閾値は $d<\theta$ でのみ自動で、**$\theta=h_0/\sigma$ 連動（＝consolidation の $\rho$ ダイヤル $\sigma=\rho\sigma_0,h=h_0/\rho$）
  を課すと保証**（$\sigma\to0$ で $u=d/\sigma-h_0/\sigma^2\to-\infty$、§10.25）。
  → **交差は消失が両側かつ σ 単独で on-brand（無条件）／閾値は片側ゆえ $h=h_0/\sigma$ 連動が要る**、が両者の唯一の差。

**(3) $\Delta h$（KDE slope バンド）の位置づけ**：2 閾値 $\theta\pm\Delta h$ の「バンド内」応答
$z_{\text{band}}=F_{\theta-\Delta h}-F_{\theta+\Delta h}=P(\theta-\Delta h<d+\eta<\theta+\Delta h)$ は**別種のバンプ（密度型）**で、
$\Delta h\to0$ で規格化すると slope $F'=\phi(u)/\sigma$（KDE slope）。**$\Delta h$ は「1 サンプルのバンド幅」ノブ**で、
$\Delta h$ 大＋片側固定 → 閾値（単調）、$\Delta h$ 小 → 密度バンプ、を補間する。**注意：この密度バンプ $F'$ は交差の
分散バンプ $2F(1-F)$ とは別物**（共に幅 $\sim\sigma$・中心 $\theta$ だが関数が違う）。したがって「$\Delta h$ で交差↔閾値を
一本のノブで統一」は不正確で、正しい統一軸は**モーメントの次数（1 次＝閾値／2 次＝交差）**である。$\Delta h$ は
「KDE で slope を測るための帯域幅」であり消失軌道の主軸ではない（§10.26 の暫定整理はこの点を混同していた）。

**(4) 深層・SR・設計への含意（枠組みから直接導かれる）**：
- **深層安定性はモーメント次数で決まる**：1 次（平均＝単調 $\Phi(u)$）は深層合成が安定、2 次（分散＝非単調バンプ）は
  深層崩壊（§10.24, §10.27。ノイズでも救えない）。
- **SR は sample 推定（有限 numT）でモーメントを測るときに現れる**（analytic＝平均場では消える、§13.1・§10.25）。
- **設計軸**：**深い合成課題＝1 次（サブスレッショルド閾値、$h=h_0/\sigma$ で on-brand＋単調＋SR の 3 拍子、§10.25）／
  浅い局所課題＝2 次（交差バンプ、単層で tanh 超え、σ 単独で on-brand）**。両者は同一の二値化ノイズ信号の 1 次/2 次
  モーメントで、ゲージ（$u$）と消失（$|u|\to\infty$）を共有し、差は「消失の片側/両側」と「on-brand に $h=h_0/\sigma$ 連動が
  要るか否か」だけ、という統一像。

**parity depth2 と absum では sample の方が良い**＝MC ノイズが助けている（§13.1 の
「ノイズは資源」がこの軸でも現れる）。したがって「sample は常にノイズ代で不利」という素朴な補正は誤りで、
**tanh 交絡は懸念したほど大きくない**（parity/absum では交差に有利な向きにさえ働く）。

**(C) ただし NARMA では交差が大きなサンプリングコストを払っている（新発見）**

| NARMA-10 depth1 | analytic | sample(numT=64) |
|---|---|---|
| 交差 | **0.217** | 0.355 |
| 閾値 | 0.377 | 0.392 |
| tanh | 0.371 | — |

**形（analytic）としては交差が最良で tanh を 41% 上回る**のに、numT=64 の推定分散が優位を食い潰している。
§10.34 で「NARMA depth1 で交差が勝つ」を 6 seed で撤回したのは **sample 設定としては正しい**が、
**活性の形としては交差が勝っている**——両者は別の主張であり、区別して述べるべきだった。

**(D) numT を上げると交差の形の優位は回復する——2 次モーメントは 1 次より標本を食う**
（`tmp/reservoir_numT.py`、NARMA-10 depth1、$\gamma{=}0.3$、3 seed）：

| $numT$ | 32 | 64 | 128 | 256 | 512 | analytic |
|---|---|---|---|---|---|---|
| **交差** | 0.498 | 0.426 | 0.398 | 0.338 | **0.301** | 0.217 |
| **閾値** | 0.392 | 0.392 | 0.407 | 0.397 | 0.389 | 0.377 |

**交差は $numT$ とともに単調に改善して analytic へ近づき、$numT\gtrsim256$ で閾値（0.39）と tanh（0.37）を
追い抜く。一方 閾値は $numT$ にほぼ不感**（0.39 前後で一定）。機構は自明で、**2 次モーメント（分散）の推定は
1 次（平均）より標本を食う**。すなわち交差活性のコストは $\gamma$ 許容窓の狭さだけでなく、
**$numT$ 要求の高さ**という第 2 の軸を持つ。

**実務上の含意**：本系の既定 $numT{=}64$（FPGA 実装の凍結仕様でもある、`idea_fpga.md`）では
**交差の形の優位は原理的に実現されない**。交差を性能目的で使うなら $numT$ を 4 倍以上に上げる必要があり、
それはサンプリングコスト（時間・電力）と直接トレードオフする。逆に**閾値は $numT$ に鈍感なので
低 $numT$ のハードウェアに向く**。
なお §13.1 留保 2 は「SR 利得は有限標本現象（$numT\to\infty$ で analytic へ漸近）」＝**有限標本が資源**の側面を
述べていた。本節はその裏側＝**有限標本が交差にとってコストになる場合**を示しており、
(B) の符号が一定しない表と合わせると、**有限標本ノイズは課題によって資源にも代償にもなる**が正確な言明である。

**方法論の教訓（2 つ目）**：活性の比較では **$\gamma$ を揃える**（§10.33）だけでなく **ノイズ代を揃える**
必要がある。tanh のような決定論的活性を基準にすると両者が混ざる。**最も安全なのは
「閾値 vs 交差」＝同じ二値化・同じ numT の 1 次 vs 2 次比較**であり、幸いそれが本系で本当に問いたい軸である。

### 10.36 実行報告（2026-08-07）：$\gamma$ は $\lambda$ の弱同定を治さない——原因は勾配の小ささではなく**ベイスン固着**

`tmp/reservoir_lambda_ident.py`。§10.35 の説明（$\partial z/\partial\lambda$ は $s{=}0$ で厳密に 0、
信号は $\gamma$ とともに増える）から「**$\gamma$ を上げれば同定できる**」と予測し、検証した。
**同定性の指標＝$\lambda$ 初期値 0.1/0.5/0.9（初期ばらつき 0.8）に対する最終 $\lambda$ のばらつき**。

**素の回帰（$\beta{=}0$）**：

| $\gamma$ | init 0.1 | init 0.5 | init 0.9 | **ばらつき** | NRMSE |
|---|---|---|---|---|---|
| 0.5 | 0.360 | 0.676 | 0.819 | 0.459 | 0.518 |
| 1.0 | 0.235 | 0.595 | 0.836 | 0.601 | 0.411 |
| 2.0 | 0.222 | 0.513 | 0.872 | 0.649 | 0.635 |
| 5.0 | 0.149 | 0.451 | 0.845 | **0.696** | 0.949 |

- **❌ 予測は反証された**。$\gamma$ を上げるとばらつきは縮むどころか **0.46 → 0.70 と増える**。
- **原因は勾配の小ささではなく「ベイスン固着」である**。値の動き方を見ると、$\gamma$ が高いほど
  低 init は**さらに下へ**（0.36→0.15）、高 init は**上に留まる**（0.82→0.85）＝中央から**両側へ発散**する。
  これは収束の失敗ではなく**双安定**であり、機構は明快——**ネットワークの残りの部分（重み・しきい値 $c$）が
  現在の $\lambda$ に合わせて共適応し、その $\lambda$ を局所最適にしてしまう**。$\gamma$ が高いほど非線形性が
  強くベイスンが深いので、固着も強まる。$\gamma{=}5$・init 0.9 は NRMSE が悪いまま $\lambda{=}0.845$ に
  留まっており（脱出できない）、これが固着の直接の兆候である。
- **✅ 一方 on-brand 罰則は全 $\gamma$ で確実に効く**（$\beta{=}1$）：ノイズ無し活動は
  0.166–0.258 → **0.035–0.145** に下がり、$\lambda$ は全 init・全 $\gamma$ で上昇する。

**確定した含意**：**$\lambda$ は「当てはめて決まるパラメータ」ではなく「要求して決めるパラメータ」である。**
性能勾配では同定できず（$\gamma$ を上げても治らない、むしろ悪化）、しかし**明示的な要求（on-brand・沈黙・
電力）に対しては頑健に応答する**。§2.7.1c の生物規範の整理と完全に整合し、さらに強い形になった——
交差活性（$\lambda\to1$）は**性能最適化が選ぶものではなく、設計者/生物が「ノイズ無しでは黙る素子が要る」と
要求したときに現れる**。実務的には $\lambda$ は**学習させるより指定する**のが正しい扱いになる。

## 12. consolidation の消滅経路との関係（θ 凍結がゲージを固定する）

consolidation は (w,b,σ,h) 空間に 2 方向を区別した（§3–4, §15.1）：**ゲージ軌道**（4 つを α で
一括スケール＝関数不変な冗長方向。σ→0 をここで近づくと不定形の特異点）と、**消滅経路**（入力側
(w,b) を固定して (σ,h) だけを動かす関数変化の方向。バンプ活性ゆえ $\bar z$・$\mathrm{Var}(z)$ が
連続に 0 へ、$\nu$ だけが不変な参加量。第 1 層は σ↓、深い層は漏れるので h↑ を併用。h↑ は入力側
スケール一斉縮小のゲージ像）。「ゲージ不変な経路を進み、σ と h の連動を切って消滅経路で整理する」
とは、ゲージ軌道上の 4 パラメータ連動をほどき、(w,b) 固定のまま (σ,h) を検出方向へ動かす整理を指す。

リザバーへの写像で決定的なのは次の 5 点：

- **(I) θ 凍結がゲージを自動的に固定する。** RC の規律で $\theta=(w,b)$ は不変。ゲージ移動には
  w,b の同時スケールが要るので、θ を固定した瞬間、非自明なゲージ移動は消える（α=1 の恒等のみ）。
  ゆえに場のダイナミクスがどう動いても必ず**消滅経路型（関数を変える本物の方向）**であり、冗長な
  ゲージ軌道へ滑り落ちる心配が構造的に消える。§8-1 のゲージ懸念は規律そのものが大半を解いている。
- **(II) 帰結：σ のスケールは冗長でなくなる（§5.6 の修正）。** duality 稿の「σ 勾配＝重み勾配の
  動径成分」「h=cσ で σ が重みノルムと冗長」は**重みが動ける学習系**の話。θ 凍結下では σ を変えても
  重みが補償できないので、σ の大域スケールすら本物の DOF になる。よって $\rho$ を使う主目的は
  「冗長性除去」ではなく「深い層でも厳密な休止＝真のゼロ出力アトラクタ」（§5.6 理由2）に一本化される。
- **(III) だから「σ と h を切る」＝2 枚場が原理的に正当化される。** consolidation が σ（第 1 層検出・
  バンプ幅）と h（深層検出・厳密沈黙）を別方向として整理したのと同じく、θ 凍結下では σ を過渡の
  richness ノブ、h（または $\rho_h$）を on/off・休止ノブとして分離運用できる。§5.6 の 2 枚場は、この
  消滅経路の分解にそのまま対応する。$\rho$ 単独＝畳んだ表現（clean・厳密休止）、2 枚場＝ほどいた
  表現（σ で richness を独立制御）が、consolidation の ρ 統合／σ-h 分解に一対一で移る。
- **(IV) 同じ経路、逆の目的。** consolidation は消滅経路を「損失駆動でゆっくりアニールし、失う機能を
  forward-noise 学習則が補償する」＝支持を縮めても**関数を保つ**ために使う。リザバーは同じ経路を
  「自律的な速い散逸で補償なしに」流す＝場の減衰に**関数を乗せて時間基底を生む**。geometry は共有し
  epistemics が反転する（関数不変／補償あり ⇄ 関数変化／補償なし＝特徴生成そのもの）。
- **(V) 同時停止の含意。** consolidation の「$\mathrm{Var}(z)\to0$ で credit も消灯（推論と学習が
  同時離脱）」は、リザバーでは「休止に達すると出力も局所勾配/credit も消える」＝**読み出しは過渡
  （$\nu>0$）の間にしか学べない**を意味する。forward-only 読み出しも過渡でのみ供給される。

補足（次元の対応）：consolidation の圧縮フロア $m\le\mathrm{floor}\le\lceil\mathrm{er}\rceil$（読み出し
次元と有効ランクで両側から挟む）は、リザバーでは**利用可能な過渡モード数＝memory capacity**に
読み替わる（拡散の固有モードのうち、異なる時定数で減衰する独立方向の数）。同じ「支持の有効次元」が、
片方では圧縮限界、もう片方では記憶容量になる。

### 13.1 ノイズは本当に本質か（SR 曲線の不在）

**問い**：混合ノイズ場 において、加法ノイズは計算に必要な資源なのか、それとも
単に $\sigma_k$ を経由した滑らかな非線形性の実装手段にすぎないのか。

**なぜリスクか**：現行モデルの場（LDN・遅延線・カスケード）はすべて決定論的な
線形力学であり、確率性は交差ユニットの内部にしか存在しない。この状態で
"noise-modulated reservoir" と名乗ると、査読者の最初の質問は必ず
「ノイズ強度を固定して同じ形の単調飽和非線形（sigmoid）に置き換えたら
何が失われるのか」になる。§10.20 で「活性の形（バンプ vs 単調シグモイド）は
test 性能にほぼ無関係」を統計的に確定させてしまっているため、この問いに
現有の結果では答えられない。答えられなければ、本系は「LDN メモリ＋学習された
飽和非線形写像」＝LMU の再発明として読まれる。

**決着のつけ方**：§10.1 Tier B-6 の SR 曲線をリザバー文脈で実施する。
noise floor（および $M$ のスケール＝実効 $\sigma$ の大域強度）を掃引し、
NARMA-x の test NRMSE と memory capacity を縦軸に取る。`analytic`（平均場、
$z_k=2\Phi(1-\Phi)$ を決定論的に評価）と `sample`（真のモンテカルロ交差）を
同一重みで対照する — `idea_neuromod.md` §8 の TODO にある「同一重みで両応答を評価する
専用診断」がここで必要になる。

**合格条件**：`sample` モデルで内点最適（逆 U 字）が複数 seed で再現し、かつ
`analytic` では内点最適が消えるか大きく浅くなること。これが出れば
「ノイズは資源であって実装手段ではない」が時間軸で成立し、Neurocomputing
2018/2021 の主張が本稿で RC に拡張されたことになる。出なければ、"noise-modulated"
を看板から降ろし「乗法的ゲート場」として書き直す判断が要る（主張の格は下がるが
誠実であり、その場合の投稿先も変わる）。

#### 実行報告（2026-07-30 実施）：合格 — sample は内点最適、analytic は平坦。ノイズは時間軸でも資源

**実装**（`tmp/reservoir/sr.py` ＋ `tmp/reservoir_sr.py` → `tmp/out/reservoir_sr/sr_curve_sigma.png`）：
§9 TODO の**同一重み診断**を実装した。LDN 場（$H_f=48,\theta=60$）＋ 混合ノイズ場 map（$H_o=48$）を
**analytic（平均場）で学習し $d,M,c$ を凍結**、その同一重みのまま大域ノイズ強度
$\sigma_k(t)=s\,(\text{floor}+\text{softplus}((MA)_k+c_k))$ の $s$ を $[0.05,10]$ で 25 点掃引。各 $s$ で
**両応答**を採点した：`analytic` $z=2\Phi(d/\sigma)(1-\Phi)$（平均場・閾値なし）と `sample`（有限
$numT{=}64$・閾値 $h{=}0.2$ のモンテカルロ交差、`nnn.activation.CrossingStatistic` 機構の numpy 版）。
指標は NARMA-$x$ test NRMSE と total memory capacity（narma の駆動 $u$ は iid なので MC プローブに流用）、
NARMA-10/20 × 6 seed。機構確認：$numT\uparrow$・$h\downarrow$ で sample→analytic に収束（平均絶対誤差
0.034→0.004）、固定 $h$ 下で小 $\sigma$ 交差が崩壊（SR バリア）を数値確認済み。

**結果（合格条件を満たす）**：

| 指標 | sample（機構） | analytic（平均場） |
|---|---|---|
| NRMSE の形 | **逆 U 字（内点最適）**、$s^\*\approx0.20$–$0.23$ | **平坦なプラトー**（$s\gtrsim0.5$ でほぼ一定） |
| 内点最適 seed 率 | **1.00**（NARMA-10/20 とも全 6 seed） | 0.67–1.00 だが $s^\*$ は散乱（端点 $s{=}10$ を含む） |
| NRMSE 掃引深さ | **0.25**（NARMA-10: 0.78→1.02, NARMA-20: 0.79→1.02） | 0.10–0.11（低 $s$ 側の立上りが主で高 $s$ 側は平坦） |
| total MC の形 | **鋭い内点ピーク**（$\approx6.3$ @ $s{\approx}0.25$ → 高 $s$ で 0.05 へ崩壊） | **平坦**（$\approx26$、全 $s$ でほぼ一定） |

- **sample は逆 U 字（内点最適）が全 seed・両タスクで再現**。低 $s$ 側は閾値下で交差不能（SR バリア）、
  高 $s$ 側は $\sigma\gg d$ で $z\to0.5$ 飽和し情報消失。→ **最適ノイズ水準が存在＝ノイズは資源**。
- **analytic は内点最適が消え平坦化**。平均場は読み出しの再スケールで消失する特徴も救えるため、
  真の SR バリアがなく、広い $s$ でほぼ一定（$s^\*$ は seed ごとに端点まで散乱）。深さは sample の
  約 1/2.4。MC は全 $s$ で $\approx26$ の完全平坦。
- **合否＝合格**：§13.1 の合格条件「sample＝内点最適が複数 seed で再現／analytic＝内点最適が消えるか
  大きく浅く」を満たす。「ノイズは資源であって実装手段ではない」が時間軸（RC）で成立し、Neurocomputing
  2018/2021 の SR 主張の本稿への拡張が数値で立った。**"noise-modulated" は看板から降ろさない。**

**正直な留保（査読で必ず突かれる 3 点、writeup に明記する）**：
1. **sample は絶対値では全域 analytic より悪い**（$numT{=}64$ の推定分散コスト）。主張は**曲線の形
   （内点最適の有無）**であって絶対性能ではない。図でも「形の対比」を強調する構図にした。
2. **SR 利得は有限標本現象**：$numT\to\infty$ で sample は analytic プラトーへ漸近（$numT$ 64→512 で
   最適点は残るが床は緩やかに低下、$\propto1/\sqrt{numT}$）。これは**正しい物理**で、生物・HW の任意の
   物理実装は有限標本ゆえノイズ資源は実在、平均場は数学的理想化。査読者の「固定 $\sigma$ の同形
   シグモイドに置換したら何が失われるか」への直接の答え＝**平均場（＝固定 $\sigma$）は内点最適を失う**。
3. **sample の $s^\*\approx0.23$ は analytic 学習水準 $s{=}1$ より小**。よって内点最適は「重みがその $\sigma$ に
   最適化されていたから」の産物ではない（むしろ学習水準から離れた所に最適が立つ）。

**ゲージの観点からの再解釈（2026-08-07 追記、`idea_core.md` §4.8・§2.7.2）**：本掃引は**重みを凍結して
大域ノイズ強度 $s$ を振る**ので、実効ゲイン $\gamma_k=\lVert a_k\rVert/\sigma_k$ に対し $\gamma\propto1/s$、すなわち
**この SR 曲線は $1/\gamma$ 軸の掃引**である。したがって「最適ノイズ水準が存在する」は、より正確には
**「最適な実効ゲイン $\gamma^\*$ が存在する」**（$\gamma^\*\propto1/s^\*$）と述べられる。この言い換えは主張を
**弱めず、むしろ強める**：$\sigma$ の絶対値はゲージ依存で単独では測ってはいけない量だが（§4.8 の警告）、
$\gamma$ は**ゲージ不変量**なので、内点最適が「単位の取り替えで動く見かけの現象」ではないことが保証される。
重みを凍結した同一重み診断は、まさにこのゲージ固定を行っているから正当である。
なお $\gamma$ 軸で見ると、§10.24 以降の「活性の形の比較」と同じ軸を掃引していることになり、
**SR の内点最適と活性比較は同一平面（$\gamma$ 軸）上の別断面**として統一的に読める（§10.33）。

**補助確認の要否**：同一重み診断が §13.1 の指定手法そのものであり、6 seed × 2 タスクで曖昧さなく
合格した。idea_neuromod.md の train スイープ（各 $s$ で再学習）は分類文脈由来の別手法で、同一重み結果を
覆す要素はない（analytic の平坦性は平均場再スケールに由来し重み非依存）ため、必須の補助確認としては
未実施（将来の hardening 候補）。**残：**§13.3 の LMU/NG-RC 比較図に、この「乗法結合ゆえの SR 内点最適
（加法結合の NG-RC/LMU には無い）」を本系固有性質(ii)の 1 枚として組み込む。

### 13.2 NARMA 族への過適合（外的妥当性の未検証）

**問い**：§10.21 の「2 つの独立な容量ダイヤル」は NARMA という単一のタスク族の
性質ではないか。NARMA は記憶次数 $x$ が明示的なパラメータであるため、
「$H_f$ を上げると長記憶が改善する」は構成上ほぼ自明に出うる。

**なぜリスクか**：現在の主要結果（NARMA-20/40 で ESN の約 5 倍低い NRMSE）は
すべて `narma_x` という自作の族の上にある。§10.16 で非退化性は確認済みだが、
これは「標準ベンチマークである」ことを意味しない。査読者は
「NARMA でしか示していない結果は NARMA の結果である」と書く。

**決着のつけ方**：タスクを最低 3 種、できれば 4 種に広げる。
(i) Mackey–Glass（$\tau=17$、標準設定）、(ii) Lorenz または Rössler の
自由走行予測（valid prediction time で評価）、(iii) Jaeger の memory capacity
$MC(k)$ 曲線（$H_o$/$H_f$ の 2 ダイヤルが MC プロファイルをどう変えるかを直接可視化。
§10.1 Tier A-1 の未実施分）、(iv) 余力があれば spoken digits（TI-46 または
Lyon 耳モデル前処理）。$H_o$/$H_f$ スイープを少なくとも 2 種のタスクで繰り返し、
「短記憶＝$H_o$ 律速／長記憶＝$H_f$ 律速」がタスク族に依らないことを示す。

**合格条件**：非 NARMA の少なくとも 2 種で、同一パラメータ予算の ESN に対する
優位が保たれ、かつ律速ダイヤルの切り替わりが再現すること。ここで優位が消えるなら、
主張を「性能」から「設計自由度と forward-only 実装可能性」へ全面的に移す
（§13 既存項目の「勝つことは目的でない」較正を、今度は本気で適用する）。

### 13.3 公平性と先行研究への吸収（最大の査読リスク）

**問い**：「記憶と非線形を分離する」という主張は、それ自体としては既知である。
本系がそれらと区別されるのは何によってか。

**なぜリスクか**：以下の 3 つが直接の先行研究として存在し、いずれも査読者が
必ず挙げる。
- **Next-Generation RC**（Gauthier et al., *Nat. Commun.* 12, 5564, 2021）：
  遅延線メモリ＋明示的な多項式非線形。混合ノイズ場＋delay 場と構造的に同型に見える。
- **LMU**（Voelker, Kajić & Eliasmith, NeurIPS 2019）：LDN 場は文字どおり
  LMU のメモリ。§10.15 で自ら LMU の系譜に乗ると書いている。
- **Chaos 33, 113120 (2023)**, "Reservoir computing decoupling
  memory–nonlinearity trade-off"：タイトルの時点で §10.21 と正面衝突。
背景として Dambre et al.（*Sci. Rep.* 2, 514, 2012, IPC）と Inubushi & Yoshimura
（*Sci. Rep.* 7, 10199, 2017）も引かれる。
加えて公平性の問題がある。現行比較は「Ours: 固定 LDN 座標 $H_f$ 個＋学習ユニット
$H_o$ 個＋$d,M,c$ 学習」対「ESN: $H$ 個で読み出しのみ学習」であり、
「学習パラメータが多いだけ」という最も安価な反論を許している。§10.16 の
アブレーション（場＋線形読み出しのみで 0.412 < ESN 0.643）は良い防御だが、
これは「LDN が ESN より良いメモリである」ことしか示しておらず、それは LMU の既知の主張である。

**決着のつけ方**：(a) 比較対象に **LMU（LDN＋学習写像＋BPTT なし読み出し）と
NG-RC（遅延線＋多項式特徴＋リッジ）** を必ず加え、パラメータ数・特徴次元・FLOPs を
揃えた「誤差 vs 予算」曲線として提示する。(b) 主張の本体を分離から降ろし、
**結合様式（場が入力ではなくノイズ強度に乗る＝乗法的）** と、そこから帰結する
**forward-only credit の成立**（§7.1、有限差分一致 ~1e-8）に置き直す。
NG-RC も LMU も加法的・入力経路の結合であり、ここは構造的に別物である。

**合格条件**：LMU / NG-RC と同予算で並べたときに、(i) 性能が同等以上であり、
かつ (ii) 本系だけが持つ性質（乗法結合、$\sigma\to0$ による ESP、
forward-only、SR の内点最適）を独立の図で示せること。(i) だけでは不十分で、
(ii) が本稿の存在理由である。

#### 実行報告（2026-07-30 実施）：合格条件 (i) は NG-RC に対して**不成立** — 性能の物語は撤回、(ii) へ全面移行が必要

**実装**：`tmp/reservoir/baselines.py`（`NGRC`＝Gauthier 2021：遅延線＋degree-2 一意積＋リッジ、

Ours/LMU は $H_f{+}H_o$）、NARMA-10/20 × 4 seed。図 `tmp/out/reservoir_baselines/budget_curve.png`。

**結果1：NARMA 予算揃え（NG-RC が支配）**：

**結果2：非多項式タスク probe（それでも NG-RC が支配）**：遅延の厳密ラグに依らない目標なら勝てるか？を

**判定＝合格条件 (i) は NG-RC に対して不成立**。§13.3 自身が「(i) だけでは不十分、(ii) が本稿の存在理由」と
書いたとおり、**性能優位の主張は撤回し、本系の存在理由を (ii) 固有性質に全面移行する**必要がある。確立済みの
(ii)：**乗法結合**（NG-RC/LMU は加法・入力経路。本系のみ場が σ に乗る＝"noise-modulated" の本体）、
**SR の内点最適**（§13.1 で実証、加法・決定論の NG-RC/LMU は持ちえない）、**forward-only credit**（§7.1、
有限差分一致 ~1e-8）、**$\sigma\to0$ の ESP／生物学的接地**（§10.14–10.15 時間細胞・神経修飾）。加えて
**Ours ≈ LMU入力結合版** は「乗法再定式化に性能コストがない」ことを予算揃えで示す防御材料になる。

**戦略的含意（要ユーザ判断）**：これは §10 が積み上げた性能の物語の中核を撤回する決定であり、進路の選択が要る。
(a) 性能優位を完全に降ろし、(ii) 固有性質＋生物学的接地＋forward-only/HW 親和性で立てる（§13 の「勝つことは
目的でない」較正を本気で適用。投稿先は Neural Networks の neuroscience 系や neuromorphic 系へ寄る）。
(b) 学習した乗法特徴が NG-RC を原理的に超える土俵（§7.2 の「特徴学習は必要」反証＝本プログラム最難問：
非多項式かつ入力適応基底を要する高次元/分岐タスク、または NG-RC の $d^2$ 特徴爆発が効く超長記憶）を作りに行く。
(c) 比較対象を NG-RC が不適用な領域（オンライン・非定常・省メモリ HW 制約下）へ移し、そこでの優位を主張する。
**推奨：(a) を主軸に据えつつ (c) の HW 制約土俵を補強に使う**。(b) は魅力的だが最難問で、成否不明のまま
主張を賭けるのは危険。§13.2 の非 NARMA 一般化も、この文脈では「NG-RC 非適用な土俵を探す」作業として再設計すべき。

**決定（2026-07-30、ユーザ選択）＝(a) を採用**：性能優位の主張を降ろし、存在理由を (ii) 固有性質＋生物学的
接地に全面移行する。これを操作化する**中心図**を作成した（`tmp/reservoir_properties.py` →
`tmp/out/reservoir_properties/properties_ii.png`、4 面「NG-RC/LMU が構造的に持ちえない性質」）：
(1) **乗法ノイズの SR 内点最適**（§13.1、sample 逆 U 字 vs analytic 平坦＝ノイズは資源）、
(2) **forward-only credit が厳密**（解析勾配 vs 有限差分：**cosine=1.000000, 相対誤差 7.2e-9**、BPTT 不要）、
(3) **$\sigma\to0$ の ESP**（LDN・カスケード・減衰直交の散逸場が入力後ゼロへ＝構成的 fading memory）、
(4) **時間細胞**（LDN 場を分数遅延で復号すると各セルが固有遅延でピーク＝窓のタイル化、§13.4 への橋渡し）。
これが新しい主張の骨格：**「性能で勝つ」ではなく「加法・決定論の先行研究が持ちえない乗法ノイズ／SR／
forward-only／散逸 ESP を、生物学的に接地した単一アーキで同時に満たす」**。Ours≈LMU入力結合版 の予算揃え等価は
「乗法再定式化に性能コストがない」防御として併置する。

#### 実行報告（2026-07-31 実施）：path (b)/(c) の probe — (b1) 相補性は成立、θ² 効率反転は否定／(c1) は条件付き

ユーザ依頼で path (b)（NG-RC を超える土俵）と (c)（NG-RC 非適用領域）の最有力候補を実装・実行した。

**(b1) 長窓モーメント × 非多項式外側関数**（`tmp/reservoir_longwindow.py` →
`tmp/out/reservoir_longwindow/longwindow.png`、3 seed）。目標 $y=g(s)$、$s(t)=m_1^2-m_2^2$（$m_r$＝長さ
$\theta{=}40$ 窓の第 $r$ Legendre モーメント）、外側 $g\in\{$linear, tanh, sign 閾値, gauss 検出$\}$。

| 外側 $g(s)$ | NG-RC | Ours |
|---|---|---|
| linear（多項式） | **0.000** | 0.362 |
| tanh$(s{-}1)$ | 0.631 | **0.431** |
| sign$(s{-}0.3)$ | 0.883 | **0.586** |
| gauss $e^{-s^2}$ | 0.897 | **0.577** |

- **当初の (b1) 仮説「長窓非線形で NG-RC は $\theta^2$ 特徴を要し LDN 圧縮が勝つ」は否定**。NG-RC は窓の
  二次形式を**厳密・安価に表現**（linear で NRMSE 0.000）し、滑らかな窓は stride で間引ける。
- **実際に成立したのは多項式↔非多項式の相補性**：NG-RC の読み出しは多項式特徴上で**線形**ゆえ**外側の
  非多項式関数を適用できず**、予算を増やしても gauss で $\approx0.90$ の**表現的フロア**に張り付く（図(1) の
  平坦な曲線）。Ours の学習バンプ写像は普遍的（だが不完全）な非線形で、非多項式標的では NG-RC のフロアを
  明確に下回る（gauss 0.58 対 0.90、sign 0.59 対 0.88）が、**多項式標的では NG-RC に負ける**（0.36 対 0.000）。
- **含意**：§13.3 の「NARMA＝NG-RC の本丸」を裏返した命題＝「**閾値・検出器・飽和など非多項式の標的が
  Ours の本丸**」。両者は標的の多項式性で住み分ける（Ours の絶対誤差は本丸でも 0.58 と不完全な点は正直に留保）。

**(c1) オンライン非定常（concept drift）**（`tmp/reservoir_drift.py` → `tmp/out/reservoir_drift/drift.png`、
3 seed）。ストリーム途中で標的が切替（regime A=遅延4 の gauss 検出、B=遅延20・中心 −0.5）。両手法とも同一の
スライディング窓プロトコル（直近窓で再学習→次ブロック予測）。NG-RC は**読み出しのみ**再学習、Ours/LMU は
**特徴写像を forward-only で継続学習**。定常 NRMSE：**Ours 0.667 < LMU入力結合版 0.723 < NG-RC 0.745**。

- **一様な勝ちではなく、条件付きの二面性**（図の遷移曲線）：
  (i) **特徴が学習可能な regime（A=浅い遅延4）では Ours/LMU が NG-RC を圧倒**（0.15 対 0.65、約 4 倍低）。
  (ii) しかし **切替直後の適応は NG-RC が速い**（読み出しリッジは瞬時、Ours の特徴学習は数ブロックかけて回復）。
  (iii) **特徴が学習しにくい regime（B=深い遅延20、LDN 窓で忠実度低）では Ours ≈0.95 で NG-RC 0.75 に負ける**。
- **含意**：オンライン特徴適応は**諸刃**。regime の非線形特徴が学習可能なら読み出しのみ適応を大きく下回るが、
  適応は遅く、特徴が学びにくい regime では負ける。NG-RC の読み出しのみ適応は**速く頑健だがフロアで頭打ち**。
  当初の (c1) 仮説「オンライン特徴適応が一様に勝つ」は**部分的にのみ成立**。オンライン制約（小窓・warm-start
  過学習：epochs を増やすと悪化）が Ours のバッチ潜在性能を削る点も判明。

**probe の総括**：path (b) は「非多項式標的」という使える住み分けを与える（(b1) 成立、ただし θ² 効率反転は否定）。
path (c) は「学習可能 regime での大幅優位」を示すが「適応速度・難 regime で負ける」二面性つき（(c1) 条件付き）。
どちらも path (a) の (ii) 固有性質を**性能面から補強**するが、単独で「NG-RC に勝つ」と言い切れる土俵ではない。
→ 主軸は (a) のまま、(b1) の非多項式住み分けと (c1) の「学習可能 regime での適応優位」を**補助的**に併置するのが
誠実。次に詰めるなら (c) の HW/オンチップ capability（性能でなく「BPTT なしでオンライン特徴学習できる唯一性」）。

### 13.4 生物学的主張の水準（比喩か測定量か）

**問い**：§10.15 の「LDN 場＝時間細胞」は、比喩を超えた定量的な対応なのか。

**なぜリスクか**：現在示せているのは「Legendre 復号すると各座標が固有の遅延で
ピークを打つ」（選好遅延 6/18/30/42 → ピーク t=6/18/30/41）という、
構成から予測される再現に留まる。海馬・嗅内皮質の時間細胞の非自明な性質 —
**選好遅延が長いほど受容野幅が広がる（時間の対数的／Weber 的スケーリング）**、
遅延の分布が一様でなく短時間側に密であること — と照合していない。
この照合なしに「時間細胞である」と書くと、神経科学側の査読者からは
「基底関数に時間局在があるという当たり前の事実を時間細胞と呼んでいるだけ」と
評価される。逆に照合できれば、Neural Networks の neuroscience セクションや
より上位の一般誌に対する最大の武器になる。

**決着のつけ方**：LDN 場（および窓長 $\theta$ とサイズ $H_f$ を振ったもの）の
各座標について選好遅延 $\tau_k$ と受容野幅 $w_k$ を測り、$w_k$ 対 $\tau_k$ の
スケーリング指数を推定する。実測の時間細胞で報告されている関係
（$w \propto \tau$、いわゆる scale-invariant time cells / Weber 則）と比較する。
併せて、$H_f$ を変えたときにタイル化がどう変わるかを「時間解像度の資源配分」として
提示すれば、§10.21 の $H_f$ 律速の結果に生物学的な意味が付く。
対照として、減衰直交場（神経修飾のクリアランス）と拡散場（容積伝達）でも同じ量を測り、
**どの散逸場が時間細胞様のスケーリングを自然に持つか**を一枚の図にする。

**合格条件**：LDN 場で $w_k$ が $\tau_k$ とともに単調に広がり、その関係が
報告値と桁で整合すること。整合しない場合は「時間細胞である」を主張せず、
「時間窓をタイルする直交時間基底であり、時間細胞と同じ機能的役割を担いうる」
という水準に落とす（この水準でも §10.15 の統合的な物語は成立する）。

#### 実行報告（2026-07-30 実施）：LDN は Weber 則に**不整合**（指数 ≈0.5）→「時間細胞」主張は水準を落とす

**実装**（`tmp/reservoir_timecells.py` → `tmp/out/reservoir_timecells/timecells_scaling.png`）：場に依らない
「時間細胞」定義を用いた — 目標遅延 $D$ に対しランダム入力で $u(t{-}D)$ を再構成するリッジ復号器 $w_D$ を学習し、
その**インパルス応答** $h_D(t)=X_{\text{pulse}}w_D$ を細胞の時間チューニングとする。選好遅延 $\tau=\arg\max|h_D|$、
受容野幅 $w=$ 主ローブの**補間 FWHM**（整数量子化と二次モーメントの裾感度を回避）。復号器のピークが目標 $D$ を
追う細胞のみ採用（記憶破綻復号器が偽トレンドを作るのを排除）。LDN（$\theta{=}100$）・減衰直交・拡散で $w$ 対 $\tau$ の
スケーリング指数を推定（Weber $=1$）。

**結果**：

| 場 | 生物対応 | 指数（$w\propto\tau^{\text{exp}}$） | Weber（=1）判定 |
|---|---|---|---|
| **LDN（時間細胞）** | 海馬/EC 時間細胞 | **0.47**（≈$\sqrt\tau$、単調増だが**劣線形**） | **不整合**（0.5 対 1） |
| 減衰直交 | 神経修飾クリアランス | 0.03（幅ほぼ一定） | 不整合（平坦） |
| 拡散 | 容積伝達 | 1.45（**超線形**） | 過剰 |

- **LDN の受容野幅は $\tau$ とともに単調に広がるが、成長は $\sim\sqrt\tau$（指数 ≈0.5）で、実測時間細胞の Weber 則
  （$w\propto\tau$、指数 1）とは**桁で整合しない**。よって §13.4 の合格条件に従い、**「LDN は時間細胞である」の強い
  主張は撤回**し、「**時間窓をタイルする直交時間基底で、時間細胞と同じ機能的役割を担いうる**」水準に落とす。
- **どの純粋な場も Weber（指数 1）を clean には満たさない**：LDN は劣線形（0.5）、拡散は超線形（1.45）、減衰直交は
  平坦（0）。Weber（1）は LDN と拡散の**中間**に位置する（＝混合場や中間時定数なら当てられる可能性はあるが、
  現行の純粋場では出ない）。指数の精密値は幅測定（FWHM vs std）に感度があるが、**定性順序（LDN 劣線形 < Weber <
  拡散 超線形、減衰直交は平坦）は測定法に頑健**。
- **副産物（§10.21 への生物学的接地）**：LDN の $H_f$ を増やすと細胞が**細くなり時間分解能が上がる**
  （$H_f$=24→48→96 で幅が単調減）。**$H_f$ ＝時間分解能の資源配分**という読みが定量化でき、§10.21 の
  「長記憶＝$H_f$ 律速」に生物学的意味（時間タイルの解像度予算）が付く。

**判定＝水準を落とす（§13.4 の想定どおり）**。「時間細胞である」とは書かず、「時間窓を直交タイルする基底で、
時間細胞と同じ機能的役割を担いうる」に統一する。§10.15 の統合物語（散逸場が時間文脈を保持し回路が非線形計算）は
この水準でも成立。**もし Weber 則を積極的に主張したいなら拡散寄りの中間場を探索する**のが筋（LDN 単体では出ない）。

## 14. 共分散変調 × 多層交差の検証計画（"より noise-modulated" への一歩）

**位置づけ**：現行の NNN Reservoir は「信号が排他的にノイズに宿る」軸では極大だが、変調しているのは**ノイズの
唯一のスカラー性質＝周辺尺度 $\sigma_k$**（周辺・ユニットごと・ガウス）に限られる。"noise-modulated" を「ノイズ
**構造**の変調」まで広げると、残る有望な「先」は**ユニット間ノイズ共分散の変調**（相関ノイズ）で、これは本系の核
（`covariance_credit`／cov_jac＝共分散ベース credit）と地続きである。本節はそれが**表現力を実際に足すか**を検証する計画。

### 14.0 出発点：相関はどこに効くのか（周辺は鈍い／下流層が拾う）

**周辺交差は相関に鈍い**。単一ユニットの期待交差 $\mathbb E[z_k]=2\Phi(d_k/\sigma_k)(1-\Phi(d_k/\sigma_k))$ は
$\eta_k$ の**周辺分布のみ**の関数で、他ユニットとの相関 $\rho_{jk}$ には依存しない。相関は同時分布の性質で周辺には
現れないため、これは **analytic でも sample でも同じ**（`tmp/reservoir_cov_smoke.py` で実測：$\rho$ を $-0.9$〜$0.9$ に
振っても周辺交差率は 0.417–0.421 で平坦）。よって**現行の単層＋線形読み出しは、ノイズ相関を変えても特徴が動かない**。

**しかし「相関が効かない」のは NNN 一般の性質ではなく、単層・周辺特徴に限った話である**。交差層をもう一段
重ねると、第 1 層出力の相関は**第 2 層の前活性の分散**を通じて必ず効く：

$$\mathrm{Var}\Big(\sum_j w_j z^{(1)}_j\Big)=\sum_j w_j^2\,\mathrm{Var}(z^{(1)}_j)+\sum_{j\ne k} w_j w_k\,\mathrm{Cov}(z^{(1)}_j, z^{(1)}_k),$$

すなわち**共分散項が第 2 層ユニットの実効ノイズ幅を変え、その交差率＝出力を変える**。NNN の交差は
「前活性のゆらぎ幅」に応答する素子なので、**相関の変調は下流層にとって“実効 $\sigma$ の変調”として自然に見える**。
**本計画はこの経路を採る**：joint 統計を読む特殊な特徴（単層 co-crossing 特徴）を手で足すのではなく、**交差層を
複数にして、相関がネイティブな機構（下流の分散）を通じて効くようにする**。単層 co-activation 特徴の案は破棄する。

**設計上の含意（重要）**：相関を効かせるのに必要なのは「joint を見る何か」であり、それは
(i) 明示的な joint 特徴か、(ii) **下流の層**か、のどちらかである。(ii) は NNN のネイティブな素子だけで済み、
アーキテクチャの追加概念がなく、`covariance_credit` の思想（ユニットのゆらぎに credit を配る）とも整合する。

**S1 実行報告（2026-08-03、合格）**（`tmp/reservoir_cov_s1.py`）：層 1 の周辺 $\sigma$ を固定し共有:私的の配分だけで
$\rho$ を振り（§14.1）、層 1 周辺交差率と層 2 交差率を実測。

| $\rho$ | 層1 周辺交差 | 層2（coherent $W_2$） | 層2（balanced $W_2$） | pre2 の std |
|---|---|---|---|---|
| 0.0 | 0.4194 | 0.0000 | 0.4106 | 0.452 |
| 0.5 | 0.4202 | 0.0170 | 0.3985 | 1.137 |
| 0.9 | 0.4213 | **0.1282** | **0.3213** | 1.968 |

- **層 1 の周辺は実質不変**（$\rho$ 0→0.9 で +0.0019＝ユニット間ばらつき 0.001 と同オーダー）、**層 2 は 67 倍の変化**
  （coherent +0.128 / balanced −0.089）。**符号が理論どおり**（coherent は共通モードを加算→分散増→交差増、balanced は
  打ち消し→減）。pre2 の std が 0.45→1.97 と増えるのが $\sum_{j\ne k}W_jW_k\mathrm{Cov}$ 項の直接証拠。
  → **$W_2$ の符号パターンが「どの相関構造を読むか」を決める＝対の選択は学習で獲得できる**（§14.2 の主張を裏づけ）。
- **$\rho(t)$ の線形回収**：層 1 周辺（32 ユニット）は **R²=−0.01（回収不能）**、層 2 は **わずか 3 ユニットで R²=0.85**。
  破棄した単層 co-crossing 案（R²=0.57）を**上回る**＝多層経路の方が優れることを確認。

  と緩やかに劣化するのみ（層 1 周辺は全域で回収不能のまま）。層 2 は numT サンプルの交差率を平均するため推定ノイズが
  均され、§13.1 の SR で見た $1/\sqrt{numT}$ の重い依存より頑健。**本比較は numT=64–100 で回せる**＝§14.7 リスク 3
  （sample 分散の二重化）は軽度、モーメント伝播（§14.2 (ii)）は当面不要。

  $d_2,\sigma_2$ を調整し**内点に動作点を置く**必要がある（さもないと低 $\rho$ 域で勾配が消える）。

**判定＝S1 合格**（§14.0 の分散経由経路が数値で成立、設計見直し不要）。

**S2 実行報告（2026-08-03、不合格）**（`tmp/reservoir_cov_s2_oracle.py`）：**ゲート積を共分散機構が表現できるか**を
学習抜きの**オラクル**で検証（理想の周辺エンコード＝各ユニットの σ が $u_5/u_{15}$ を符号化、理想の相関＝
$\rho(t)=\text{gate}(u_{40})$ を手で与える）。最小 2 ユニット診断（unit0 の σ が $u_5$、unit1 の σ が $u_{15}$ を符号化、
相関 $\rho=\sqrt{\text{gate}}$）：

| 量 | corr² |
|---|---|
| 共分散特徴 $\mathrm{Cov}(z_0,z_1)$ vs **目標 $y=\text{gate}\cdot u_5 u_{15}$** | **0.054**（回収失敗） |
| 共分散特徴 vs **gate（相関の強さ $\rho$）** | **0.665** |

  **相関の強さ $\rho$（＝gate）を強く符号化する（corr²=0.67）が、相関している値の積 $u_5 u_{15}$ はほとんど符号化しない
  （corr²=0.03）**。$\rho$ が $[0,0.9]$ を大きく振る乗法因子として支配し、slope·σ の穏やかな $u_5,u_{15}$ 変調を掻き消す。

  できるが、「**相関した信号の積（ゲートされた相互作用）を計算する**」ことはできない。狙った新プリミティブ

- **注意（設計は正しかった）**：S1 で「層 2 は相関に応答する」ことは確かに成立している。S2 が示したのは、その応答が
  **相関の強さ**であって**相関値の積**ではない、という別レベルの事実。ゲート積を選んだのは相互作用の必要性を測る
  ためだったが、この機構ではその相互作用を作れない。

§14.5 の不合格条件どおり「**共分散変調は（少なくともゲート相互作用という狙いでは）表現力を足さず、現行の尺度
変調＝NNN Reservoir が "noise-modulated の実用的極大" である**」で締める。これは STP（§10.22–23）・対数間隔遅延線
（§5.8）と並ぶ、正直な負の結果。**残された可能性**（本命ではない）：co-fluctuation が $\rho$ を読めること自体を活かす
用途——場が**ルーティング/ゲートの判断**を相関で信号し下流がそれを検出する（積の計算ではなく離散的な経路選択）
——は §6.1 の「低速ゲート状態」と接続しうるが、優先度は低く、現行 path (a) を固める方が先。

**共分散変調の別用途スモーク（2026-08-03）：深層 forward-only credit のミラー誤差を無相関化できるか**
（`tmp/deep_mirror_smoke.py`）。`cov_weight` は $W_{ji}=\mathrm{Cov}_t(d_j,z_i)/\mathrm{Var}_t(z_i)$ を復元するが、これが真の
重みに一致するのは **$z_i$ の揺らぎが独立なときだけ**（`nnn/credit.py`）。揺らぎが相関すると欠落変数バイアスで
$\hat W=W_{\text{true}}R$（$R_{ki}=\mathrm{Cov}(z_k,z_i)/\mathrm{Var}(z_i)$、独立なら $R=I$）となる。共分散変調で
揺らぎを**無相関化（whitening）**すればミラーが直る、という仮説。
- **(A) 機構は成立**：相関揺らぎ（mix=0.7、offdiag 0.19）でミラー相対誤差 **0.83**、しかも $\hat W=W_{\text{true}}R$ に
  相対誤差 **0.000** で一致（完全に構造化）。**whitening で誤差 0.001 へ消える**。機構は綺麗に確認された。
- **(B) しかし引き金が弱い**：現実の 3–4 層交差ネットで層内揺らぎ相関 offdiag は**通常ノイズ（σ=0.6, SR 最適域）で
  ~0.008＝無視可**（外挿でミラー誤差 ~3%、有限標本に埋もれる）。相関が育つのは**低ノイズ σ=0.05（~0.06）や高ゲイン
  （~0.06）**の非典型域のみで、それでもミラー誤差 ~20% 止まり。**独立ノイズ注入の設計が揺らぎを decorrelate に保つ**
  ため、通常域では欠落変数バイアスがそもそも生じない。
- **判定＝弱い負**：機構は本物だが、NNN の動作点（noise-as-resource ゆえ中程度のσ）では深層ミラー誤差は無視でき、
  共分散無相関化が解く問題がほぼ存在しない。加えて decorrelation は誤差源の 1 つ（相関バイアス）専用で、深層 credit の
  他の誤差（有限標本分散・slope 推定）は解かない。→ **idea_deep（別取り組み）を今起こす動機は弱い**。留保：学習済み・
  超深層の表現は乱数 $W$ より相関しうる（未検証）ので、低ノイズ/超深層を狙う場合のみ再訪。**多層交差の価値は
  「共分散でミラーを直す」ではなく「forward-only で深い非線形写像を学習できる（線形読み出し RC への対比）」＝論点1
  に置く**のが妥当。

### 14.1 ノイズ場の与え方（共分散を変調する機構）

現行は各ユニットに**独立**な加法ノイズ $\eta_k(t)\sim N(0,\sigma_k^2)$、$\sigma_k=\text{floor}+\text{softplus}((MA)_k+c_k)$。
共分散版は**共有潜在ノイズ**でユニット間に相関を入れる（低ランク＝安価）：

$$\eta_k(t)=\underbrace{\sum_{r=1}^{R} L_{kr}(t)\,\xi_r(t)}_{\text{共有（相関）成分}}+\underbrace{\sigma_k^{\text{priv}}(t)\,\varepsilon_k(t)}_{\text{私的成分}},\qquad \xi_r,\varepsilon_k\sim N(0,1)\ \text{iid（毎サンプル新規）}.$$

- **場が負荷 $L_{kr}(t)=g\big(A(t)\big)$ を与える**（場からの学習線形写像＋非線形リンク）。これが共分散を制御する新しい自由度。
  $R$ は共有モード数（$R\ll H$、既定 $R=2$–$8$）。
- 生じる共分散は $\mathrm{Cov}(\eta_j,\eta_k)=\sum_r L_{jr}L_{kr}$、相関 $\rho_{jk}(t)=\mathrm{Cov}/(\sigma_j\sigma_k)$。
  **場が各ユニットのノイズの大きさ $\sigma_k$（従来どおり）に加え、ユニット間ノイズ相関 $\rho_{jk}(t)$ も決める**。
- **周辺を現行と一致させる**：全分散 $\sigma_k^2=\sum_r L_{kr}^2+(\sigma_k^{\text{priv}})^2$ を現行の $\sigma_k$ に固定し、
  **共有:私的の配分だけ**を場に動かさせる。こうすると「尺度のみ」モデルと**周辺挙動が完全に同一**になり、差は純粋に
  **相関構造**だけになる（フェアな対照）。この設計は必須：周辺が動くと「ただノイズを変えただけ」の交絡が入る。
- 生物対応：共有潜在＝**共有ゲインゆらぎ／correlated variability**（神経系で普遍）、$L$ の場変調＝神経修飾や文脈に
  よる相関の動的制御。§9.1 C 群（場→σ／利得）に**相関変調**を一段足した形。

### 14.2 多層交差アーキテクチャ（相関を拾う機構）

**構成**（2 層を既定、深さは可変）：

$$\text{層1：}\ z^{(1)}_k(t)=\text{crossing}\big(d_k+\eta_k(t)\big),\quad \eta\ \text{は §14.1 の相関ノイズ（場が }\sigma,\rho\text{ を変調）}$$
$$\text{層2：}\ z^{(2)}_m(t)=\text{crossing}\big(W^{(2)}_m z^{(1)}(t)+b_m+\eta^{(2)}_m(t)\big),\qquad \text{読み出し：線形}(z^{(2)}\ \text{[，}z^{(1)}\text{]})$$

- **層 2 が相関を拾う原理**：$W^{(2)}_m z^{(1)}$ の分散に $\sum_{j\ne k}W_jW_k\mathrm{Cov}(z^{(1)}_j,z^{(1)}_k)$ が入るので、
  場が $\rho$ を上げ下げすると層 2 の実効ゆらぎ幅＝交差率が変わる。**相関が「下流ユニットの実効 $\sigma$ 変調」として
  伝わる**。$W^{(2)}$ の符号パターンで「どの対の相関を読むか」が決まり、**学習で対の選択が獲得される**（手で対集合を
  設計する必要がない＝単層 co-crossing 案に対する利点）。
- **実装の要点**：層 1 の出力は**確率変数**なので、層 2 の前活性は「平均＋ゆらぎ」を持つ。評価は
  (i) **sample**（層 1 をモンテカルロで実現→層 2 に流す。相関がそのまま伝播、実装が素直・機構に忠実）と
  (ii) **モーメント伝播**（層 1 の平均と共分散を解析的に求め、層 2 の前活性を $N(\mu,\,W\Sigma W^\top)$ 近似して
  交差期待値を閉形式評価）の 2 方式。**まず (i) sample で viability を見て、必要なら (ii) で分散を落とす**。
- **credit（forward-only を保つ）**：場は固定なので時間再帰は無く、勾配は各時刻の静的和（§7.1）。層 2 は層 1 の
  ゆらぎを通じて学習するため、**`covariance_credit`（ユニットのゆらぎと損失の共分散から credit を作る forward-only 則）が
  そのまま自然な学習則**になる（転置重み backward を要しない）。層 1 のノイズ写像（$M$、負荷 $g$、$d$）と層 2
  （$W^{(2)}, b$）を forward-only で学習し、読み出しはリッジ。**BPTT は不要のまま**。
- **単層 co-activation 特徴は使わない**（本計画から削除）。理由：手で対集合 $\mathcal P$ を設計する必要があり、
  $O(H^2)$ の管理と閉形式 $\Phi_2$ の実装コストを伴う一方、多層化は NNN のネイティブ素子だけで同じ機能
  （joint 統計の読み取り）を、**学習で対選択まで含めて**実現できるため。

### 14.3 ゲート課題（入力依存で相互作用が on/off される課題）

**なぜ必要か**：**静的な積**（NARMA の $u(t{-}x)u(t{-}1)$）は尺度＋混合 $M$ が既に作れる（§10.19）。共分散が勝つのは
**相互作用そのものが入力で動的にゲートされる**課題に限る。具体形（**文脈ゲート積**）：

$$y(t)=\text{gate}\big(u(t{-}c)\big)\cdot u(t{-}a)\,u(t{-}b),\qquad \text{gate}(v)=\tfrac12\big(1+\tanh(\kappa v)\big),$$

既定 $c{=}40,\ a{=}5,\ b{=}15,\ \kappa{=}4$、$u\sim\text{iid }U[-1,1]$。**遠ラグの文脈 $u(t{-}c)$ が高いときだけ、近ラグの積
$u(t{-}a)u(t{-}b)$ が出力に現れる**。

**重要な但し書き：これは「記憶の課題」ではなく「結合の課題」である**。$c,a,b$ はすべて**場の射程内**（$H_f=48$ の
LDN/カスケードが保持できる範囲）に置いてあり、3 つのラグを保持する負担は**場が担う**。共分散変調に問われるのは
「保持された 3 つのラグを**どう結合するか**（文脈で積をゲートする）」だけである。したがって
**共分散変調は記憶容量・保持長には何も足さない**（§5.8 の総線形 MC $\le H$ はそのまま有効、特定ラグの選択的取り出し
可否も場の設計＝§10.12–10.13 が決める）。足すのは**「入力依存で結合を動的に切り替える」能力のみ**。
**より野心的な設計**：$c$ を場の射程外に置き、**文脈を低速フィードバック状態に長期保持させて後続の入力対に適用する**
形にすれば、§6.1（特定時刻のイベント保持）と本節が直結し、**記憶と結合が協調しないと解けない課題**になる。
ただし ESP・forward-only との緊張（§6.1）が生じるので、まずは現行の「射程内・純粋な結合課題」で共分散の可否を
判定し、合格後に §6.1 の拡張へ進むのが安全。

- **共分散＋多層モデルの解き方（自然）**：場が「文脈 $u(t{-}c)$ が高い→lag $a$ と lag $b$ を担うユニットに共有ノイズを
  載せる（$\rho_{ab}\uparrow$）」を学習すれば、層 2 のユニットがその**相関の増減を実効 $\sigma$ の変化として検出**し、
  ゲート積を表現できる＝**場が相互作用を動的にゲートする**。
- **尺度のみモデルの解き方（非効率）**：$(u_c,u_a,u_b)$ の 3 次元空間で乗法曲面をバンプの和で覆う必要があり、同じ
  精度に多くの $H_o$ を要する。→ **誤差 vs 予算曲線で差**が出る、が仮説。
- **課題の頑健化（cherry-pick 回避）**：$(c,a,b,\kappa)$ を数種、ゲート関数を tanh/指示関数で振り、傾向がタスク個体に
  依らないことを見る。相互作用を要さない対照課題（NARMA）と対にする。

### 14.4 比較するモデルと対照

| モデル | 層 | ノイズ | 役割 |
|---|---|---|---|
| **尺度のみ・単層（現行 Ours）** | 1 | 独立・$\sigma_k$ のみ | 基準 |
| **尺度のみ・多層** | 2 | 独立・$\sigma_k$ のみ | **層を足しただけの効果**を分離（決定的対照） |
| **共分散変調・多層** | 2 | 共有潜在＋**場変調の負荷**（$\rho$ 動的） | 提案拡張 |
| **静的相関・多層（対照）** | 2 | 共有潜在だが**負荷固定**（$\rho$ 静的） | 勝因が「**動的な**共分散変調」だと分離 |

**2 つの対照が決定的**：(i) *尺度のみ・多層* が無いと「深くしただけ」の反論を許す。(ii) *静的相関* が無いと
「相関ノイズを足しただけ・パラメータが多いだけ」の反論を許す。加えて**周辺課題対照＝NARMA-20**（静的積・ゲート
なし）で **共分散 ≈ 尺度のみ**（無償の一般改善でなく、ゲート相互作用という特定の新能力）を確認する。

### 14.5 学習と指標・合否

- **学習**：forward-only（場固定→時間再帰なし→各時刻の静的勾配和、§7.1）。層 2 は `covariance_credit`（ゆらぎ×損失の
  共分散）で credit を受け、層 1 のノイズ写像・負荷も同じ forward-only 則で更新。読み出しはリッジ。**BPTT 不使用**。
- **指標**：ゲート課題の **test NRMSE vs 予算**（総ユニット数・パラメータ数・特徴次元を揃える。多層は層 1+層 2 の
  合計で数える）。
- **合格**：ゲート課題で **共分散・多層 < 尺度のみ・多層** かつ **共分散・多層 < 静的相関・多層**、さらに
  **NARMA では共分散 ≈ 尺度のみ**。→「場が動的にユニット間相互作用をゲートし、それを下流交差層が読む」という
  尺度変調に無い能力を実証＝"より noise-modulated" の意味づけが立つ。
- **不合格**：ゲート課題でも差が出ない／静的相関や尺度のみ・多層で同等 → 共分散変調は表現力を足さず、
  **現行が "noise-modulated の実用的極大"** で確定（これはこれで綺麗な締め）。

### 14.6 実施段階と所要時間

新モデル（相関ノイズ生成＋多層交差＋その forward-only credit）を作るので、拡散/STP より実装が重い。段階的に de-risk：

| 段階 | 内容 | 見込み |
|---|---|---|
| **S1** | **機構確認**：層 2 の交差率が層 1 の相関 $\rho$ に実際に応答するか（$\rho$ 掃引で層 2 出力が動くこと、周辺は不変のままであることを実測）。§14.0 の分散経由経路の数値確認 | 実装＋確認で数ラウンド（~30–60 分相当） |
| **S2** | **最小 viability**：共分散・多層 1 個でゲート課題を学習できるか（forward-only で gate を回収）。1 設定・少 seed | 1 バックグラウンド実行（~10–20 分）＋デバッグ |
| **S3** | **本比較**：4 モデル × 予算掃引(5) × 3 seed × 2 課題（ゲート+NARMA）≈ 120 学習 | 2–4 バックグラウンド実行（各 ~30–90 分）＋作図 |
| **S4** | 図・CSV・§への実行報告 | 1 ラウンド |

**全体**：拡散(§5.7)/STP(§10.22–23) と同程度〜やや重い規模。壁時計では本比較が 1–1.5 時間/回、実装デバッグ込みで
複数セッションにまたがりうる。バックグラウンド実行＋通知で進める。**S1 が最重要の関門**（ここで層 2 が相関に
応答しなければ設計自体を見直す）。

### 14.7 正直なリスク

1. **尺度モデルは万能近似器**ゆえ、大予算では両者収束し「勝ち」は小予算・効率差に限られる可能性（誤差 vs 予算で見る）。
2. **多層化それ自体の効果**と共分散の効果が交絡しうる → *尺度のみ・多層* 対照で必ず分離する（§14.4）。
3. **sample 評価の分散**：層 1 のゆらぎを層 2 に流すので推定ノイズが二重に乗る（§13.1 の numT 問題の再来）。
   共有モード数 $R$ を小さく、必要ならモーメント伝播（§14.2 (ii)）へ。
4. **STP・対数遅延線と同様、負の結果もあり得る**（差が出ない＝尺度で十分）。その場合も「現行が実用的極大」という
   価値ある結論になる。
5. **課題の恣意性**：ゲート課題は設計物。静的相関対照・尺度のみ多層対照・NARMA 対照で挟み cherry-pick を排す。
6. **共有潜在ノイズは線形記憶を食う**恐れ（確率成分増）。記憶は決定論場（LDN/カスケード）に残し、共分散は
   **相互作用ゲート専用**に薄く足すのが安全（§5.8 の記憶上限と整合）。
